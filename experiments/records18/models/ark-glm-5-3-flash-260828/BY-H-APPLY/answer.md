## 一、你的定位分析

**优势（能打的牌）**
1. **排名硬通货**：前约3% ≈ 前3%。绝大多数夏令营对"未设研究生院高校"学生的排名要求是前10%（如天津大学化工学院明确为前10%，或在成果、竞赛上突出），你三项全占：排名达标 + EI论文 + 两项国家级竞赛奖。
2. **科研叙事完整**：吸附脱硫 + 催化剂大创 + 一作EI会议论文，正好构成"清洁油品/催化新材料研发"的完整故事线。这条线与石油化工体系的院校（天大、大工、华理、石大、中科院过程所/化物所）**高度同源**，面试时最容易讲出深度。
3. **竞赛背书强**：全国大学生化工设计竞赛属教育部认可的重要全国性赛事（列入全国普通高校大学生竞赛榜单），国二含金量高；化工安全设计国一进一步证明工程化能力，能弥补"偏科研、缺工程"的质疑。
4. **本校推免资格可期**：辽宁石油化工大学具备推免资格，2027届推免工作办法已于2026年9月发布，按排名和综合测评你拿到名额的概率很高。

**短板（要有对策）**
1. **双非出身**：头部985（清北浙复交）化工夏令营对双非入营极其挑剔，不必浪费志愿。
2. **六级425–449**：过了天大化工≥425的硬线，但简历上不占优。2026年12月、2027年6月还有两次刷分机会，目标450–499+。
3. **EI会议论文分量有限**：是有效的"科研经历证明"，但弱于SCI期刊。若2027年4月前能基于大创再产出1篇期刊论文或1项专利，入营率会明显提升。
4. **无SCI、无英文成绩**：面试可能被追问英文文献阅读能力，需提前准备（见第八节）。

**结论**：你的主战场是 **天大、大工、华理、北化四所目标校 + 石油大学两校区 + 中科院系统（过程所/化物所）**，用985冲刺保概率，用行业强校和A类学科双非保底线。下面按 **冲刺6个 + 主申10个 + 保底7个 = 23个组合** 给出完整清单。

## 二、总体策略

1. **三档结构**：冲刺档6个（拿offer靠发挥）、主申档10个（拿offer靠执行力）、保底档7个（确保9月底手里有书可签）。同一学校允许以不同学院/专业/学位类型/校区出现多次（如天大两条、大工两条、华理三条），因为它们是**独立的录取通道**。
2. **双通道打法**：5—7月夏令营为主，9月预推免/九月推免兜底补录。天大官方明确"未获夏令营优秀营员不影响后续9月推免"，所以夏令营没入营≠没机会。
3. **主线叙事**：吸附脱硫（清洁油品、环保硬约束）→ 催化剂（构效关系、失活再生）→ 未来做研发。这条线在天大、大工、华理、石大、化物所、过程所的面试中通用。
4. **材料方向**：以"能源/催化材料"为切入点，用华东理工材料、北化材料两个组合覆盖；若想加大材料比重，可把第6项（北理工）替换为武汉理工大学材料科学与工程学院（材料A+），或把第15项（川大）替换为北京科技大学材料类。
5. **志愿系统规则**（2027届实测）：全国推免服务系统9月21日9:00起填报，**同时只能填3个平行志愿**、提交后48小时锁定，9月24日14:00起可确认"待录取"（一经确认即锁定，不可再改）。所以9月21日的首填组合建议"冲1—稳1—保1"。

9. **面试陈述PPT**：3—5分钟，结构为"背景—方法—我的贡献—结果—读研计划"，务必讲清个人在大创中的具体分工

## 八、套磁与面试要点

- **故事线**：油品深度脱硫是清洁燃料的硬约束 → 我的吸附剂/催化剂做了什么（制备—评价—构效关系）→ 为什么想去贵校该团队继续做 → 研发职业规划。两个设计竞赛国奖讲成"工程化落地与安全环保意识"，正好补齐科研型学生的短板。
- **每校精读2—3位对口导师近三年论文**，套磁邮件和面试提问都要落在具体工作上（例如"您组里XX工作里脱附再生能耗问题，我大创里遇到过类似现象……"）。
- **面试高频问题**：中英文自我介绍各1分钟；论文细节追问（区分"你做的"和"团队做的"，如实回答）；化工原理/物理化学/催化基础题（吸附等温线、判据类计算、催化剂失活原因等）；读研规划（学硕还是直博、想解决的问题）。
- **诚信红线**：EI会议论文不要说成期刊；大创"在研"状态如实说明；所有材料造假会被取消入营和录取资格（天大通知原文警告）。

## 九、风险与合规提示

1. 本文所有时间、专业与通道均为**2026年招生周期（2027届）的实测信息**，2027年（2028级）政策可能调整，务必以各校研究生院/学院当年官方通知为准；大工等专业性强的学院可能出现第二轮预报名、新增专项（如储能、药学）等情况，需持续盯通知。
2. 未获夏令营优秀营员≠失败：天大等多校明确9月推免通道独立有效；南工大、郑大、青科大、石大华东的主要接收工作都发生在9月。
3. 直博=一次性承诺5年，签约前想清楚；学硕入学后仍有硕博连读机会，研发志向两条路都走得通。
4. 谨防非官方"保offer"机构与钓鱼群；所有报名只通过各校官方系统和全国推免服务系统（yz.chsi.com.cn/tm）进行。
5. 23个组合是"申请弹药库"，不是每条都要走到面试：建议实际操作时**夏令营报12—15个、9月推免聚焦5—8个**，把精力集中到主申档。
