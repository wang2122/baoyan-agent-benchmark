# 保研择校方案：15个"学校—学院—电气方向"候选组合（电网就业导向）

**答卷口径说明**

- 撰写基准日：2026年3月18日。面向2027年入学的各校夏令营/预推免通知尚未发布，文中时间与门槛均参照2025年各校官方通知的节奏，最终以2026年当年通知为准。
- 主要依据：教育部学位与研究生教育发展中心第四轮学科评估（0808电气工程）官方结果；各校研究生院/学院官网通知（如东南大学电气工程学院2025年夏令营通知、华北电力大学2025年接收推免办法及学院细则等）；国家电网招聘平台公示及第三方公开统计（不同口径有出入，凡引用均标"约/据公开统计"）。
- 假设：按"家在南京（江苏）"理解"尽量离家近"；若家在苏北或邻省，可上调徐州（矿大）、合肥（合工大）两站权重，整体结构不变。

## 一、先看清你手里的牌（定位分析）

**优势**

1. 硬成绩：南京信息工程大学是"双一流"高校，电气工程及其自动化是国家级一流本科专业建设点、通过教育部工程教育认证（设于自动化学院，并与国电南京自动化股份有限公司联合培养）；专业排名前约2%（前2%），满足东南电气"双一流高校电气类本科、成绩名列专业前茅"的入营硬条件，也通吃绝大多数学校的推免门槛。
2. 英语：四级600–649、六级550–599。东南电气要求"四级≥500或六级≥425"，华北电力电气学院要求硕士推免"六级≥425"，你全部远超；六级550–599在面试英语环节是直接的加分项，也让美赛、全国大学生英语竞赛的"英语好"人设可信。
3. 科研方向高度契合：汽车充电调度EI论文（在投）正踩在"车网互动、新型电力系统优化调度"的热点上；东南大学电气工程学院官网明确把"电动汽车无线充电、综合能源系统与需求响应"列为特色方向——这是你套磁和面试的现成故事线。在审专利是第二佐证。
4. 综合素质：美赛＋全国大学生英语竞赛＋智慧精英类竞赛，支撑"数理建模＋英语＋综合能力"的画像。

**短板与风险**

1. 推免资格未落袋：按前约2%的排名，获名额概率很高，但正式名单要9月才公示，这是全年最大的单点风险（对冲见第六节）。
2. 硬成果未兑现：论文未录用、专利在审，"成果栏"暂时是"在途"状态，筛材料时说服力打折——夏营报名前能落定一项是一项。
3. 本校电气非电力传统强校：在东南、浙大这类学校的入营池里，要靠"排名前2%＋英语＋方向契合"主动讲清自己（简历第一屏就写工程教育认证、一流专业、排名证明）。
4. 竞赛若非国家级以上奖项，综测加分有限，主要作面试素材使用。

**总体结论**：适合"漏斗型"结构——冲刺东南（本部＋苏州联合研究生院双通道），主申电网系211（华电、武大、山大、合工大、矿大、南师大、河海），保底电力行业校（南航、上电、三峡）。主申档只要拿下任意一个，"进电网＋离家近"的目标即告成立；东南是上限牌，值得全流程三线并进。

## 二、择校三筛（为什么是这15个）

1. **电网认可度筛**：国网校招按"电工类"专业筛简历，且明显偏好电力传统校。据公开统计：2025年国网录用总量华电约1600人（全国第一，另有统计口径约1800）；三峡大学约700人、上海电力约600人，均居全国前五。江苏电网2026年第一批（含提前批）实际录用约1153人、其中电气岗约950人（2026年1月公示口径）；2025年江苏电网录用中，第三方统计南京工程约250人居首、东南大学约102人次之，南师大、矿大、河海等也是主力211。选校先问一句：这所学校去年有多少人进了电网、进的是哪个省网。
2. **地域筛**（以南京为圆心）：南京本地（东南/南师大/河海/南航）→ 1小时高铁圈（矿大·徐州/合工大·合肥）→ 2.5—3小时圈（上电·上海/浙大·杭州/山大·济南/武大·华科·武汉）→ 更远（华电·北京约4小时，因电网系统地位唯一破例入选）。学科评估参考（第四轮，官方）：华电A、华科A，浙大A-，上交/东南/南航/山大B+，矿大/合工大/武大B，河海/上电/三峡B-；东南电气学院官方另称第五轮评估"取得跨越性突破"、软科电气近三年全国第5—8名。
3. **方向与代码筛**：
   - 进电网首选**电力系统及其自动化**（调度、规划、变电、营销口都认）；**高电压与绝缘技术**对口特高压与省检修；**电力电子与电力传动**对口直流、储能、新能源，与你论文最契合；电机与电器、电工理论与新技术对口性弱，不作为推荐方向。
   - 专硕认准**085801电气工程**；不要报"085800能源动力"大类下的非电气方向，避免网申专业不符被刷。学硕（080800）与专硕（085801）在国网网申中同等有效，差别主要在学制、学费与读博便利。

## 四、逐项详解：为什么、胜算、怎么打

### 冲刺档（1—5）

**1. 东南大学 · 电气工程学院 · 080800电气工程学硕（电力系统及其自动化方向），兼报085801电气工程专硕**
- 为什么：如果你的终点是江苏电网，东南电气就是"天花板"选项——第四轮评估B+，但学院官方称第五轮学科评估取得跨越性突破、软科电气近三年全国第5—8名；是国内首批电力系统自动化博士点、我国首个通过工程教育认证的电气专业。据第三方对国网江苏2025年录用公示的统计，东南约102人居全省第二（仅次于南京工程学院），江苏及华东电网校友网络最厚；学校就在南京，通勤、家访、人脉全部最优。
- 契合点：学院特色方向含"电动汽车无线充电、综合能源系统与需求响应"，与你的充电调度论文同源，套磁邮件有现成切入点；四级600–649远超其"四级≥500或六级≥425"门槛；南信大双一流＋前2%满足其入营对象条件。
- 怎么打：2025年流程是7月1日—31日在东南研究生报考服务系统（gsas.seu.edu.cn）报名、只能填一个志愿、8月初公布入营名单——2026年预计同节奏，6月下旬起盯电气学院官网；同时准备9月的推免预选拔（预推免）；入营前给车网互动/综合能源方向的老师发套磁邮件（附论文摘要）。若科研意愿强可问直博，以电网就业为纲则硕士更优。
- 风险：入营≠优营，本部竞争激烈；优营后仍需9月拿到本校推免名额才算闭环。

**2. 东南大学—蒙纳士大学苏州联合研究生院 · 085801电气工程专硕（电气工程学院负责培养）**
- 为什么：这是"曲线进东大"的官方第二通道。电气学院2025年通知明确"苏州联合研究生院电气工程专业由我院负责培养"，毕业授东南大学学历学位，国网校招一律按东南大学认可；报考/入营门槛通常低于本部，且本部若被退回，7月下旬—8月初可改报苏州联院夏令营（2025年规则）。
- 代价：学制3年、学费6.2万元/年（2025—2026年标准）、全英文授课，校区在苏州。能接受这两点，它就是东南本部之外性价比最高的选择。
- 怎么打：与本部共用一套材料同步准备；单独关注苏州校区/联合研究生院的夏令营与推免通知；志愿填报阶段若手里有苏州联院优营而本部只是候补，果断用它锁定"东南学籍"。

**3. 浙江大学 · 电气工程学院 · 080800电气工程学硕（电力系统及其自动化方向）**
- 为什么：第四轮A-，稳居第一梯队；杭州在南京1小时高铁圈，浙江省网待遇全国前列，长三角就业半径完全覆盖"离家近"；平台对将来进电科院、读博都是加分。
- 怎么打：5—6月关注夏令营通知，竞争极强，把它当一张高价值彩票；材料突出"优化调度建模（美赛＋EI在投论文）＋英语（六级550–599）"的组合；电力系统、储能方向都与你的论文衔接得上。

**4. 上海交通大学 · 电子信息与电气工程学院 · 电气工程系 · 080800电气工程学硕（电力系统及其自动化方向）**
- 为什么：985顶尖平台；第四轮B+但生源与就业质量高，上海到南京高铁1.5—2小时；智能配电网、储能与电力市场方向强，华东电网认可度高。电气体量小、精品化，名额少是双刃剑。
- 怎么打：电院夏令营一般在5—6月开放报名，动手要早；面试准备用英文讲清你的充电调度模型（建模思路＋结果），这正是它欣赏的类型。

**5. 华中科技大学 · 电气与电子工程学院 · 080800学硕或085801专硕（电力系统及其自动化方向）**
- 为什么：第四轮A，与华电并列全国第3—4；研究生招生体量大，对外校优秀生源相对友好；武汉与南京高铁约3小时。若接受这个距离，它是"名校牌＋电网全国通吃"的高性价比冲刺。
- 怎么打：6—7月夏令营；强电磁、电力系统、电力电子大方向都不排斥你的车网互动背景；若最终不愿离家太远，用第7项武大平替此冲即可。

## 六、风险对冲清单

1. **推免资格（最大单点风险）**：排名前约2%按学院往年比例大概率在列，但要做四件事——后续学期成绩不翻车；吃透综测加分细则并逐项落实（EI录用、专利受理、目录内竞赛获奖）；所有获奖与论文证明在9月前完成归档；万一极端情况未获名额，Plan B为12月考研（目标东南电气或南师大/河海电气）或以六级成绩申请港澳高校电气类硕士。
2. **论文与专利"在途"**：夏令营前拿到录用通知最理想；赶不上就用"已投＋在审＋摘要/预印"分层展示，套磁邮件永远附技术摘要而非空口描述；专利以受理＋实审为准，授权不强求。
3. **竞赛加分面**：智慧精英类竞赛在材料中写明主办单位与获奖等级（如属全国普通高校大学生竞赛榜单赛事或省级以上奖项，综测可加分）；美赛与英语竞赛主要作面试英语与建模能力佐证，与四级600–649/六级550–599互相印证。
4. **时间冲突**：7月夏令营密集，东南（8月上旬）与华电、浙大（7月中下旬）大概率错峰，但南师大、河海、合工大、矿大可能互撞——按第1—15项的优先级预设取舍。
5. **志愿填报纪律**：系统仅3个平行志愿；手握优营先填优营校；东南本部若只是候补，平行填苏州联合研究生院锁定"东南学籍"；未确认待录取前不要口头放弃任何一家。
6. **材料细节**：成绩单与排名证明提前两周找教务盖章；两封专家推荐信提前约；所有扫描件去底色、按清单命名，避免形式审查被退。
