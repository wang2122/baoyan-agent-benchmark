# 2026年推免申请：12个"学校—学院—专业（项目）"组合推荐方案

## 一、申请人背景定位

- **院校与排名**：东北大学生物医学工程（985平台），专业排名 前约3%（约前 约3%），稳居校内第一梯队，获推免资格把握很大。
- **英语**：CET-6 500–549 分，高于绝大多数夏令营/预推免的英语门槛（常见要求 425–500）。
- **科研经历**：医学影像 + 机器学习，与"医学影像计算 / 医学人工智能 / 医工交叉"方向高度对口。

**硬指标自查（参考近年公开要求）**：清华大学生物医学工程学院夏令营近年要求"本科前三学年总评成绩一般在年级前15%、985/211高校优先"（达标）；中科院深圳先进院医工所要求"专业排名前30%"（达标）；多数985院校BME夏令营要求前10%–30%（达标）。整体上具备冲击C9及A类学科院校的资格。

**总体策略**：12个组合按 **"4冲刺 + 5稳妥 + 3保底"** 梯度分布，全部锁定医学影像/医学人工智能相关方向，兼顾地域（北京、上海、南京、杭州、武汉、西安、成都、深圳、沈阳）与考核渠道（夏令营＋预推免双通道）。

## 三、逐项推荐说明

### 冲刺档

**1. 清华大学生物医学工程学院 — 生物医学工程（医学影像/智能医学方向）**
- 推荐理由：清华BME为第四轮学科评估A-，医工交叉平台与附属医院资源全国顶尖；现以独立的生物医学工程学院运行，设直博、学硕项目，招生与考核信息通过清华研究生申请服务系统（yzbm.tsinghua.edu.cn）发布。
- 匹配点：医学影像、医学人工智能是学院核心方向之一，你的影像+ML经历直接对口。
- 申请要点：直博生材料提交窗口近年约为7月1日–7月28日（如2026级为2025年7月1日–28日）；夏令营门槛曾为"年级前15%"，材料审查后按招生计划1.5–4倍确定综合考核名单；9月还有硕士推免考核办法（8月下旬发布）。
- 备注：竞争极强，建议同步关注清华大学深圳国际研究生院的医工相关方向等平行渠道。

**2. 上海交通大学生物医学工程学院（含Med-X研究院） — 生物医学工程/电子信息（医学影像方向）**
- 推荐理由：第四轮学科评估A；学院研究生项目涵盖生物医学工程、生物学、生物与医药、电子信息四个学科，第一大类方向即"医学影像、医疗机器人、生物医疗仪器、纳米生物材料、脑机接口等"。
- 渠道：每年7月举办"研究生优才夏令营"（线下，统一安排住宿）；学院明确"优先通过夏令营招收推免生，视生源情况决定是否举办9月推免"——**务必参加夏令营**。
- 政策：优秀营员获推免资格并在推免服务系统第一志愿报考即拟录取，直博优先；另有工程硕博士培养改革专项（校企联合培养，名额单列）。
- 竞争：极高（常年吸引北大、南大等头部生源），面试重视数理、编程与科研陈述。

**3. 东南大学生物科学与医学工程学院 — 生物医学工程（医学影像与图像处理/医学人工智能）**
- 推荐理由：第四轮学科评估A+（全国并列第一），国家重点学科、首批"双一流"建设学科，学院官网称"近四轮教育部学科评估中连续获得第一或A+评级"；依托数字医学工程全国重点实验室（2023年3月获批，聚焦数据采集融合、医学人工智能和智能数字诊疗），学院另设有生物医学信号与图像处理实验室。
- 匹配点：影像处理是学院传统强项，与你的项目方向完全一致。
- 渠道：夏令营＋9月预推免；学硕、专硕、直博齐全；苏州医疗器械产业技术研究院提供产教融合通道。
- 竞争：高；对图像处理、信号与系统等专业基础考查较深。

**4. 浙江大学生物医学工程与仪器科学学院（生仪学院） — 生物医学工程（医学影像与医学信息）**
- 推荐理由：A-学科；浙大"信息+医学"双重生态（附属医院、计算机学院资源丰富），影像组学与医学信息方向成熟。
- 渠道：2026年夏令营为7月2日–4日（玉泉校区），报名6月22日截止，欢迎直博生；未获优秀营员可走9月预推免（参考2026级通知：9月10日前完成系统申请）。
- 特别提示：学院已发布"2027年硕士研究生招生学科专业调整公告"，报名前务必核对最新专业目录与代码。
- 竞争：高；面试含专业英语与科研经历陈述。

### 稳妥档

**5. 华中科技大学生命科学与技术学院 — 生物医学工程（医学影像/分子影像计算）**
- 推荐理由：第四轮学科评估A+（与东南并列全国第一）；武汉光电国家研究中心的生物医学光子学与分子影像平台全国知名。
- 渠道：6月夏令营＋9月预推免；学硕/直博名额较多。
- 匹配点：影像重建、光学成像、影像AI课题组多，机器学习背景受欢迎。
- 竞争：高，但在A+院校中入营机会相对较多，是"冲A+学科"的性价比之选。

**6. 复旦大学 信息科学与工程学院生物医学工程系 — 生物医学工程学硕（医学影像与人工智能）/电子信息专硕（人工智能——医学影像与辅助诊断）**
- 推荐理由：1996年硕士点、2000年一级学科博士点、2003年博士后流动站，上海市重点学科；夏令营方向目录中"医学影像与人工智能"（学硕02）与"医学影像与辅助诊断"（专硕12）与你的背景严丝合缝（参考2024年夏令营方案）。
- 动态：学校新设"生物医学工程与技术创新学院"（已举办2025年夏令营并承担工程硕博士培养改革专项），报考当年务必确认学院归属与专业目录。
- 竞争：高；上海平台对实习与就业友好。

**7. 西安交通大学生命科学与技术学院 — 生物医学工程（医学影像分析与AI）**
- 推荐理由：学院下设生物医学工程、生物学两个一级学科，医工交叉特色鲜明，与附属医院合作的影像组学/影像AI团队多。
- 渠道：5–6月夏令营（近年已连续举办至第十二届）＋9月预推免（参考2025级窗口：9月13日–22日报名）；夏令营优秀（合格）营员在推免中优先录取，新生奖学金覆盖面大。
- 竞争：中高；对985生源友好，你的排名有优势。

**8. 北京航空航天大学生物与医学工程学院（医工交叉学科群） — 生物医学工程（医学影像与医学人工智能）**
- 推荐理由：A-学科；学院由2002年成立的生物工程系发展而来，另有医工交叉学科群（医工交叉创新研究院/医学科学与工程学院）联合招生，设083100生物医学工程学硕、077700生物医学工程（授理学学位）及专业学位、直博等多种类型。
- 渠道：以9月推免工作方案为主渠道，历年9月还组织第二批直博生报名——错过夏令营仍有较大概率。
- 匹配点：医学影像、医学人工智能方向组多，工科氛围与你的ML背景契合。
- 竞争：中高。

**9. 中国科学院自动化研究所（中国科学院大学培养单位） — 控制科学与工程/电子信息（医学影像与模式识别、影像组学）**
- 推荐理由：拥有多模态人工智能系统全国重点实验室和中国科学院分子影像重点实验室（医学影像、影像组学、手术导航），"AI+医学影像"研究实力全国一线。
- 渠道：6月"人工智能"大学生暑期学校是主入口；9月推免考核，历年常有第二批（导师推荐制）——未入营者9月直接联系导师仍有机会；推免简章明确欢迎"生物及有志于开展交叉学科研究的相关专业"背景。
- 学位：学硕（控制科学与工程等）、电子信息专硕、直博；学籍在中国科学院大学。
- 竞争：高（AI赛道热门），但医学影像组方向相对主赛道略缓，值得重点投入。

### 保底档

- 推荐理由：医学成像全国重点实验室（超声、MRI、光声、PET与影像AI），并与国家高性能医疗器械创新中心开展工程硕博士联培专项（直博＋推免硕士名额单列）；方向与"医学影像+ML"高度重合，地处深圳，产业与就业生态好。
- 渠道：6月夏令营（医工所单列）＋8月下旬推免（含直博）通知；申请门槛参考"前三学年专业排名前30%"。

**12. 东北大学医学与生物信息工程学院（本校） — 生物医学工程（生物医学影像学/人工智能临床医学等自设二级学科方向）**
- 推荐理由：学院拥有生物医学工程一级学科博士点、硕士点与博士后流动站，自设生物医学影像学、人工智能临床医学等二级学科，学科以医学影像、医学信息学、健康电子为核心——与你的影像+ML背景完全对口；地处沈阳，毗邻东软医疗等医学影像设备龙头，产教资源好。
- 保底价值：本校推免录取确定性最高，可提前锁定影像AI课题组，争取硕博连读或直博。

## 五、备考与材料建议

1. **项目陈述公式**：临床问题 → 数据与模态（CT/MRI/超声/病理，数据规模）→ 方法（预处理、U-Net/Transformer等网络、损失函数、数据增广）→ 指标（Dice/IoU/AUC及相对基线的提升）→ 个人独立贡献。准备一页纸"项目摘要"和可演示的代码/结果截图。
2. **笔试/机试复习**：数字图像处理、数字信号处理、概率统计、机器学习与深度学习基础（CNN、Transformer、优化与正则化）、Python/C++编程题。
3. **英语**：500–549分已达标，重点练口语自我介绍、英文文献朗读与翻译（多校面试含文献题）。
4. **套磁**：5–6月向意向导师发邮件（CV＋排名证明＋项目一页纸）；对东南、西交、自动化所、深先院等导师话语权较大的单位，先拿到导师意向再走流程，事半功倍。
5. **填报节奏**：推免服务系统中可填报多个志愿但最终只能确认一个待录取；先锁定保底（本校/川大/深先院），再等冲刺院校结果，留意各校"待录取确认"截止时间，避免两头落空。
