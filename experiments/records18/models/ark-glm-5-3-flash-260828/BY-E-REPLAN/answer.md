# 升学方案调整与海外申请

**（2025年7月版 · 目标2026年秋季入学）**

背景：2025年7月，本轮已无法通过国内推免通道升学，已决定转向境外研究生申请；原答卷对资格原因及与导师协商的断言已概括；地区意向为香港、新加坡，以硕士层次为主体规划。本方案按"先定方向、再排项目、再排考试与材料、最后排时间表与预案"展开。文中截止日期、学费、语言门槛按各校为2026年秋季入学公布的安排与近年规律整理，最终一律以各校研究生院及项目官网当年页面为准。

---

## 一、总体判断：先定方向，再动手

1. **时间完全来得及，不需要gap。** 港新申请主战场在2025年9月—2026年2月。现在距港校开放约1.5—2个月，距港大主轮（2025年12月1日）约4个半月，距NUS截止（2026年1月31日）约6个半月。走"大四上申请 → 2026年6月毕业 → 2026年8—9月入学"的无缝衔接。
2. **当前唯一硬缺口是语言成绩。** 此前无雅思/托福；港三新二的底线普遍在雅思6.0—6.5，且港三新二基本不接受六级。语言安排必须放在第一优先级（见第四节）。
3. **竞争力定位。** 南大C9背景在港新认可度高；均分83.4处于"可申但不稳"区间，需要用科研履历（NJU NLP科研约半年、第二段科研在研、自然语言处理会议论文在途）对冲。策略上必须拉开梯度：冲刺、主申、稳妥三档都要有，不能只盯港三新二。
4. **主线与支线并行。** 以授课型硕士为主线（录取确定性高、学制短、学历可留服认证），同步套磁香港研究型硕士（MPhil）作为科研向冲刺——MPhil通常带每月约1.9万港币津贴，经济上最优，但名额少、不确定性大，只能并行，不能作为唯一方案。

## 二、授课型 vs 研究型：先把培养路径分清

| 维度 | 授课型硕士（港MSc / 新MComp、MSc） | 研究型硕士（港MPhil；新加坡研究型硕士极少） |
|---|---|---|
| 学制（全日制） | 港约1年；新约1—2年 | 港MPhil约2年 |
| 费用 | 自费为主，总花费约25—60万人民币 | 一般带津贴：港MPhil约HK$19,100/月（2025/26—2026/27水平），基本覆盖学费+生活 |
| 申请方式 | 网申+文书+推荐信+语言成绩，不强制联系导师 | 必须提前套磁导师、提交研究计划，多数有面试 |
| 竞争逻辑 | 看院校背景、均分、实习科研、语言 | 看科研记录、论文、方向匹配；名额很少 |
| 出口 | 以就业为主，也可再申博士 | 学术/研发路径，可直接衔接博士 |
| 与国内的关系 | 不是"学硕"，但属正规硕士学位，教育部留学服务中心可认证，就业、考公、再申博均可用 | 对应国内"学硕/直博"的学术培养路径 |

要点澄清：不能把"国内学硕"直接等同于"境外只接受研究型硕士"。境外授课型硕士是被广泛认可的正规硕士（毕业做留服认证即可用于就业、考公、再申博）；真正对应学术培养的是MPhil/博士。因此**建议：主申授课型6—8个项目 + 同步套磁港三MPhil 2—3所**。若论文在申请季落地、导师人脉引荐顺利，MPhil有机会转正；无论结果如何，授课型offer都能保住入学确定性。新加坡的研究型硕士名额极少，若坚持科研路径且愿意读博，可在大四上同步咨询新加坡直博（NUS/NTU博士8月入学一般前一年8—12月申请），但这超出硕士层次、对论文要求更高，只作可选支线。

**港新怎么选（从你的港新倾向出发）：**
- **预算紧、想快毕业** → 以香港为主：一年制总花费明显低于新加坡，离家近、实习面试方便，毕业后有IANG类安排可留港就业。
- **不赶时间、看重科研氛围或新加坡就业** → 新加坡权重上调：NUS/NTU学制更长、课程更重，但NUS要GRE、总花费更高（学制1.5—2年），NTU语言门槛（雅思6.5/托福100）高于港校底线。
- **组合建议**：港三打主，NTU MSAI作并列主申，NUS视GRE备考情况决定去留（见第四节）。

**投递策略：**
- 同一学校常有多个可申项目（如港大另有电子商贸与互联网计算等），可在同一校内加投1个摊薄风险；每多一个项目多一份申请费（港校约HK$200—500/校，NUS约S$109、NTU约S$50）。
- 滚动录取、先到先审的项目（科大、城大等）必须首轮带分递交，晚交等于自动降档。

## 四、语言考试安排（第一优先级，本周启动）

1. **选雅思**（港新最通用），目标分**6.5（单项6.0）**：够到全部目标项目底线，接近多数项目的实际录取水平。
2. **时间线**：
   - 本周内：报名8月下旬—9月中旬的雅思机考（暑期考位紧张，先锁位再刷题）；
   - 8月底—9月中：首考；一次到6.5则全部递交节点无忧；
   - 若首考不达标：10月中二考、11月底三考为最后窗口（港大主轮12.1、科大/城大/中大首轮在11月—1月底，带分递交远优于先申后补）。
3. **六级怎么用**：城大（CET-6 450+）、理大（部分项目CET-6 425–449+/CET-4 500–549+）等接受六级，你的CET-6 500–549、CET-4 550–599可满足其门槛——即**即使雅思一时翻车，城大/理大/浸会这条稳妥线依然可递交**。但港三新二不认六级，主线必须考出雅思。城大计算学院研究型课程另接受CET-6 450–499，可作为研究档的无雅思备用通道。
4. **GRE只与NUS绑定**：NUS MComp强制要求GRE 320+3.5或GMAT 650+；NTU MSAI与所有港校都不要求。决策规则：若9月底前雅思出分且精力允许 → 10—11月考一次GRE，保住NUS选项（NUS 1.31截止，时间恰好够）；若雅思刷分或论文修改占用过多 → 果断放弃NUS，用"港三 + NTU MSAI"组合覆盖冲刺档。
5. 不建议雅思托福双线；托福（港80 / 新90—100）只在你明显更适应机考时作为替代。

## 五、论文与科研：申请季怎么打这张牌

**论文按两种状态处理（自然语言处理会议 2025主会通知为2025年8月20日，会议2025年11月5—9日苏州）：**
- 若已投出且8月出分中稿：9—10月把CV更新为"Accepted, 自然语言处理会议 2025 (to appear)"，这是全申请季最硬的增量；11月赴会与否与面试季重叠，酌情安排。
- 若未赶上或未中：与导师定转投计划——走ARR下一周期（ACL 2026对应2026年1月5日的ARR截止、2026年4月初出结果，正好在申请季中段出分）或其他CCF-A/B会议/期刊；所有申请表如实标"Under review"，后续中稿再邮件更新给已递交院校。

**文书用法：**
- CV教育背景写均分83.4/100即可，不主动提交排名（前约45%不占优，除非项目强制要求）；
- 科研经历按"问题—方法—你的具体贡献—结果/状态"写，两段科研+在投论文是文书核心；
- PS里**不需要、也不要提"国内推免通道变化"**——你就是一名正常的留学申请人，转轨原因无需解释；
- 推荐人：科研导师（强推，对MPhil与面试尤其关键）+1—2位课程/科研合作教师；8月内把CV、成绩单、申请项目清单和各校截止时间打包发给推荐人。

**MPhil套磁（8月中备齐，9月上中旬发出）：**
- 在港三CS/CSE系筛2—3位做NLP/LLM方向、近两年活跃的导师，每校2—3位、共6—8位；
- 套磁信（英文）结构：一段自我介绍（学校/方向/均分段）+一段对导师近期论文的具体呼应+一段你的贡献与在手论文+附件（CV、成绩单、论文摘要）；
- 港研究型主轮普遍在2025年12月1日前后（与HKPFS奖学金截止同步，以研究生院为准）；
- 两周不回跟进一次，再无回复即收手，重心转回授课型——套磁的时间成本可控，收益上限高。

## 六、申请材料清单（8月内备齐）

- 中英文成绩单（盖章，先开前三年；大四成绩2026年上半年后补）+ 中英文在读证明（9月开学后开）
- 护照（7—8月办理，检查有效期）
- 雅思成绩单及官方电子送分
- 英文CV（1—2页）；PS/个人陈述（每校按项目定制300—800词，回应项目指定问题）
- 推荐信2—3封（网推，把链接和截止时间提前转给推荐人）
- 科研佐证：论文在投/录用状态、实习与项目说明、获奖证书（可选）
- 资金证明：申请阶段一般不需要；录取后办港校学生签时需财力证明（常见按覆盖学费+首年生活费准备，约HK$30—50万区间；新加坡学生证一般无需大额存款证明）

## 九、风险与预案

1. **雅思三考仍不达标**：用六级走城大/理大/浸会稳妥线；或换托福赛道；若全线无语言，转入"2027年春季/2027年秋"路径——注意2026年春季入学对你不可行（尚未本科毕业），备选春季从2027年2月算起（港科大等工学院设2月初春季入学，约2026年下半年申请）；英国多数项目可无雅思先申、拿条件offer后补交，可作为时间兜底。
2. **全拒**：按"补申英国/澳门（窗口更晚、滚动录取）→ 2027春季 → 强化科研后申2027秋研究型/博士"三级推进；空档期可用毕业后的半年做科研助理或实习，反而增强下一轮材料。
3. **留位费压力**：港校offer常要求2—4周内缴纳数万港币留位费，而更想要的结果可能更晚出——接受前问清金额与退还规则，与家庭提前约定资金调度。
4. **大四成绩滑坡**：港新条件录取普遍要求最终成绩不低于申请时水平，毕业论文认真完成，别让最后一年拖后腿。
5. **信息时效**：以上截止日、学费、语言线以各校研究生院/项目官网2026/27学年页面为最终依据；9月起每两周核对一次目标项目页面。
