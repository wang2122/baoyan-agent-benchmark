# 南理工智能制造工程 前约27%：推免准备该先做什么

> 答卷日期：2026年10月10日。下文的时间节点、政策条款已联网核对过，来源在文末。学院内部的推免细则和名额搜不到公开版本，这部分要你自己去学院核实，文中会标出来。

## 先说结论

**第一件事是弄清楚你处在哪个阶段，以及你在学院推免序列里排第几。** 排名够不够、项目怎么用，都取决于这个。

今天是10月10日，正好卡在本轮推免的收尾阶段：

| 节点 | 时间 |
|---|---|
| 推免服务系统注册、查看本人推免资格 | 2026年9月18日起 |
| 推免系统填报志愿 | 9月21日 9:00 起，**10月18日截止** |
| 确认复试、待录取通知 | **10月20日截止** |
| 2027考研预报名 | 10月9日–12日 |
| 2027考研正式报名（报名和确认一步完成，逾期不补） | **10月15日–24日** |
| 2027考研初试 | 12月19日–20日 |
| 南理工推免拟录取公示 | 往年在10月中下旬 |

所以要分两种情况：

- **你是大四（2027届）**：本轮推免还剩大约一周，第一部分是你的行动清单，**今明两天就要做完判断**。
- **你是大三（2028届）**：时间还算充裕，但"最近才开始"已经比很多人晚了。第二部分是一年的规划。

---

## 第一部分：如果你是大四（2027届）

### 第一步：今天就确认自己的推免资格

打开 [推免服务系统](https://yz.chsi.com.cn/tm/)，看能不能查到自己的推免资格，同时找辅导员或学院教学办问清楚三件事：

1. 你有没有拿到推免资格？还是在候补或递补名单上？
2. 学院最终排名用的是"纯课程成绩"还是"综合成绩"（课程成绩加科研竞赛加分）？你在那个口径下排第几？
3. 今年这个专业的名额是多少？已经有多少人放弃名额？

注意：智能制造工程专业现在归**智能科学与技术学院**（由原智能制造学院重组，2025年9月揭牌）。你这届如果仍挂在其他学院，就以你实际所在学院的通知为准，别看错了地方。

### 第二步：按结果分三条路走

**A. 有资格但还没拿到待录取通知（最紧急）**

- 10月18日前还能填志愿。3个平行志愿同时投，每个志愿提交后锁定48小时；被拒、48小时没收到复试通知或复试没过，志愿会自动解锁，可以改投。
- 这个阶段要找"还有余额"的单位：天天刷各校研招网和学院官网的"推免补录 / 二轮接收"通知，盯紧保研群里的余额信息，直接给招生秘书打电话问还收不收人。
- 优先考虑这几类：
  - 本校南理工（很多学院收本校生更积极）；
  - 中科院所属研究所的工程类方向；
  - 双一流高校里机械、控制、智能制造相关的**专硕**和新设方向；
  - 行业特色强校。
- 现在别执着于冲名校，"先上岸"是第一目标。
- 面试几乎都会让你讲项目，用第三部分的方法准备一份3分钟的项目陈述。
- 一旦接受待录取通知，就不能再填其他志愿，确认前想清楚。

**B. 没有资格，或者在递补名单上**

- 问学院还有没有递补机会。前面的人放弃资格，会按排名往下递补，但到10月中旬，这个窗口通常快关了。
- **同时一定要在10月15日到24日之间报名考研**，当作保底，逾期不能补报。如果之后真递补上并被推免录取，就按规定放弃统考，损失的只是报名费；但要是没报名，推免又落空，就要再等一年。
- 前约27% 说明你的课程基础不差。考研的话，目标定在本校或同层次学校的机械、控制、智能制造方向，现在开始全力复习，还有约10周。

**C. 已经拿到待录取通知**

确认录取（不要超过截止时间），然后去联系导师、提前进组，问问导师需要你补哪些基础。

## 第二部分：如果你是大三（2028届）

### 1. 先算清楚 前约27% 到底是什么水平

- 前约27% 约等于**前约27%**。
- 南理工教务处的推免实施办法里（我没能读到网页正文，只拿到了摘要，**请你自己核对原文和今年版本**）有这几条：
  - 申请门槛是前三年课程成绩排在学院或专业前30%；
  - 综合排名中课程成绩权重不低于85%，科研竞赛等加分合计不超过15%，其中文体和社会工作不超过5%；
  - 英语要求四级460或六级425；
  - 必修课和专业选修课不能挂科。
- 也就是说，你大概率**过了"能申请"的门槛，但能不能拿到名额，取决于实际名额数，以及你在综合成绩下排第几**。前30%只是报名门槛，不是录取线。
- 所以你现在就该去问：
  - 学院这个专业去年推了几个人？
  - 最后一个拿到资格的人排第几？
  - 加分细则里哪些项目和竞赛算分，算多少？

  你的处境会是下面三种之一：
  - 去年推到二十几名：你是"守住就行"；
  - 去年只推到十几名：你是"必须往前挤6到10名"；
  - 加分能拉开差距：加分就是你最快的提分手段。

### 2. 排名靠什么往前挤（优先级从高到低）

1. **大三这一年的课程成绩**。多数学校按前三年（或前五、六个学期）计算，大三专业课学分重、可提升空间大。占85%以上权重的部分，提升一点就很值钱。专业核心课冲高分，不要有任何一门挂科。
2. **把项目变成"可加分的成果"**（第三部分细讲）：竞赛获奖、授权专利、软件著作权、论文、大创项目结项。具体哪些算分、算几分，**以学院加分目录为准**，先拿到目录再决定投入，别做了才发现不算。
3. **六级550–599是明显优势**。远高于425的门槛，申请材料和英文面试都能用上。英语没必要再花时间，把精力放到前两项上。

### 3. 时间线（大致按往年规律）

| 时间 | 要做的事 |
|---|---|
| 2026年10月–12月 | 拿到学院推免细则、加分目录和去年名额；确定2到3个目标方向；挑一个最强的项目，开始往成果上推（竞赛、专利、软著） |
| 2027年1月–3月 | 期末冲成绩；写好简历和项目材料；开始看导师主页，整理目标学校清单 |
| 2027年4月–6月 | 夏令营报名高峰期（各校多在5–6月发通知），海投加精准投；给目标导师发邮件联系 |
| 2027年7月–8月 | 参加夏令营；没拿到优营的话，准备预推免 |
| 2027年9月 | 学校公布推免资格；推免系统开放，填志愿、复试、确认录取 |

### 4. 目标学校怎么分梯度

以 211 学校、前26%左右、有项目但未必有顶级奖项的背景来看，建议这样分配：

- **冲刺（2到4所）**：华五、华科、哈工大、同济、天大这类机械或智能制造强校中，竞争相对小一点的方向、专硕，或者校区分院。
- **主申（4到6所）**：东南大学、南航，以及其他机械、控制强的 985/211 学校；中科院各研究所的工程方向（比如机器人、自动化、先进制造类研究所）。
- **保底**：本校南理工（本校学生通常有优势，最好提前联系导师），加上一两所行业特色强校。
- 夏令营入营看"排名+学校层次"的硬门槛，前26%在名校入营会吃亏。所以**预推免和直接联系导师**对你更关键，项目经历能起作用的地方主要也在这两个环节。

## 第三部分：项目经历怎么用（大三、大四都适用）

项目可以在三个地方发挥作用，用法不一样。

### 1. 用来加分（影响能不能拿到资格）

- 逐个检查你的项目有没有带来这些东西：竞赛获奖、专利（授权的更值钱）、软著、论文、大创结项。有的话，对照学院加分细则，确认能不能计入、按什么等级计分。
- 还没转化成成果的项目，挑一个最成熟的，往这几个方向推：
  - 智能制造、机械类竞赛：中国大学生机械工程创新创意大赛（含智能制造相关赛道）、西门子杯中国智能制造挑战赛、全国大学生工程实践与创新能力大赛、挑战杯、中国国际大学生创新大赛、机器人类竞赛等；
  - 申请软著或实用新型专利。

  **哪些竞赛、什么级别能加分，以学院目录为准。**

### 2. 用来写简历和面试（影响能不能被录取）

每个项目按下面的结构准备一份1页的材料，外加一段3分钟口述：

- **背景和问题**：要解决什么实际问题，比如"产线工件表面缺陷人工检测效率低"。
- **你本人做了什么**：分清团队工作和你个人的贡献，面试官最常追问的就是这一点。
- **技术路线**：用了什么方法，为什么这么选，有没有考虑过别的方案。比如 PLC 控制逻辑、机器视觉检测、机械臂轨迹规划、数字孪生建模、MES 数据采集、生产调度优化等。
- **量化结果**：精度、效率、节拍、成本提升了多少，尽量给出数字。
- **反思**：有哪些不足，如果重做会怎么改进。

面试官会顺着项目问到底层原理，比如控制原理、机械设计、视觉算法、优化方法。项目涉及的基础知识要能讲清楚，**宁可讲深一个项目，不要浅浅地罗列五个**。

### 3. 用来定方向、联系导师（影响去哪里）

- 根据项目内容反推适合的研究方向：
  - 机器人与运动控制；
  - 机器视觉与智能检测；
  - 数字孪生与工业互联网；
  - 生产调度与智能优化；
  - 故障诊断与预测性维护。
- 找做这些方向的课题组，给导师发邮件时用两三句话说明"我做过 X 项目，和您 Y 方向的关联是 Z"，附上简历和成绩单。**方向对得上，比泛泛地说"对您的研究很感兴趣"有效得多。**
- 排名处在边缘的同学，靠"项目和课题组方向对口"打动导师，是最现实的突破口。

## 今天就能做的三件事

1. **确认身份和排名**：找辅导员或学院教学办，问清推免资格（大四）或者去年名额和排名口径（大三）。如果是大四，同时登录推免系统查看资格。
2. **大四赶截止时间**：推免志愿10月18日截止，确认通知10月20日截止；考研正式报名10月15日–24日，如果推免还没把握，一定要报名保底。
3. **整理项目清单**：把每个项目的成果、个人贡献和量化数据写下来，对照学院加分目录，标出哪些已经能加分、哪些还能转化。

你的条件（211工科、前26%、六级550–599、有智能制造项目）不算弱。问题不在"够不够好"，而在**有没有按时间节点把材料用对地方**。告诉我你是哪一届、学院去年推免到了第几名，我可以帮你把清单再细化一层。
