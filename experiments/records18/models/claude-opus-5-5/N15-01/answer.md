# 重庆大学法学 前约3%、六级550–599、无论文：法学推免准备重点

## 零、先看清现在所处的时间点

今天是 **2026年10月10日**。本届（2027级入学）推免已经进入全国推免服务系统阶段，下面几个日期决定了你"接下来这段时间"该做什么：

| 节点 | 时间 |
|---|---|
| 推免服务系统开放注册 | 9月18日（已过） |
| 系统开放填报志愿 | 9月21日 9:00 起（已过） |
| **志愿填报截止** | **10月18日** |
| **确认复试、待录取通知截止** | **10月20日** |
| 北大等校拟录取公示 | 10月20日前 |
| **2026年法考主观题** | **10月18日（周日）9:00–13:00，机考** |
| 2027考研预报名 | 10月9日–12日 |

（日期以研招网 yz.chsi.com.cn/tm 和司法部公告为准。）

大部分法学院的夏令营和预推免已经结束：北大法学院9月21日已经公布复试成绩，南大9月中旬公布复试名单，人大法硕7月就截止报名了。所以你的情况会落在下面三种之一，**准备重点完全不同**：

- **A. 你是本届推免生，还没有满意的 offer**：最重要。未来10天是"九推＋补录＋系统操作"的冲刺期，见第二部分。
- **B. 你是本届推免生，已经有 offer 或优秀营员资格**：重点是理性取舍、按时确认，以及入学前的准备，见第三部分。
- **C. 你其实是下一届（大三），2027年夏天才申请**：时间很充裕，按第四部分的长线方案准备，竞争力能明显提升。

先给结论：**你的硬条件（985法学专业前约3%、六级550–599）足够冲北大、清华、人大、法大和武大这一档。真正决定结果的是三件事：法学专业笔试和面试的基本功、能代表你研究能力的写作样本、找准方向后的申请策略。** 没有正式发表论文在法学本科生里很普遍，不是硬伤。

## 一、竞争力定位：你的优势和短板

| 维度 | 你的情况 | 评价 |
|---|---|---|
| 本科平台 | 重庆大学（985），法学院不属于传统"五院四系" | 中上。名校法学院看重 985 背景，但不会因此特别加分 |
| 排名 | 前约3%（约3%） | **核心优势**。北大法学院往年要求外校申请者在本年级前20%以内，重大法学院自己的门槛也是前20%优先。你远远高于这些线，进入顶尖院校的初审基本没有问题 |
| 英语 | 六级550–599 | 达标并略有优势。各校硬门槛多在425到480分（同济480）。但如果申请涉外法治、国际法方向或"涉外法治项目"，550–599不算亮点，最好补雅思或托福，或者在面试中展示法律英语能力 |
| 科研 | 主持法学大创，参与跨学科研究，无发表 | 中等偏上。主持人身份证明你有组织和独立研究的能力，跨学科经历是差异化卖点。不足在于**还没有形成能拿给老师看的成熟成果** |
| 短板 | 无论文；不确定有没有模拟法庭、竞赛或实习 | 法学推免最看重的是**笔试和面试中的专业功底**和**写作能力**，发表只是加分项 |

**院校分档（法学硕士或法律硕士（法学），仅供参考）**

- **冲刺**：北京大学、清华大学、中国人民大学、中国政法大学（直博和热门方向竞争更激烈）。
- **主申**：武汉大学、复旦大学、上海交通大学、浙江大学、南京大学、吉林大学、华东政法大学、中南财经政法大学、西南政法大学、厦门大学、中山大学、北京师范大学等。重大往届学生去武大、华政、法大、北师大、人大法硕的案例都有。
- **保底**：本校重大法学院、四川大学、山东大学、华中科技大学、同济大学、东南大学、北航、北理工、西南财大等（具体看方向）。

> 学位类型怎么选：**法学硕士（学硕）** 更适合想读博或做学术的人，名额少、竞争激烈；**法律硕士（法学）** 名额多，偏重实务，多为两年制，适合就业导向。还要注意，人大等校规定法学硕士和法律硕士推免只能选报一个。按你目前的背景，在顶尖院校"学硕冲刺＋法硕保底"是比较常见的组合策略。

## 二、情况 A：本届推免、还没有满意 offer（10月10日到20日的冲刺方案）

### 1. 今天到明天：盘点和止损
- 列一张表，写清楚：已经拿到的优秀营员或预录取（学校、学位类型、方向、确认截止时间）、候补位置、被拒的学校。
- 有候补的，**主动给招生办发邮件或打电话**，礼貌地询问候补排位和递补的可能性，同时表明"如果递补成功一定会接受"。法学院递补很常见，因为头部考生手里往往同时握着几个 offer。
- **一定要先确保本校的保底。** 如果本校愿意接收，问清楚确认截止时间，不要因为等外校而错过。

### 2. 系统操作：不能出错的规则
- 推免服务系统是唯一的官方渠道。夏令营或预推免拿到的"预录取"，**必须在系统里填志愿、确认复试、确认待录取以后才算数**。厦大等校明确提醒，每年都有人因为忘了系统确认而丢掉名额。
- 志愿提交后会**锁定48小时**。招生单位在48小时内拒绝，或者48小时后仍未发复试通知，志愿会自动解锁。所以**不要把志愿浪费在没有希望的学校上**，优先填已经确定会给你复试或待录取的学校。
- **确认待录取以后就不能再接受其他志愿**，也不能参加当年统考。确认前要核对清楚学位类型（学硕还是法硕）、方向、校区（例如北大法学院和北大国际法学院是两个独立的招生单位）、学制和学费。
- 每条通知都有回复时限，**每天至少登录系统两次**，同时打开短信和邮件提醒。

### 3. 九推和补录：主动去找机会
- 每天浏览目标法学院官网的"招生通知"栏和研究生院网站，再加上保研通知网一类的信息聚合平台和保研交流群。补录通知发得快、窗口短，常常只挂在学院官网上。
- 已经在细则中写明"如有计划余额将再行补录"的学校（比如华中科技大学法学院），可以重点关注。北航法学院、北理工法学院等名额较少的学院，九推阶段也可能放出余额。
- **积极联系**：给目标学院招生办写简短邮件，附上一页纸简历，说明你的排名（前约3%）、六级、大创主持经历和意向方向，询问是否还有余额。用词要克制、专业。
- 范围放宽到"主申"和"保底"档里的院校和方向。热门方向（民商法、经济法、知识产权）已经满额的，可以考虑同校相对冷门的方向（法律史、法理、环境资源法、国际法等）。你的排名在这类方向非常有竞争力，入学后在课程和研究上也有一定转向空间。

### 4. 面试临时突击：每天2到3小时
九推和补录多采用线上面试，时间短，问题集中在以下几类：
- **自我介绍**：中文1分钟版和3分钟版，英文1分钟版。按"排名、大创（研究问题、方法、结论）、跨学科研究、意向方向"的顺序讲。
- **专业基础**：法理（法的渊源、法律原则与规则、法律解释方法）、宪法（基本权利、合宪性审查）、民法（法律行为、代理、物权变动、侵权归责）、刑法（犯罪构成、正当防卫、共同犯罪）。要能清楚讲出概念，并举出一个案例。
- **方向问题**：意向方向的2到3个核心争议，以及近期的重要立法或司法解释动态（例如民营经济促进法、生态环境法典编纂、人工智能与数据治理立法讨论等，可以挑和你方向相关的准备）。
- **深挖大创**：研究问题从哪里来、文献综述的主要观点、你的创新点、研究不足、如果继续做会怎么改进。这是最容易拉开差距的地方，一定要能讲清楚"**我自己的观点是什么**"。
- **英文问答**：用英文介绍研究、解释一个法律概念（例如 the principle of good faith、proportionality），或者回答"为什么读研"。

### 5. 和法考主观题冲突怎么办
- 如果你今年已经通过法考客观题、报了主观题，**10月18日上午的主观题考试和推免冲刺时间重叠**。建议：面试优先，主观题保持基本复习节奏。考前一天和当天上午不要安排面试，提前和招生单位沟通面试时间。
- 如果没有报主观题，就忽略这一条。法考可以等研究生阶段再考，推免期间不必分心。

### 6. 兜底预案
- 考研预报名在10月9日到12日。如果到10月12日仍然完全没有 offer，可以先问清楚本校研究生院和相关政策（预报名统考后又确认推免会怎样处理），再决定要不要预报名作为保险。**一旦确认推免待录取，就不能再参加统考。**
- 实际上，以你的排名，只要**广撒网并接受本校或一档相近院校**，在10月20日前落定的概率很高。最忌讳的是"非顶尖不去"，结果两手空空。

## 三、情况 B：已经有 offer（或者落定以后）

1. **理性取舍**：手里有多个 offer 时，比较平台层级、学位类型（是否计划读博）、方向和导师资源、城市与就业地域（比如想去北京、上海、广深工作，还是留在西南）、学制和学费。按时确认，**及时放弃不去的名额**，这也是诚信问题，名额可以让给候补的人。
2. **联系导师**：法学院多数在入学前后才双选导师。可以先读潜在导师近三年的代表作，准备一封有内容的自荐邮件。
3. **把大创写成论文**：利用大四时间，把大创成果整理成一篇规范的学术论文（1.2万到2万字），作为毕业论文的基础，也可以投学生刊物或学术征文。研究生阶段这篇论文就是你的"第一篇"。
4. **法考**：大四可以报考。如果目标是实务（律所、法检），建议大四或研一拿下法考。
5. **英语和外语**：准备读博或走涉外方向的话，现在开始准备雅思或托福，或者开始学第二外语（德语、日语对民法和刑法研究很有用）。

## 四、情况 C：下一届申请者（2027年夏令营），长线准备方案

### 时间线
| 时间 | 重点 |
|---|---|
| 现在到2027年2月 | 稳住GPA排名；把大创和跨学科研究**写成论文**；确定方向；英语提分 |
| 2027年3月到5月 | 准备文书（个人陈述、研究计划、写作样本）；联系推荐人；开始系统复习专业课 |
| 2027年5月到7月 | 夏令营报名、入营、笔试和面试（人大法硕7月初就截止报名） |
| 2027年8月到9月 | 预推免（北大法学院8月底发通知，厦大、南大8月预报名） |
| 2027年9月下旬到10月20日 | 推免系统填报和确认 |

### 重点1：把"无发表"变成"有拿得出手的写作样本"
- 法学院老师最想看到的是**你能不能写出一篇像样的论文**，不是你有没有发表。北大推免要求提交个人陈述，以及两封副教授以上职称专家签名的推荐信，很多院校还要求提交学术论文或写作样本。
- 具体做法：以大创成果为基础，写一篇**问题明确、文献扎实、论证规范、注释符合《法学引注手册》**的论文（1万到1.5万字）。请大创指导老师至少修改两轮。
- 有余力的话再投稿：学生刊物、校级或全国性学术征文、学术会议论文。**获奖或入选会议**对法学本科生来说已经很有说服力。不必执着于核心期刊。
- 跨学科研究要讲清楚**你本人的贡献**。最好能从中拆出一个"法学视角"的子问题，单独写成短文。

### 重点2：确定方向，形成连贯的申请叙事
- 用"大创选题、跨学科经历、意向方向、研究计划"串成一条线。例如跨学科研究涉及工科或数据，可以往**数据法、人工智能法、知识产权、科技法、环境资源法**方向靠，这是重大的综合性优势，也是近年的热点方向。
- 研究计划写2到3页：研究问题、现有研究的不足、你打算怎么做、预期贡献。面试时老师会照着它提问。

### 重点3：专业课笔试和面试（权重最大）
- 北大法学院往年复试中笔试占60%、面试占40%；人大考核法理、宪法、民法、刑法的基本知识和运用能力。**笔试决定了很多人的成败**。
- 复习范围：法理、宪法、民法（总则、物权、合同、侵权）、刑法（总论和重点罪名），再加上意向方向的主干课。读一本权威教材，再配合经典论文。
- 练习论述题和案例分析：每周写一篇1500字左右的论述，限时作答。
- 结合法考复习：客观题的知识体系和推免笔试高度重合，可以一举两得。

### 重点4：英语
- 六级550–599已经达标。如果申请涉外法治项目、国际法方向或者打算读博，建议考雅思（7分以上）或托福（100分以上）。
- 准备英文自我介绍和研究介绍，熟悉常用的法律英语术语。

### 重点5：推荐信与其他加分项
- 推荐人：大创指导老师加上跨学科项目的老师（或者授课老师）。提前2个月沟通，给老师提供你的材料清单。
- 加分项（不是必须的）：模拟法庭或辩论赛（比如 Jessup、贸仲杯、理律杯）、法律诊所、法院检察院或律所实习、优秀学生荣誉等。

## 六、一句话总结

- **如果你在本届，还没有落定**：未来10天全力做好三件事：盯紧系统、主动争取九推和补录、准备面试。宁可"稳中求进"，不要空手而归。
- **如果已经落定**：把大创写成论文，再考下法考，为研究生阶段打好基础。
- **如果是下一届**：最重要的是**专业笔试和面试的基本功，再加上一篇高质量写作样本**。你的排名已经足以拿到顶尖院校的入场券，接下来要靠这两项真正赢下 offer。
