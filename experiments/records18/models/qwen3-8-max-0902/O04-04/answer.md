## 先说三个必须先校准的现实

**1. 美赛 S 奖不是奖。** MCM/ICM 档位是 `O > F > M > H > S`，S = Successful Participant，即"按时交了论文"。它在保研加分表和目标院校材料评审里基本不计分。你到 2026 年只剩 **2025、2026 两次**美赛机会，必须重打，目标 M 奖以上。大数赛省二同理——中等含金量，可加分但不是国奖。

**2. "92分"没有意义，排名才有。** 本周就去查上学期专业排名和学院的排名口径。经验区间：冲清华电子系需要**稳定在专业前 3%（最好前 1–2%）**；保住吉大推免资格（整体推免率约 15–20%，各院差异大）约需前 15–20%。这两个目标差距巨大，你得先知道自己在哪一侧。

**3. 大一上只是热身。** 推免看前 5–6 个学期，真正拉排名的是大二的模电、信号与系统、概率统计，和大三的通信原理、数字信号处理、电磁场。现在 92 分不是护身符。

**一票否决项守死**：不挂科、不重修、无处分、体测达标、六级过线。任何一条破了，全盘归零。

## 保研只有三条腿

| | 作用 | 目标 |
|---|---|---|
| **GPA/排名** | 决定**有没有资格** | 专业前 3% |

## GNN + 通信交叉路径

**地基（缺一后面就是硬啃）**：线代/矩阵论、概率统计、**凸优化**（Boyd 那本是这个方向的通用货币）、PyTorch。

**图学习主线**：Stanford **CS224W**（Leskovec，有公开课）+ Hamilton《Graph Representation Learning》（免费PDF）+ 手写复现 **GCN / GraphSAGE / GAT** + Wu 等人 IEEE TNNLS 2020 综述。工具用 PyTorch Geometric。

**落地选题（按上手难度）**：无线功率控制/资源分配 → 路由与流量工程 → RIS 相移设计 → 联邦学习的拓扑感知客户端选择 → 语义通信。

做功率控制这条线，**WMMSE（Shi et al., IEEE TSP 2011）是你必须自己实现的传统基线**，这是全领域的标尺。起点论文找 Shen / Razaviyayn / He 在 **IEEE JSAC 2021** 关于 GNN 做可扩展无线资源管理的工作及其 GLOBECOM 2019 前身。

本科第一篇产出现实可行的三种：复现+改进（换真实信道模型做 ablation）、交叉应用（GNN 用在尚未充分尝试的通信小问题）、或一篇结构清晰的中文综述——**最后这种门槛最低，但面试时"能讲清整个领域"的价值被严重低估**。

## 🔧 必须调整

### 1. 六级 500–549——**别再当短板攻**

旧目标"550+"，现在明确作废。清北各院系夏令营英语硬门槛历年基本是 **CET-6 ≥ 425**，500–549 已明确过线，不会成为初审被刷的理由。

**关键时序**：2026年6月六级考试，成绩 **8月中下旬**才出；清北夏令营 **6月底–7月中**已办完。**6月刷六级对夏令营完全无效**，只服务于9月预推免。想在夏令营前补英语证明，唯一路径是雅思/托福（出分快），但除非你同时有出国打算，**不值得为此单开战线**。

→ 动作：报名6月六级（免费保险，备考 ≤1小时/天），把省下的时间**全部转投英文口语面试**——这才是你英语能力里真正会影响结果、而500–549分完全测不出来的部分。

### 2. 竞赛这条线——**正式关闭**

夏令营之前（3–7月）**不存在任何能提升你竞争力的高价值竞赛**：

- 美赛 2026年1–2月已结束
- 数模国赛 2026年9月 → **在夏令营之后**
- 电子设计竞赛：**偶数年无全国赛**（2025是国赛年）
- 挑战杯：**奇数年国赛**（2025是国赛年）
- 互联网+：2026国赛在秋季 → 在夏令营之后

竞赛加分有上限，而你已有一作论文，边际收益为零、机会成本极高。旧规划"竞赛15%"配额全部转给套磁与面试。

### 3. 清华 vs 北大——在你这个**具体方向**上供给量差距很大

你的核心资产是**一作通信类论文**，兑换率差别极大：

| 单位 | 兑换率 | 说明 |
|---|---|---|
| **清华电子系（本部）** | ★★★★★ | 通信+AI交叉正是其强势方向，论文直接对口，GNN+无线资源管理有对口课题组。**唯一最优解。** |
| 清华自动化系 | ★★★★ | 网络化系统/智能控制/ML，对交叉背景友好 |
| 清华计算机系 | ★★★ | 可与CS科班（ACM+ML论文）同台；通信论文须重新包装成**方法论**贡献而非应用贡献 |
| 清华交叉信息院 | ★★ | 理论导向，除非论文偏理论 |
| **北大计算机/信科/电子学院** | ★★★(AI) / ★★(通信) | **北大本部无线通信课题组密度明显低于清华电子系和东南**。走北大等于转向更通用的AI |

**这是本次修订最需要你正视的一点**：如果"通信+AI交叉"是真实兴趣 → 清华电子系首选，北大应作为"愿意转向纯AI"时的备选，**而非并列目标**。如果学校品牌优先级更高、方向可妥协 → 北大合理，但面试要能自圆其说"为什么转"。

**两个选择都必须本月定下来**，因为它决定个人陈述怎么写、套磁发给谁、研究计划书围绕什么。海投式"都试试"会让每份材料都平庸——而平庸的材料在这一档等于没有材料。

### 4. 材料任务变了：从"证明有能力"到"讲一条连贯主线"

导师看你的材料时不再问"这人优不优秀"（前约1%+一作已回答），而是"**接下来五年想做什么，和我的方向接不接得上**"。你需要一句话主线：

> "我在 XX 问题上用 GNN 做了 XX，发现 XX 局限；接下来想解决 XX，方法上考虑 XX。"

这句话要**同时**出现在：个人陈述开头、英文自我介绍结尾、研究计划书问题陈述、面试被问"为什么来我们组"时的回答。四处一致，才叫有研究品味。

**6. 🔴 英文面试。** 清北本部普遍有英文自我介绍+英文问答。准备：3分钟英文自我介绍（背到自然）、**用英文完整讲述一作论文**（5分钟版+1分钟版）、高频问答（Why Tsinghua / Why PhD / research plan / 实验失败经历）、**专业术语英文发音**（interference, resource allocation, convex optimization, beamforming, channel state information, power control）。4月起每天30分钟，做至少3轮全英文 mock。

**7. 🟡 论文代码开源化。** 整理成干净的公开 GitHub 仓库（README + 一键复现 + 结果图），链接放进简历、个人陈述、套磁邮件。**这是面试前导师唯一能低成本验证你科研真实性的东西**，把"你说你做了X"变成"我能看到你做了X"。约2–3个周末。

**8. 🟡 不要硬追第二篇论文。** 3月到6月只有3个多月，从零启动并见刊不现实。正确做法：把一作论文的**扩展版**（更多实验、更强基线）挂 arXiv 或投出，材料里写 "under review"，效果接近已发表。面试里"一篇讲得极透彻的论文"完胜"两篇讲不清楚的论文"。
