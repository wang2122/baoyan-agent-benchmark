## 一、背景画像与总体定位

### 1.1 你的硬条件拆解

- **学校平台**：东北大学是 985 / 211 / 双一流高校，推免初审中属于"能过门槛、不被卡脖子"的层次；但它不是 BME 传统顶尖强校（第四轮学科评估 BME 未入 A 类），因此**学科平台更多要靠外校补强**。
- **专业排名 前约3% ≈ 前 约3%**：你的**最大硬通货**。除极少数只招前 1%—2% 的顶尖院系外，绝大多数 BME 院系（通常要求前 10%—30%）都对你敞开；西交生命学院前 25%、中山前 30%、电子科大医学院直博前 20% 等门槛，你都明显占优。
- **CET-6 500–549**：超过绝大多数项目的底线（常见 425 / 425–449 / 425–449 / 450–499）。但要注意：**顶尖院系同等排名下会更偏好 550+ 或有托福 / 雅思者**。500–549 够用但不算亮点；若时间允许，**再刷一次六级到 550+ 性价比很高**（电子科大医学院直博要求 CET-6 ≥ 480，你也已达标）。
- **医学影像 + 机器学习经历**：这是你**相对于纯生物 / 材料背景申请者最大的差异化优势**。当下 BME 最热的方向就是"医学影像 AI"与"医工交叉智能诊疗"，你的经历正好卡在风口。建议把它做成**可展示的作品集 / 论文 / 竞赛 / 专利**（哪怕是 preprint、挑战赛名次、课程设计），面试时能讲清"数据—模型—临床意义"闭环。

### 1.2 定位结论

- **冲刺层（4 个）**：上海交大、复旦、浙大、清华（深圳）。
- **稳妥层（5 个）**：东南、华科（稳中带冲）、川大、西交、电子科大。
- **稳保层（2 个）**：中山（深圳）、华南理工。
- **保底层（1 个）**：本校（东北大学）。**本校务必保留**，这是 100% 有书读的底线。
- **录取杠杆（重要）**：
  1. **优先直博**。上交、浙大生仪、华科生命、东南 BME、西交生命等多个项目在通知里明确"**优先接收申请直博的营员**"（华科生命学院 2025 年夏令营原文："本夏令营优先接收申请直博的营员学生"）。以你的排名 + 科研，**直博往往比硕士更容易被抢**。
  2. **提前联系导师**。医学影像 AI 方向的导师普遍"先到先得"，7—8 月就应发邮件 + 简历 + 作品集。
  3. **海投夏令营 + 精准预推免**。夏令营广撒网拿"优秀营员"，预推免再锁定 2—3 个最优解。

## 五、材料清单与面试准备（针对医学影像 AI 方向）

### 5.1 材料清单（按各校要求排序合并为一个 PDF）

1. 个人简历（1 页，突出排名、六级、影像 / ML 项目、论文 / 竞赛 / 专利）。

5. 医学影像 / 机器学习项目证明材料：代码仓库、论文 / preprint、竞赛证书、专利、导师推荐信。

### 5.2 面试准备重点

- **能讲透 1—2 个影像 AI 项目**：数据集来源与伦理、预处理、模型选型与对比、评价指标（Dice / AUC / 敏感度）、消融实验、临床意义与局限。
- **基础功底**：线性代数 / 概率统计 / 信号与系统 / 数字图像处理 / 深度学习基础；英文提问与文献朗读（西交明确"专家用英文提问"，电子科大复试英语占 100 分）。
