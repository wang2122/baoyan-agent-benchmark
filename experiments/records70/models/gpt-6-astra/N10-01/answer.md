你现在最先要做的是：**确认本校推免资格和当前还能申请的窗口，同时把一个最扎实的项目整理成申请材料。** 前约27%值得认真评估，但还不足以判断你“没机会”；六级550–599和项目经历都有用，关键在于用在正确的环节。

先提醒一个时间问题：按当前日期2026年10月9日理解，你参加的是2026年秋季申请、通常对应2027年入学的这一轮。学信网公布的本轮推免填报志愿截止日是10月18日，复试及待录取确认流程至10月20日；各院系可能更早截止或已完成接收，不能把全国系统截止日当作所有学校的报名截止日。因此，如果你正在参加这一轮，下面的“确认资格、查询接收机会”应当今天就做。[来源：学信网《推免生报名时间？》](https://kl.chsi.com.cn/wap/help/ckjjfa.action?id=av7ajr5pe5j32th6)

**第一步，先把“本校能否推荐”和“外校是否接收”分开判断。**

本校推荐决定你能否以推免生身份申请；接收院校再考察你的成绩、英语、专业基础和科研潜力。项目可能帮助你获得面试认可，但不能替代本校推免资格。研招网的申请指南也明确区分了推荐与接收两个环节。[来源：研招网推免申请指南](https://yzst.chsi.com.cn/yzzt/tmzn)

你的前约27%约为前约27%。现在最关键的未知信息是：这是学业成绩排名，还是已经计入科研、竞赛等因素的推免综合排名？83人是否就是本次名额分配对应的群体？这两点会直接改变判断。

今天联系学院教务老师或负责推免的辅导员，核实以下四件事，并以当年正式文件、公示和系统状态为依据：

- 你是否已进入推免资格名单，能否在推免服务系统查询到资格。
- 本专业或对应竞争单元的名额是多少，前约27%采用什么统计口径。
- 当年的综合评价公式、项目或竞赛成果认定办法，以及你的材料是否已被认定。
- 如果尚未获得资格，目前是否仍有正式的核查、申诉或递补程序，具体期限是什么。

可以直接这样问：“老师您好，我是智能制造工程专业学生，目前排名前约27%，想确认这个排名是否为推免最终采用的排名，以及本人今年的推免资格状态、专业名额和项目成果认定情况。”

我没有查到足以确认你所在专业本轮推荐名额及实施细则的官方材料，所以不会用全校保研率推算你能否入围，也不会把其他学院或往年的规则套给你。**若22就是最终综合名次，必须结合实际名额判断；若只是学业名次，则先按正式规则核算，不能预设项目一定能加分。**

如果已经有资格，马上把重心转到接收申请；如果资格尚不明确，核实与材料准备并行；如果学院确认本轮无法获得资格，就及时转向考研等替代路径，项目材料仍可用于后续复试。

**第二步，用一天整理一个代表项目，证明你具体能做什么。**

你目前只说“做过一些智能制造项目”，还无法判断这些经历的竞争力。优先挑你参与最深、证据最完整、最能讲清楚的一项，不必挑名字最大的一项。按下面六个问题写成一页项目说明：

| 要讲清楚的内容 | 应准备的信息 |
| --- | --- |
| 解决什么问题 | 实际场景、原有方法的不足、项目目标 |
| 你负责什么 | 独立完成的模块、与队友的分工 |
| 怎么实现 | 方法选择、软件或硬件、关键技术步骤 |
| 遇到什么困难 | 一个具体问题、排查过程、解决办法 |
| 效果如何 | 测试条件、对照方法、真实指标或完成的功能 |
| 有什么证据和不足 | 代码、实验记录、演示、报告，以及当前限制 |

例如，**如果你确实做过工业视觉缺陷检测**，简历可以采用这个框架：“面向［零件/缺陷类型］，负责［数据处理、模型改进或部署模块］；采用［方法］，在［测试条件］下取得［可核验结果］，完成［验证或演示］。”方括号只能填你的真实经历。没有量化结果，就写清测试范围和功能完成情况，不编造提升比例，也不把团队成果全部写成个人贡献。

项目材料至少形成三个版本：简历上的3—4行、一份简短展示材料、一个3分钟口头介绍。练习回答“为什么选这个方法”“你本人改了什么”“如何证明有效”“失败过什么”。这些回答比罗列技术名词更能体现能力。如果只是课程项目，也可以诚实写成课程项目，重点展示独立思考和验证过程。

**第三步，根据项目和课程基础选方向，再筛申请单位。**

智能制造工程可以连接多个研究方向，但要看你实际做过什么：

- 若以机械设计、制造工艺、设备集成为主，先看机械工程、智能制造相关团队。
- 若以PLC、运动控制、机器人系统为主，先看机电系统、机器人和控制相关团队。
- 若以工业视觉、设备故障诊断、制造数据分析为主，可看相应交叉团队，同时检查自己的编程、数学和算法基础。

这只是方向映射，不代表这些专业一定接受你的本科背景。不要因为专业名称里有“智能”，就默认跨申计算机或人工智能没有门槛。

对仍有接收机会的院系，建立一张小表，记录官方通知链接、截止时间、专业背景限制、排名和英语要求、研究方向及复试安排。优先查本校相关学院，再筛与你项目匹配的外校团队；本校也需要核实剩余接收机会，不能默认保底。若通知明确要求前20%，你的前约27%通常不满足该项要求，除非官方条款另有适用条件；若只写“成绩优秀”，则需要结合完整材料评估，不能自行判定出局或保证入围。

当前阶段，先致电目标院系公布的招生咨询电话，确认是否仍接收、是否需要额外报名，再及时提交。联系导师时，用一页简历和代表项目说明具体匹配点；导师的积极回复不能替代正式录取程序。

**第四步，英语保持即可，把主要精力放在材料和面试。**

六级550–599是值得展示的英语成绩。在没有目标项目更高硬性要求的情况下，我不建议你现在优先重刷六级；仍需逐项核对目标院系的英语条件。每天练习英文自我介绍、代表项目介绍，以及研究方向的常用术语，把分数转化为能交流、能阅读的表现。

专业课则围绕拟申请方向复习，优先补项目里实际用到、面试容易追问的基础，例如机械原理、控制基础、数学或编程。当前不宜为了“增加履历”仓促新开一个大项目，更值得把已有项目讲透。
