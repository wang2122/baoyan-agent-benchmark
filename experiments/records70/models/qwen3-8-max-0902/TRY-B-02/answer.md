## 〇、结论先行

1. **你的两个目标在很大程度上是同向的，不是冲突的。** 电网招聘有极强的地缘属性（省公司/地市公司偏好本地生源、本地院校，宣讲会与实习都在学校所在城市）。如果家在江苏或长三角，那么"离家近"和"进江苏电网"会同时指向南京的**东南大学**与**河海大学**。真正需要权衡的三难选择是：**院校层次（东南985）vs 录取确定性（河海211）vs 行业嫡系通道（华电）**。

2. **四校优先级（假设家在江苏/长三角、目标国网江苏）**：
   - **冲：东南大学** —— 985 + 南京同城 + 江苏电网/南瑞主场，是"目标匹配度 × 平台上限"的最高分。
   - **稳：河海大学** —— 211 + 南京同城 + 你被录取概率最高，进江苏电网完全够用，是**性价比最高的确定性选择**。
   - **特例：华北电力大学** —— 若你把"进电网"的确定性和行业内上限放在第一位、且能接受异地，华电的行业回报可能**高于**东南。但必须先核实录取在北京校部还是保定校区。
   - **慎：山东大学** —— 985平台好、电气学科扎实，但除非家在山东或明确愿意留山东就业，否则它与你的双目标匹配度**最低**。

3. **这不是四选一。** 夏令营与预推免阶段可以（也应该）同时申请 6–12 所，直到 2026 年 9 月下旬教育部推免系统开放、你确认"待录取"之前，所有 offer 都不冲突。**现在就把四校全报上，用结果来做选择，而不是用想象来做选择。**

4. **当前最大的风险不是"能不能上名校"，而是"本校推免资格"这一前置条件。** 排名 前约2% 使这个风险很低，但它是一票否决式的：拿不到资格，所有 offer 同时作废。**这件事必须在 2026 年 3–4 月内书面落实，不能拖到 9 月。**

- **短板**：本科院校电气学科平台有限；成果"在投/在审"意味着无法用硬指标证明科研能力；缺少目标院校的地缘人脉。

## 三、四校逐一分析：利弊与适配度

> 本节涉及的**学科评估等级、校区分布、招生目录、就业数据**均可能随年度变化，请以各校研究生院与学院官网 2026 年最新文件为准（详见第八节"需核实清单"）。教育部**第四轮**学科评估（2017 年公布）是目前最后一轮完整公开结果，**第五轮（2022 年完成）结果未正式对外公开**，本文引用第四轮数据仅作参考坐标。

### 3.1 东南大学（南京 · 985 / 双一流 A 类）

**基本情况**：电气工程学院，电气工程一级学科博士点、博士后科研流动站；第四轮学科评估电气工程 **B+** 梯队。校区需核实（东南有九龙湖、四牌楼、丁家桥等校区，电气学院传统上以四牌楼为主）。

**利（Pros）**

1. **同城 + 985，是"离家近"与"平台上限"唯一同时满足的选项**（若家在江苏）。研究生 2–3 年在家门口，生活成本与家庭支持最优，南京落户对研究生友好。
2. **江苏电网主场作战。** 国网江苏省电力公司在国网系统内规模与待遇长期位居前列。东南电气与江苏电网系统、江苏电科院、经研院的产学研联系紧密，宣讲会、实习、导师横向项目都在这个圈子里。**主场 = 信息差最小 + 人脉最近 + 面试机会最多。**
3. **南瑞集团（国网电力科学研究院）总部在南京。** 这是国网直属最大的产业单位，招聘量大、待遇在电力行业内属第一梯队，另有国电南自（南京）、中电电气、江苏电力设计院等。**在南京读书意味着你可以实习、可以做横向项目、可以被导师直接推荐**——这是外地院校学生几乎无法复制的优势，很多人选校时会漏掉这一条。
4. **985 身份的长期期权价值最高。** 若未来想跳出电网（转新能源企业、电力设备厂商、金融/咨询的能源组、公务员与选调生），985 的门槛通过率明显高于 211。江苏部分定向选调、部分省属国企"高层次人才引进"岗位对院校层次有硬性要求。
5. **综合性大学的跨学科资源**：电力电子、控制、信息、能源与环境、经济管理（电力市场方向）都可交叉，对你"电气相关研究"这种天然跨电力+运筹+数据的题目非常有利。

**弊（Cons）**

1. **录取难度最高。** 南京同城优质生源（南大、东南本校、南航、南理工、河海、南邮、南工大及江苏籍外省 985 学生）扎堆申请，你以双一流高校非优势专业前 2% 的身份参战，被刷风险真实存在。
2. **电气学科的"行业嫡系"程度不如华电。** B+ 梯队意味着学科声誉主要靠学校综合品牌与区域地位支撑，而非全国电力行业的"根正苗红"。若你的目标是**国网总部直属科研单位、中国电科院**这类岗位，华电的校友网络更厚。
3. **竞争激烈带来的内部压力**：985 电气研究生毕业进省公司本部/电科院的竞争者同样来自 985，"东南硕士"不再稀缺。
4. 若被调剂到非意向方向（如偏电机、偏高压试验）或遇到项目少的导师，进电网的单位层级可能不如预期——**导师选择的风险高于学校选择的风险**。

**对你的适配度**：**★★★★☆**（家在江苏时）/ ★★☆☆☆（家在山东、华北时）
**一句话**：目标匹配度最高的"上限之选"，值得作为第一志愿冲，但必须有保底。

### 3.2 华北电力大学（北京校部 / 保定校区 · 211 / 双一流学科建设高校）

**基本情况**：电力系统及其自动化为**国家重点学科**；第四轮学科评估电气工程 **A-**，是行业特色高校中的最高档次；拥有**新能源电力系统国家重点实验室**等国家级平台。北京校部与保定校区为**两个独立的招生单位（院校代码不同）**。

**利（Pros）**

1. **电网就业通道全国最强，这是华电不可替代的核心价值。** 华电被誉为电力行业的"黄埔军校"，在国家电网、南方电网历年校园招聘的录用人数中长期位居高校前列（具体名次与人数请查国网/南网官方公告与各校就业质量报告）。校友遍布国网/南网的省公司、地市公司、县公司、调度中心、电科院、经研院各层级。**这意味着：你未来在电网系统里，几乎在任何单位都能找到师兄师姐**——这在体制内是实打实的晋升与信息资源。
2. **学科实力与你的研究方向高度契合。** 华电在**电动汽车充放电与电网互动（V2G）、需求响应、新能源并网、电力市场、配电网优化**等方向有全国领先的团队和大量国网科技项目。你的"电气相关研究"论文在这里是**加分项而非孤立经历**，容易找到方向匹配的导师，也容易被导师认可。
3. **国家级平台 + 项目经费充足**，学生参与真实电网课题的机会多，简历上的"项目经历"更硬。
4. **招聘方认可度**：很多省公司的招聘宣讲与"目标院校清单"里，华电与 985 并列甚至单独列出。在**电力行业内**，华电的品牌溢价高于其综合排名。

**弊（Cons）**

1. **地理最远，与"离家近"直接冲突**（若家在江苏）。北京/保定到江苏距离最大，实习与家庭支持都不便。
2. **校区差异是重大不确定项，必须在报名前搞清楚。** 北京校部与保定校区在导师阵容、科研资源、就业辐射范围、生活条件上差别显著；两个校区招生代码独立，**报错了等于换了所学校**。同时需核实：毕业证/学位证是否标注校区、你想联系的导师在哪个校区、该校区是否招收你意向方向的硕士。
3. **非 985，跨行业退路窄。** 若未来想离开电力行业（互联网、金融、其他制造业央企），华电的综合品牌与校友网络在其他行业几乎无溢价；部分省份的**定向选调生、部分央企总部管培生、部分地方人才引进**明确要求 985 或"一流大学建设高校"，华电会被排除在外。
4. **北京的生活成本与落户现实**：研究生阶段基本无法解决北京户口；北京电网类岗位（国网总部、中国电科院、华北电力调度等）竞争极其激烈且名额少。**"在北京读书"不等于"在北京就业"**，多数华电毕业生流向各省电网。
5. **行业单一化的路径依赖风险**：华电的培养与就业生态高度围绕电力行业，一旦行业景气度或招聘政策变化（如国网缩减招聘规模、提高院校门槛），你的转换成本高于 985 毕业生。

**对你的适配度**：**★★★★★（若目标就是"稳稳进电网"，且能接受异地）** / ★★☆☆☆（若"离家近"是不可让步的硬约束）
**一句话**：单一目标（进电网）下的**期望值最高**选项；但它要求你用"3 年异地 + 院校层次降档 + 行业锁定"来交换。**这笔交易是否值得，完全取决于你对电网的执念强度。**

> **关键提示**：如果你选华电，请把"进电网"的目标细化到省份。华电在**华北、西北、东北**及多数省网的渗透力最强；在**江苏**，华电校友同样很多，但江苏本地院校（东南、河海）在省内宣讲会与实习上的便利性更强。

### 3.3 山东大学（济南 · 985 / 双一流 A 类）

**基本情况**：电气工程学院，位于济南（兴隆山校区），电气工程一级学科博士点、博士后流动站；第四轮学科评估电气工程 **B+** 梯队。注意山大济南、青岛、威海三地办学，**威海校区为独立招生代码**，勿误报。

**利（Pros）**

1. **985 平台 + 学科实力扎实**，与东南同属 B+ 梯队，综合性大学的跨学科资源（山大的控制科学与工程实力很强，对"电气相关研究"这类需要优化与控制理论的题目是加分项）良好。
2. **山东电网通道顺畅。** 国网山东省电力公司体量大、待遇在国网系统内属中上，山大是其核心生源校之一，省内校友网络密集。山东是新能源装机大省（光伏、风电），新型电力系统相关课题与岗位多。
3. **985 身份的长期期权价值**（选调、跨行业、央企总部）与东南相当。
4. 相比东南，**报名竞争的"南京同城扎堆效应"较弱**，对省外双一流高校生源的接受度较好，你的前 2% 排名在这里可能相对更突出。

**弊（Cons）**

1. **地缘错配是致命短板**（若家在江苏、目标江苏电网）。济南到江苏虽不算极远，但**读研城市与就业城市分离**意味着：失去本地实习机会、失去本地宣讲会信息、失去导师的本地人脉推荐。回江苏就业需要**跨省独自竞争**，而江苏电网的招聘现场会被东南、河海、南航、南理工的学生占满。
2. **"山大在山东强、出山东弱"的属性明显。** 山大的校友网络与雇主品牌存在清晰的地理衰减，在江苏电网系统内的影响力显著弱于东南。
3. **985 溢价你付了，但用不上。** 如果最终回江苏进电网，你为大平台的"跨行业期权"付出了 3 年异地的成本，而这个期权你并不打算行权。
4. 校区位置（兴隆山）相对偏，生活便利度一般。

**对你的适配度**：**★★★★☆（家在山东，或明确愿意留山东就业）** / **★★☆☆☆（家在江苏且目标江苏电网）**
**一句话**：**它是一所好学校，但可能不是"你的"好学校。** 只有当"家在山东"或"愿意把就业地改成山东"这两个前提之一成立时，山大才应该进入第一梯队；否则它是四校中与你双目标匹配度最低的一个——不是因为山大差，而是因为地缘价值无法兑现。

### 3.4 河海大学（南京 · 211 / 双一流学科建设高校）

**基本情况**：电气相关专业归属能源与电气学院（学院名称、所在校区务必核实——河海有南京西康路本部、江宁校区及常州校区，不同学院分布不同）。水利工程为 A+ 顶尖学科，电气工程学科的规模与评估层次明显低于华电、东南、山大。

**利（Pros）**

1. **录取确定性最高。** 同城 + 211 + 你前 2% 的排名 + 方向对口，这是四校中你**最可能拿到 offer** 的一所。在"推免资格尚未确认"的现实下，一个高确定性的优质保底极其宝贵。
2. **同城 = 与东南几乎相同的地缘红利。** 家在南京周边，实习、家庭支持、宣讲会、南瑞/江苏电科院的地理便利性**与东南基本一致**。**这是最容易被忽视的一点：在地缘与行业圈层上，河海与东南的差距远小于在院校层次上的差距。**
3. **进江苏电网完全够用。** 国网江苏每年招聘涵盖 985/211/行业特色院校，河海在江苏省内认可度高，其毕业生进入国网江苏各地市公司、以及国网新源（抽水蓄能）、发电集团、电力设计院的人数稳定。**对"进电网"这个目标，河海是达标线以上的选择，不是妥协。**
4. **学科特色与能源转型风口契合。** 河海的电气与水利水电、抽水蓄能、海上风电、综合能源系统深度交叉。这些正是"双碳"下电网与发电集团的重点投资领域（国网新源、三峡集团、五大发电集团、海上风电并网）。你的电气相关研究背景可以自然延伸到"综合能源系统/微网相关研究"。
5. **学院规模较小 → 人均导师资源可能更充裕**，学生与导师的关系更紧密，横向项目参与度高。
6. **申请成本最低**：同城，你可以直接去学院当面拜访导师、参加开放日，这是外地院校做不到的。

**弊（Cons）**

1. **院校层次是 211，不是 985。** 在以下场景会受限：部分省份**定向选调**（常限 985/"一流大学建设高校"）、部分央企总部与研究院的简历关、部分地方"高层次人才引进/购房补贴"政策的院校清单、以及未来若想跳出电力行业的品牌溢价。
2. **电气学科实力最弱。** 学科平台、国家级平台数量、行业话语权低于华电，也低于东南/山大。若目标是**中国电科院、国网总部直属科研单位、省公司电科院研究岗**，河海的竞争力弱于前三者。
3. **校内资源分配不占优。** 河海的王牌是水利、港航、环境，电气在学校层面的资源优先级不是最高。
4. **"稳妥"的心理陷阱**：如果东南、山大、华电你都拿到了 offer，却因为河海录取最早、压力最小而选择它，事后可能长期 regret。**保底的意义是让你敢于去冲，不是替代冲刺。**

**对你的适配度**：**★★★★★（作为"高确定性 + 地缘最优"的组合）**
**一句话**：**这是你名单里被低估的一个。** 它同时满足"离家近"和"进电网"两个目标，代价是放弃 985 身份与更高的学科平台。如果东南冲不上，河海不是退路，而是**在你既定目标下的合理最优解**。

### 4.2 关键洞察：院校层次的边际价值，取决于你要进电网的"哪一层"

这是很多人选校时想错的地方。电网不是一个均质的雇主：

| 目标单位 | 决定性因素 | 四校排序 |
|---|---|---|
| **国网总部 / 中国电科院 / 华北、华东分部 / 直属科研院** | 院校层次 + 学科嫡系 + 博士学历 | 华电 ≈ 东南 ≈ 山大 > 河海（且这些岗位多要求博士或 985 硕士） |
| **省公司本部（管理/技术岗）/ 省电科院 / 省经研院** | 院校层次（部分省份"高层次人才招聘"限 985/一流大学建设高校）+ 本地生源 + 笔试面试成绩 | 东南 ≈ 山大 > 华电 > 河海 |
| **国网产业单位（南瑞、许继、平高、南瑞研究院）/ 电力设计院** | 专业匹配 + 项目经历 + 学校地理位置 | **南瑞在南京 → 东南/河海有主场优势**；华电亦强 |
| **地市供电公司（运检、营销、调度、建设）** | 生源地（强偏好本地生源）+ 通过国网统一招聘考试 | 地缘 > 层次。**家在江苏 → 东南/河海最优；家在山东 → 山大最优** |
| **县公司 / 三新公司等基层单位** | 笔试面试成绩为主，院校层次影响小 | 四校差异很小，**不必为此牺牲其他目标** |
| **发电集团（华能/大唐/华电/国家能源/国家电投）、国网新源、三峡** | 专业匹配（水电、新能源、火电） | **河海在水电/抽蓄方向有独特优势**；华电强 |

**推论**：
- 如果你的目标是**省公司本部或电科院研究岗**，院校层次的权重最大 → **东南 > 山大 > 华电 > 河海**，且应考虑读博。
- 如果你的目标是**地市供电公司（回原籍）**，地缘与生源的权重最大 → 家在江苏则 **东南 ≈ 河海 > 华电 > 山大**。
- 如果你只要"稳稳进电网，哪个层级都行"，行业通道的权重最大 → **华电**期望值最高。

## 五、决策框架：请这样倒推

不要问"哪所学校好"，要按以下顺序问自己：

```
第1步：我家在哪个省？我未来 10 年想在哪个城市定居？
        ↓（若答"江苏"）
第2步：我想进电网的哪一类单位？（省公司本部 / 电科院 / 地市公司 / 南瑞等产业单位）
        ↓（若答"江苏地市公司 或 南瑞"）
第3步：地缘价值 → 南京读书（东南、河海）；
        院校层次 → 东南 > 河海；
        录取确定性 → 河海 > 东南。
        ↓
第4步：结论 = 冲东南，保河海，同时用华电做"行业内上限"的对冲。
        山大仅在"愿意改就业地为山东"时纳入。
```

### 三套典型情景下的推荐组合

| 情景 | 推荐组合（按志愿优先级） | 理由 |
|---|---|---|
| **A. 家在江苏 + 目标江苏电网（最可能）** | 冲：东南；稳：河海；对冲：华电（若愿异地）；备选：南航/南理工/中国矿大/合工大 | 地缘与目标完全同向；东南拿院校层次上限，河海拿确定性 |
| **B. 家在山东/华北 + 目标当地电网** | 冲：山大（若在山东）或华电（若在华北）；稳：华电/山大；备选：天津大学、西南交大 | 地缘反转，山大与华电升为第一梯队，东南/河海降为备选 |
| **C. "进电网"是唯一硬目标，城市可让步** | 首选：华电（务必核实校区）；并行：东南、山大、河海 | 华电的行业通道是四校中最强的单一变量 |

## 六、行动计划（2026年3月 → 2026年10月）

> 注意：你现在处于**大三下学期**（2027届），距离 2026 年 9 月的推免系统开放约 6 个月，距离各校夏令营报名截止约 2–3 个月。**时间够用，但不宽裕，3–4 月是关键窗口。**

### 阶段一：3月中 – 4月底（地基期）

| 优先级 | 事项 | 具体动作 |
|---|---|---|
| **P0** | **落实本校推免资格** | ① 向学院教务/辅导员索取《推荐免试攻读研究生工作办法》最新文件；② 核实：本学院/本专业的推免名额数、排名核算口径（前五学期还是前六学期）、竞赛与论文的加分细则及上限、一票否决条款（挂科、纪律处分、体质测试、四六级门槛）；③ 请老师按现行规则**书面或明确口头**测算你当前是否在名额内。**这是所有其他工作的前提。** |
| **P0** | 明确目标省份与单位类型 | 见第五节决策框架，写成一句话 |
| P1 | 整理论文材料 | 把在投论文改写为一份 **15 分钟可讲的技术报告**（问题背景 → 建模假设 → 目标函数与约束 → 求解算法 → 数据来源与算例 → 结果与创新点 → 局限与后续工作）。**面试考的是这个，不是"录用通知"。** |
| P1 | 建立导师清单 | 每校筛 5–10 位方向匹配导师（关键词：电气相关研究、能源系统优化、需求响应、配电网优化运行、电力市场、综合能源系统、微电网）。渠道：学院官网师资页 + CNKI/Web of Science 检索近 3 年论文 + 国家自然科学基金项目查询。**特别关注承担国网科技项目、南瑞/电科院横向课题的团队**——电气是强行业属性学科，导师的项目与人脉直接决定你能进哪个单位。 |
| P2 | 专业课复习 | 夏令营笔试常考：电路、电力系统分析（稳态/暂态）、电机学、电力电子技术、高电压技术、自动控制原理（因校而异）。按目标院校历年考核范围准备。 |
| P2 | 材料清单准备 | 中文简历（1页）、个人陈述、成绩单（教务处盖章，含专业排名证明）、2 封副教授及以上推荐信、获奖证书扫描件、英语等级证书、论文手稿/技术报告、专利受理通知书。 |

### 阶段二：5月 – 6月（申请期）

- **密切关注**各校研究生院与学院官网的夏令营通知（一般 5 月中下旬发布，6 月中下旬截止）。**四校全部申请**，并额外申请 4–8 所分散风险（见第七节）。
- **发出套磁邮件**（4–5 月开始）。要点见第七节 7.3。
- 若家在江苏：**利用同城优势，主动申请到东南、河海当面拜访导师或参加学院开放日**。一次面对面交流的效果通常胜过十封邮件。
- 准备中英文自我介绍（各 1–3 分钟）、"为什么选我们学校/这个方向/这位导师"的标准回答。

### 阶段三：7月 – 8月（考核期）

- 参加夏令营（注意**多校撞期**是常态，需提前排定优先级并做取舍）。
- 考核形式通常为：专业笔试 + 综合面试 + 英语面试 + 科研经历汇报。
- 拿到"优秀营员"后**务必确认其含义**：是"直接拟录取/免复试"，还是"同等条件下优先"？前者接近确定，后者仍需在 9 月系统中竞争。**要求学院给出书面或明确的说明。**
- 未拿到理想 offer 的，8 月准备 9 月**预推免**（多数 985/211 在 9 月还有一轮，且名额常比夏令营更宽松）。

### 阶段四：9月 – 10月（决胜期）

- **本校推免资格公示与确认**（9 月上中旬）→ 拿到资格，才具备被录取的法律前提。
- **教育部推免服务系统**开放（一般 9 月下旬，历年多在 9 月 28 日前后）：
  - 每人可**同时填报 3 个平行志愿**（不分先后），每个志愿由招生单位在 **48 小时**内回复；
  - 收到"复试通知"→ 确认参加 → 收到"待录取通知"→ **确认待录取后即为最终录取，不可更改**；
  - 志愿锁定期间不能修改，因此**填报顺序与时机是博弈**：不要在第一轮就把 3 个志愿全填成冲的学校，至少留 1 个已给过"优营/预录取"承诺的保底。
- 10 月中下旬系统关闭，流程结束。

### 并行不悖的 Plan B（务必启动，不要侥幸）

| 风险 | 应对 |
|---|---|
| 万一拿不到推免资格 | **考研**：12 月下旬全国统考。目标可仍为东南/山大/华电/河海，但注意华电与东南电气的考研竞争极其激烈（分数线高、报录比低），需从 3 月就开始系统复习数学一 + 英语一 + 专业课。 |
| 万一推免全部落空 | **秋招（2026年9–12月）**：国网第一批统一招聘通常在 11–12 月。**本科学历同样可以进电网**（多为地市/县公司），NUIST 在国网江苏有稳定生源。这是一条真实可行的退路。 |
| 万一只有保底 offer | 参考第四节的"单位分层表"：地市供电公司层面对院校层次不敏感，河海足够。 |

## 七、材料与申请策略

### 7.1 论文与专利：如何呈现（重要，别踩坑）

**红线：绝不能把"在投"写成"已发表"、把"已受理"写成"已授权"。** 夏令营面试老师会当场追问投稿期刊、审稿状态、DOI；部分院校要求提交录用通知或检索证明原件；推免系统填报的成果也可能被本科院校与接收院校双向核查。**一旦被发现不实，后果是从"没录取"升级为"取消资格 + 记录污点"，这个风险与收益完全不对称。**

**正确做法：**

| 材料 | 规范写法 | 加分动作 |
|---|---|---|
| 在投论文 | 成果栏写"**在投 / Under Review**"，注明目标期刊或会议名称与其级别（如 SCI 一区/EI/中文核心），并在科研经历栏详细描述技术内容 | 面试时主动提交一份技术报告，把"未发表"转化为"可展示、可追问、可讨论"的科研能力证明 |
| 专利 | 写"**已受理**"+ 受理号 + 类型（发明专利 / 实用新型），发明受理含金量高于实用新型 | 说明专利解决的具体技术问题与论文的关系 |
| 竞赛 | 只保留最相关的 2–3 项，标注**全称 + 级别（国家级/省级）+ 奖项等级 + 个人排名/角色** | 突出与电气、控制、能源、建模相关的奖项 |

**面试时你的论文会被深挖，请提前准备好这些问题的答案：**
- 研究的具体问题是什么？为什么它重要（政策与工程背景）？
- 优化模型的**决策变量、目标函数、约束条件**分别是什么？
- 求解方法：MILP / 启发式（遗传算法、粒子群）/ 强化学习 / 其他？为什么选它？与对比方法的优劣？
- 数据来源与算例规模？结果的可信度如何验证？
- **电气研究与电网的耦合效应**：负荷峰谷、变压器负载率、电压偏差、网损；电网互动的影响；不确定性（运行状态、时序、边界条件）如何建模？
- 你的**创新点是什么？局限性是什么？如果给你 3 年读研，你想怎么把它做下去？**

> **政策背景可作为开场亮点**：国家发展改革委等部门曾印发关于加强新能源汽车与电网融合互动（车网互动）的实施意见，提出到 2030 年基本建成车网互动技术标准体系、新能源汽车充电设施具备千万千瓦级调节能力的目标（**文件名称、发布时间与具体指标请以官方发布为准**）。引用它能让导师立刻明白你的方向有国家级需求支撑——但**务必核实后再说，说错政策比不说更糟**。

### 7.2 个人简历的排序建议

```
1. 教育背景 + 专业排名（前约2%，前 约2%）+ 核心课程成绩（电路、电力系统、电机学、电力电子、自控原理）
2. 英语（CET-6 550–599 / CET-4 600–649）
3. 科研经历（电气相关研究项目：问题 → 方法 → 你的贡献 → 结果；论文标注"在投"）
4. 竞赛获奖（精选 2–3 项，标级别）
5. 专利（已受理，标类型与受理号）
6. 实践/学生工作（1–2 行，不要占篇幅）
7. 技能（MATLAB/Simulink、Python、CPLEX/Gurobi/YALMIP、PSCAD/ETAP、LaTeX）—— 电气导师很看重工具链
```

### 7.3 套磁邮件要点

- **标题**：`[推免咨询] 姓名-南京信息工程大学-电气工程及其自动化-专业排名前约2%-意向XX方向硕士`
- **正文**：150–300 字。① 一句话自我介绍（学校+排名+英语）；② 2–3 句话说明你的电气相关研究做了什么、用了什么方法；③ **1–2 句话说明为什么是这位导师**（引用其近期某篇论文或某个具体项目，证明你不是群发）；④ 询问该年度是否有学硕/专硕/直博招生名额，是否方便进一步交流。
- **附件**：简历（1页 PDF）、成绩单、论文手稿或技术报告、代表性获奖证书。**不要压缩成一堆散图。**
- **禁忌**：一封邮件抄送多位导师（同校尤其致命）；把"论文已发表"写进去；通篇谈"我想进电网"而不谈研究兴趣（导师要的是能干活的学生，不是求职咨询）。
- **节奏**：4 月中旬首轮发出，7 天无回复可换角度补发 1 次，之后转向该团队的其他老师。**优先联系有国网科技项目、年轻（副教授/新晋博导，急需学生）、且方向与你论文重合度高的导师。**

## 十、最后的三句话

1. **先解决"资格"，再谈"择校"。** 3–4 月把本校推免名额的书面测算拿到手，同时启动考研复习作为 Plan B。排名 前约2% 让你大概率无忧，但"大概率"不能替代"确认"。
2. **四校全报，外加 4–8 所，用 offer 来做决定。** 夏令营阶段没有排他性，唯一的排他点在 9 月下旬推免系统的"确认待录取"。现在的任务是把选择权做厚，而不是提前收窄。
3. **在你的双目标下，"南京"这个变量价值极高。** 若家在江苏，东南与河海共享同一份地缘红利（江苏电网、南瑞、江苏电科院、实习与宣讲会），差别主要在 985 身份与录取概率；华电用行业嫡系换取异地与院校层次；山大是好学校，但地缘红利无法在你的目标省份兑现。**先确定"想进哪个省的电网"，答案会自己浮现。**
