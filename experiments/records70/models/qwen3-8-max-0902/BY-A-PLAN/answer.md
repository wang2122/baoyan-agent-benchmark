## 〇、一页纸结论（先记住这四句话）

1. **先确认资格，再谈努力。** 中外合作办学专业在部分高校不参与推免、或名额单列、或与普通班合并排名，规则差异极大。这是"1 和 0"的问题，必须在两周内查清，否则后面所有计划都建立在沙地上。
2. **排名是命门，不是竞赛。** 绝大多数学院的推免综合成绩里，学业成绩（学分绩点/排名）权重占七成到九成。竞赛、论文、大创是"加分项和敲门砖"，能把你的排名往前推几个身位、能让你在夏令营面试里有话说，但**替代不了 GPA**。一门课挂科或从 90 掉到 75，损失往往大于一个省级竞赛奖的收益。
3. **科研要趁早进，产出要真实。** 大二下进实验室、大三上拿下大创立项和至少一项校级以上竞赛奖、大三下把数据和材料整理成夏令营弹药——这个节奏刚好卡在推免评价的截止线上。发明专利授权周期 2—3 年，从现在开始都未必赶得上，所以**不要为"加分"去灌水论文和买专利**，那是负收益。
4. **同时准备 Plan B。** 中外合作项目的天然优势是英文授课和外方资源，出国申请是你的第二条腿；考研是第三条腿；研究生支教团、"特殊学术专长"通道是第四条腿。两年里不要把所有筹码押在一条路上，但也**不要三条路同时平均用力**——主线始终是学业排名。

**接下来两周只做三件事**：① 拿到并通读三份文件（培养方案、学院推免实施细则、学校学科竞赛目录）；② 找三个人问清口径（辅导员、教务秘书、学业导师/班主任）；③ 手算自己当前的学分绩点和专业排名，算出与目标排名的差距。

## 一、第 0 步：资格与规则核查（2024 年 10 月，两周内完成）

### 1.1 最高优先级：中外合作办学专业到底能不能推免

现实中存在三种情形，你必须确认自己属于哪一种，因为三种情形的策略完全不同：

| 情形 | 典型规则 | 你该怎么办 |
|---|---|---|
| **A. 可以推免，与普通班合并排名** | 全专业（含中外项目）统一按学分绩点+综测排序，共用一个名额池 | 注意外方引进课程的成绩转换方式是否吃亏；排名竞争面更大，需要更靠前 |
| **B. 可以推免，但名额单列/单独排名** | 中外项目内部单独排名，单独下达 1—3 个名额（常见于规模较大的项目） | 你的竞争对手是同班同学，**班内前 1—2 名**是唯一目标；同时要清楚名额极少意味着容错为零 |
| **C. 不参与推免（或原则上不参与）** | 部分高校在推免办法中明确排除中外合作办学专业学生，或规定"按教育部及学校有关规定执行"而实际无名额 | 立刻转向：① 查清能否转专业（见 9.4）；② 全力准备出国申请（你的项目优势所在）；③ 大三下启动考研准备 |

**核查路径**（按优先级）：
1. 华东地区一所211高校研究生院官网 → "通知公告"/"推免工作"栏目 → 下载**最近一年**（通常是 2024 年 9 月前后发布的、面向 2025 届毕业生的）《华东地区一所211高校推荐优秀应届本科毕业生免试攻读研究生工作实施办法》及《本科学院推荐免试硕士研究生工作实施细则》。搜关键词"中外合作办学""推免名额""推荐条件"。
2. 本科学院官网 → 通知公告 → 同上；并找《本科学院本科生综合素质测评办法》。
3. 直接去学院教务办公室当面问（比邮件快，比电话准），并同时问辅导员。
4. 找**上一届中外项目的学长学姐**（大三、大四，或已毕业读研的）复盘：他们那届有没有人拿到推免？几个人？怎么排的？——这是最真实的一手信息，价值高于任何网络帖子。

> ⚠️ 一个常见误判：很多中外合作项目学生默认"反正我要出国"，从而在大二放松 GPA。即使你最后走出国路线，GPA 也是最重要的申请材料；即使你走推免路线，GPA 也是决定性因素。**两条路的前 90% 努力是重合的**，所以现在不需要纠结选哪条，只需要把成绩做到最好。

### 1.2 培养模式：是否必须出国？（这一条会颠覆你的两年计划）

中外合作办学项目常见"4+0"（全程国内）、"3+1"、"2+2"（后两年出国）等模式。请务必确认：

- 本项目是哪种模式？**后两年是否必须赴外方院校就读**？能否申请全程在国内完成？
- 若必须出国：大三/大四在境外就读会直接导致——无法参加国内夏令营（2026 年 7—8 月）、无法参加学院推免面试与公示环节、境外成绩单与国内排名口径不一致、部分课程学分认定滞后。**这种情况下"本校推免资格"实际上很难走通**，应尽早把主线切换为境外读研申请（用外方学位+外方导师推荐信申请海外/港新硕士或博士）。
- 若是"4+0"或可选择留在国内：本方案完全适用。
- 外方学位的授予条件（如外方课程最低分、语言要求）是否与国内毕业证/学位证绑定？影响推免资格审查吗？

## 二、推免到底比什么：拆解评价体系

### 2.1 通行的计算方式

国内高校（含本校各学院）普遍采用如下结构，**具体权重以学院当年细则为准**：

```
推免综合成绩 = 学业成绩得分 × W1  +  综合素质/创新能力得分 × W2
其中 W1 通常在 70%—90%，W2 通常在 10%—30%
学业成绩 = 前六学期（或前五学期）必修课/全部课程加权平均学分绩点，换算为百分制后排名
综合素质 = 学科竞赛获奖 + 科研成果（论文/专利/项目）+ 学生工作 + 志愿服务 + 荣誉表彰 + 文体竞赛
```

**门槛条件（先过筛，再排序）**：思想政治与品行考核合格、无违纪处分、无考试作弊、无不及格课程（部分学院规定"无补考/重修记录"）、外语达到规定水平、体质健康测试达标、应届毕业生身份。

### 2.2 各要素的"性价比"排序（大二学生视角）

| 要素 | 对最终结果的影响 | 投入产出比 | 你现在的动作 |
|---|---|---|---|
| **专业课+数理基础课 GPA** | 决定性（占 70—90%） | ★★★★★ | 每学期都当高三过，尤其高数、大物、物化、材科基、电化学 |
| **专业排名（相对位置）** | 决定性（名额按排名切） | ★★★★★ | 搞清楚排名口径，锁定"高学分课"重点突破 |
| **英语（四六级/雅思托福）** | 门槛+面试加分 | ★★★★★ | 大二上过大四、大二下过大六，目标 550—600+ |
| **大创项目（国家级/省级立项）** | 中高（综测加分+面试核心素材） | ★★★★☆ | 大二下申报，大三上立项，大三下—大四结题 |
| **对口学科竞赛（节能减排、创新大赛、挑战杯、数模）** | 中（加分有上限，但面试极有说服力） | ★★★★☆ | 只打学校竞赛目录内、且与能源材料对口的 3—4 项 |
| **进实验室+真实科研能力** | 中（不直接加分，但决定夏令营/直博面试成败） | ★★★★★ | 大二下进组，固定每周 ≥8 小时 |
| **SCI 论文（本科阶段）** | 高（若有，且合规） | ★★☆☆☆ | 顺其自然，作为科研的副产品；**绝不花钱发水刊** |
| **发明专利** | 低（授权周期赶不上） | ★☆☆☆☆ | 若有真实成果可由导师牵头申请，不要单独为加分去做 |
| **学生工作（班委/学生会/社团）** | 低—中（综测少量加分） | ★★☆☆☆ | 最多担任一个职务，大二下可退，避免占用科研时间 |
| **志愿服务时长** | 低（部分学院有最低要求） | ★★★☆☆ | 用零散时间凑够学院要求的时长即可，不必刷 |
| **文体类比赛** | 低 | ★☆☆☆☆ | 有兴趣可参加，不作为投入重点 |

### 2.3 红线（一票否决项，任何时候都不要碰）

1. **考试作弊/违纪** → 直接丧失资格，且记入档案，影响出国与就业。
2. **课程不及格** → 多数学院规定推免时不得有未通过的必修/限选课程；有的还看是否有补考重修记录。
3. **学术不端** → 论文代写、数据造假、竞赛挂名、AI 代写参赛文本。夏令营面试时教授会追问细节，答不上来比没有成果更糟。
4. **超期未确认待录取** → 拿到资格却在推免服务系统开放期间没完成志愿填报/确认，等于作废。
5. **体质测试不达标 / 处分未解除** → 形式审查阶段被刷。

## 三、学业成绩：占大头的部分怎么打

### 3.1 先把"排名口径"问清楚（这一步能省你半年瞎努力）

同样一份成绩单，在不同口径下排名可能差十几名。必须确认：

- 计算范围：**必修课**还是**全部课程**？公选课/通识课/体育课计不计入？
- 外方引进课程（英文授课）计入吗？成绩是等级制（A/B/C）还是百分制？如何换算成国内绩点？**换算规则会不会让你吃亏**（比如 A- 换算成 85 而普通班同学轻松拿 92）？
- 加权方式：按学分加权平均，还是按课程门数平均？绩点制是 4.0 制还是 5.0 制？
- 时间范围：前六学期全部计入，还是只算到推免当年 8 月 31 日前已出成绩的课程？
- 重修课程按哪个分数计（原分/最高分/标注"重修"）？
- 排名基数：中外项目是否单独成一个排名池？

**行动**：拿到口径后，用 Excel 建一张"绩点跟踪表"，把已修课程全部录入，算出当前绩点与排名；再列出未来四个学期的所有课程与学分，**标注出"高学分+高难度"的课**（这些课一门顶三门，是你必须优先攻占的高地）。

### 3.2 新能源材料与器件专业的课程地图与优先级

（课程名以你的培养方案为准，以下是该专业的通用主干）

| 类别 | 典型课程 | 优先级 | 说明 |
|---|---|---|---|
| **数理基础（大二）** | 高等数学（下）、线性代数、概率论与数理统计、大学物理、大学物理实验、复变函数/数学物理方法 | ★★★★★ | 学分高、拉分大，也是考研与科研的底层能力。数学物理方法对后续固体物理、半导体物理至关重要 |
| **化学与材料基础（大二—大三）** | 无机化学、有机化学、分析化学、**物理化学**、**材料科学基础**、材料物理化学、固体物理、结构化学 | ★★★★★ | 物理化学与材料科学基础是本专业的"两大命门"，挂科重灾区，也是研究生面试必问 |
| **专业核心（大三）** | **电化学原理/电化学测量方法**、储能材料与技术、锂离子电池原理与技术、太阳能电池原理与工艺、材料现代分析测试方法（XRD/SEM/TEM/XPS/AFM）、材料制备与合成技术、半导体物理与器件、新能源材料导论 | ★★★★★ | 直接决定你在实验室能不能干活、夏令营面试能不能对话 |
| **计算与工具** | C 语言/Python 程序设计、材料计算（第一性原理/分子动力学）、工程制图、数据处理与Origin | ★★★★☆ | **强烈建议主动补 Python + 数据可视化**，这是本科生在课题组里最快建立不可替代性的技能 |
| **能源与动力类（视培养方案）** | 工程热力学、传热学、流体力学、能源转换与利用、氢能与燃料电池 | ★★★★☆ | 若你的方向偏储能/热管理/氢能，这几门要学好 |
| **外语与通识** | 大学英语、学术英语（外方课程）、思政类、体育、通识选修 | ★★★★☆ | 中外项目的英语课要保持高分（既是 GPA 也是你的差异化优势）；思政课别轻视，学分不低且是"送分题"，投入少回报稳 |

### 3.3 高分方法论（可操作，不讲鸡汤）

1. **第一节课就要拿到"评分构成"**：平时分/期中/期末/实验报告各占比多少，是否有考勤、课堂测验、小组汇报。把构成写进跟踪表，**平时分是免费的 20—30 分**，靠出勤+作业+提问就能拿满，很多同学的排名就是被平时分吃掉的。
2. **往年题与老师划的重点**：向学长学姐、课程群、学院资料库要历年试卷与作业题。大学期末考试的重复率通常不低，这是合规的高效复习方式。
3. **作业与实验报告当成作品写**：实验报告规范、图表专业（Origin/Python 出图，不要手绘截图），既拿高分，也顺带练了科研基本功。
4. **组队学习，但独立作答**：找 3—5 个同样想保研的同学组成学习小组，每周固定一次答疑互讲（费曼学习法），考前一起做往年卷。
5. **把"预习—听课—当天复盘—周末总结—考前真题"变成固定流程**：当天 20 分钟复盘的效率远高于期末 3 小时补。
6. **数学/物理/物化不要靠刷题海**：先建立体系（每章画一张知识地图），再做题；错题本记录"错因"而不是"错题"。
7. **英语授课课程**：提前把课件术语表整理出来（如 anode/cathode/electrolyte/specific capacity/Coulombic efficiency），中英对照，既应付考试又为读文献铺路。
8. **考前 3 周启动**：排出每门课的复习时间表，按学分权重分配时间，不要平均用力。

### 3.4 中外合作项目的特殊注意

- **英文授课是杠杆不是负担**：你能直接读英文教材和 SCI 原文，这在进实验室和夏令营面试时是明显优势。主动把它写进个人陈述。
- **成绩转换要吃透**：若外方成绩为等级制，问清转换表；必要时请教务出具"专业排名证明"时说明口径。
- **两套成绩单**：出国申请需要外方成绩单/学位证明，推免需要中方成绩单+排名证明。从大二起就分别归档，避免大四手忙脚乱。
- **不要为了刷高 GPA 去选"水课"堆学分**：如果排名按加权绩点算，低学分水课影响很小；如果按绩点平均算，则要谨慎。**这又回到 3.1：口径决定策略。**

## 四、科研训练：从"进实验室"到"有产出"

### 4.1 方向选择：先广后窄

本科学院/新能源材料方向常见的课题组主题（以学院官网师资页为准）：

- **二次电池**：锂离子电池、钠离子电池、固态电池、锂硫电池、硅基负极、高镍/富锂正极、电解液与界面（SEI/CEI）
- **光伏**：钙钛矿太阳能电池、硅基电池、有机光伏、叠层器件、稳定性与封装
- **电催化与氢能**：电解水制氢（OER/HER）、燃料电池、CO₂ 电催化还原、非贵金属催化剂
- **储能与热管理**：超级电容器、相变储热、电池热管理、储氢材料
- **材料计算与 AI**：第一性原理计算（VASP）、机器学习势函数、电池材料筛选、寿命预测
- **器件与工程**：柔性电子、传感、电池 PACK、系统集成与能源经济

**选择原则（三条）**：
1. **与你未来的兴趣/读研方向大致一致**——夏令营和面试会被追问"你为什么选这个方向"。
2. **课题组有明确的本科生培养习惯**——有的老师不愿带本科生，有的老师每年带好几个并署名论文。查方法：看该组近三年发表论文的**作者列表里有没有本科生名字**、看课题组主页有没有"本科生/毕业设计"栏目、问带过你的学长学姐。
3. **课题组的"平台条件"匹配你的能力增长曲线**——大二更适合进入有明确分工、有师兄师姐带的大组；如果你动手能力强、想要独立课题，小而精的组更合适。

### 4.2 如何找导师（这是可以标准化的动作）

**渠道**：① 学院师资主页（看研究方向、近三年论文、承担项目）；② 你正在上的专业课老师（最自然的入口，课上表现好→课后请教→提出进组）；③ 学业导师/班主任；④ 学长学姐引荐（成功率最高）；⑤ 学院的本科生科研计划（如大创、学校层面的本科生科研见习进修类资助计划——华东地区一所211高校参与李政道先生发起的"䇹政中国大学生见习进修计划"，校内通常称䇹政基金/䇹政学者，具体以当年申报通知为准）。

**邮件模板**（发给意向导师，简洁、有准备、不索取）：

学号XXXXXX。我在您的《XXX》课程中取得XX分/我在学院官网读到您课题组关于

### 4.3 实验室成长阶梯（四级，每级 3—6 个月）

| 阶段 | 时间 | 目标 | 具体动作 |
|---|---|---|---|
| **L1 熟悉期** | 大二下前 2—3 个月 | 安全规范+基础操作，让师兄师姐愿意带你 | 通过实验室安全培训与考核；学会称量、配液、手套箱/管式炉使用规范、废液处理；学会扣式电池组装或薄膜制备的基础流程；**每次实验写完整记录**（日期、条件、现象、数据、结论、下次改进） |
| **L2 上手期** | 大二下后半—暑假 | 能独立完成一条完整实验链 | 独立制备样品→组装器件→电化学/结构表征→数据处理→作图；掌握 XRD、SEM、CV、EIS、充放电曲线的基本解析；能看懂组会 PPT 并提问 |
| **L3 产出期** | 大三上—大三下 | 有一个自己的小课题，能讲清"为什么做、怎么做、结果说明什么" | 承担大创项目或导师课题的子任务；每周组会汇报；完成 2—3 组系统性对比实验；写成论文/竞赛作品/专利初稿 |
| **L4 表达期** | 大三下—大四上 | 能把科研讲给外校教授听 | 准备 3 分钟/10 分钟两个版本的科研汇报；能回答"你这个工作的创新点在哪""为什么不用XX方法""数据误差来源是什么"；准备英文口头介绍 |

> **关键提醒**：本科生在课题组最容易犯的错误是"只做不说"。你的组会汇报质量、提问质量，直接决定老师会不会在大三下给你写一封有内容的推荐信。**推荐信里"该生独立完成……"和"该生参与……"是天壤之别。**

### 4.4 本科生必备工具清单（大二一年内全部拿下）

- **文献**：Google Scholar / Web of Science / 学校图书馆数据库（Elsevier、Wiley、RSC、ACS、Springer）；EndNote 或 Zotero 管理文献；会看 Supporting Information
- **数据与作图**：Origin（必会）、Python（numpy/pandas/matplotlib，处理电化学数据极其高效）、Excel 高级功能
- **仪器数据格式**：电化学工作站导出文件、XRD raw/txt、SEM 图片标尺与能谱
- **计算（可选但加分）**：VASP/Gaussian 入门、Materials Studio、pymatgen；或机器学习基础（scikit-learn）
- **写作**：学术英语写作规范、图表标题与注释、参考文献格式；LaTeX（可选）
- **表达**：PPT 制作（组会与答辩用）、英文口语自我介绍

### 4.5 关于论文与专利的忠告（避坑）

- **不要为了加分去发"水刊"**：学院细则通常限定 SCI 收录、限定作者排序（如第一作者或导师一作/学生二作）、并会排除预警期刊名单。花钱发的论文一旦被查出学术不端，推免资格、学位、声誉一起没。
- **发明专利来不及**：授权通常 2—3 年，公开也要 18 个月。若导师有真实成果愿意带你署名，很好；但不要自己单独去"买一个专利"。
- **实用新型/软著**：加分低，性价比不高。
- **正确顺序**：真做实验 → 有真数据 → 导师判断可否成文 → 投稿（哪怕到大四才见刊，"在投/已接收"状态在夏令营也常被认可，但要以学院认定规则为准）。
- **竞赛作品同样要真实**：节能减排、挑战杯、创新大赛的评委都是行业专家，编造的项目现场三问就穿。

## 五、竞赛与项目：只打"计分且对口"的

### 5.1 优先级清单（时间以学校每年通知为准）

| 赛事/项目 | 大致时间节奏 | 对口度 | 建议 |
|---|---|---|---|
| **大学生创新创业训练计划（大创）** | 每年 3—5 月申报，次年结题 | ★★★★★ | **最该抓住的一个**。目标：大二下报校级 → 大三上争取省级/国家级立项。它同时提供经费、导师、结题成果、综测加分 |
| **全国大学生节能减排社会实践与科技竞赛** | 约 3 月报名，5—6 月校/区赛，8 月全国决赛 | ★★★★★ | 本科学院最对口的国家级赛事，选题直接来自你的科研方向 |
| **中国国际大学生创新大赛（原"互联网+"）** | 4—6 月校赛，7—8 月省赛，10—11 月国赛 | ★★★★☆ | 级别最高、加分最多，但需要成熟项目和跨学科团队（建议加入能源+管理+设计的队伍，或依托导师的产业化成果） |
| **"挑战杯"** | 大挑（课外学术科技作品，奇数年）/小挑（创业计划，偶数年）；校赛通常提前 6—12 个月启动 | ★★★★☆ | 含金量最高，周期最长。2025 年为大挑年，若要参加需在 2024 年底—2025 年初就进入校赛选拔 |
| **全国大学生数学建模竞赛（国赛）** | 9 月初，三天 | ★★★☆☆ | **大二最容易上手、回报最稳的国家级奖**。练 Python/MATLAB + 论文写作，对科研也直接有用 |
| **美国大学生数学建模竞赛（MCM/ICM）** | 1 月底—2 月初，四天 | ★★★☆☆ | 与国赛技能同源，寒假集训一次即可；英文写作对中外项目学生是优势 |
| **全国大学生英语竞赛（NECCS）/外研社杯演讲·写作·阅读** | 4 月初赛，5 月决赛 | ★★★☆☆ | 中外项目学生的相对优势区，投入小、拿奖概率高 |
| **专业类赛事**（材料/化学/物理实验/机械创新等，以学校竞赛目录为准） | 各异 | ★★★☆☆ | 只在学院推荐、且目录内计分时参加 |
| **校内竞赛/院级科技节** | 各异 | ★★☆☆☆ | 加分低，但可作为国家级赛事的练手与选拔通道 |

**参赛纪律**：
1. 只打**学校学科竞赛目录内**的赛事（目录外的一般不计综测分）。
2. 两年内控制在 **3—5 项**，其中 1—2 项冲国家级。广撒网=全部拿不到奖。
3. **优先当核心队员，不要当挂名队员**。面试时"你在队里负责什么"这一问答不上来，奖项就变成负资产。
4. 时间冲突时，**学业 > 大创/科研 > 国家级竞赛 > 其他**。

### 5.2 大创怎么申报（大二下最重要的单项动作）

- **提前 2—3 个月找好指导老师**（最好就是你要进组的那位），并确定课题方向。课题要"小、真、可完成"：一年期内能做完、有明确指标（如"某材料在 X 电流密度下循环 Y 圈保持率 Z%"）。
- **申报书写法**：研究背景（3—5 篇关键文献支撑）→ 科学问题 → 研究内容与技术路线（画流程图）→ 创新点（1—2 条，别吹）→ 进度安排 → 预期成果（论文/专利/竞赛作品）→ 经费预算（材料、测试、差旅）。
- **团队 3—5 人**：分工要明确（合成、表征、数据、写作），找靠谱的人比找厉害的人重要。
- **中期检查与结题**：大三上中期、大四上结题。结题等级（优秀/良好）会影响综测加分，也要写进简历。

### 5.3 选题从哪里来

- 导师课题的一个子问题（最稳妥）
- 你在组会/文献里发现的"小缝隙"（最有说服力）
- 节能减排竞赛：从"能源+社会"角度切入，如校园/工业园区余热回收、光伏+农业、电池梯次利用与回收、储能经济性与碳核算——这类选题不需要昂贵设备，适合本科生
- 数学建模：与能源系统结合，如电池寿命预测、光伏出力预测、微电网调度——可以把你的专业数据直接用进模型

## 六、外语与综合素质

### 6.1 英语节奏表

| 时间 | 目标 |
|---|---|
| 2024 年 12 月 | **CET-4 一次通过**（若未过，这是本学期最高优先级之一；中外项目学生若已有四级，直接冲六级） |
| 2025 年 6 月 | **CET-6 通过**，目标 500+ |
| 2025 年 12 月 | CET-6 刷到 **550—600+**（部分学院/夏令营对六级有隐性门槛，550 以上更安全） |
| 2025 年寒假起 | 学术英语：每周精读 1—2 篇 SCI（先综述后研究论文），做术语表 |
| 2026 年上半年 | 若考虑出国 Plan B：考雅思（目标 6.5—7.0）或托福（95—100+）；同时准备英文自我介绍与英文科研汇报 |
| 全程 | 口语：能就自己的课题做 3 分钟英文陈述并回答提问（夏令营英文面试常考） |

> 注意：确认学院推免细则中的**外语硬性门槛**（四级 425 分是最低线，很多学院要求六级；部分学院认可雅思/托福替代）。门槛不达，排名再高也无法推荐。

### 6.2 综合素质测评的其他加分项

- **学生工作**：班长/团支书/学生会部长/社团负责人通常有加分，但上限低。**建议最多担任一个职务**（如班级学习委员或科创类社团），既能拿分又能获取信息，大二下若与科研冲突就卸任。
- **志愿服务**：确认学院是否有最低时长要求，用寒暑假和周末零散凑够即可。
- **荣誉表彰**：三好学生、优秀学生干部、优秀团员、奖学金（**奖学金本身也常是综测加分项和夏令营的软性参考**，尤其是国家级/校级一等）。
- **体质健康测试**：每年都要参加并达标，别因体测不过被形式审查卡住。
- **社会实践**：暑期"三下乡"等，加分有限，可选做一次（对创新大赛的"社会价值"论述有帮助）。

### 6.3 明确不要做的事

- ❌ 找付费"保研机构"买名额信息、买内推、买论文/专利/竞赛挂名——信息你可以自己查到，成果造假会毁掉一切。
- ❌ 参加学校竞赛目录外的"野鸡赛事"（很多是收报名费的商业赛）。
- ❌ 用 AI 代写竞赛申报书、课程论文、个人陈述后原样提交（查重与 AIGC 检测越来越严，且面试一问就露）。**AI 可以用来学概念、改语言、debug 代码，但不能替代你的思考与署名责任。**
- ❌ 为了竞赛翘专业课。
- ❌ 熬夜刷实验而忽视安全规范（实验室安全事故是一票否决，且不可挽回）。

## 九、决策树：本校 vs 外校，学硕 vs 专硕 vs 直博，以及 Plan B/C

### 9.1 拿到资格后去哪儿：留本校还是走出去

你说的"争取本校推免资格"，通常指**获得华东地区一所211高校的推免资格**（这是资格问题），而**用这个资格去哪儿读研**是另一个选择：

| 选项 | 优势 | 需要注意 |
|---|---|---|
| **留本校（本科学院）** | 导师熟悉、课题连续、无适应成本、实验室资源已上手、成功率高 | 平台与视野上限取决于课题组；若本科已在此，研究生换环境有助于学术网络扩展 |
| **外校/中科院系统** | 平台更强、方向更前沿、人脉更广 | 需要夏令营/预推免竞争，大四上异地奔波；对本科出身与排名更敏感 |
| **直博** | 5 年拿学位、导师资源集中、适合确定要做科研的人 | 中途退出成本高；需要极强的科研兴趣与心理韧性 |
| **学硕** | 科研训练完整，可转博 | 名额相对少 |
| **专硕（如材料与化工、能源动力）** | 偏工程与应用，就业导向 | 若想读博，需确认培养单位的转博/申博通道 |

**建议**：大二—大三先不锁死，用"冲/稳/保"三档目标并行；**本校作为"保"档是理性的**（导师已认识你、课题已上手），同时向外冲 2—3 个更强平台。到 2026 年 5—7 月根据夏令营结果再做最终决定。若确定留本校，务必在大三下（2026 年 3—5 月）就与意向导师面谈，确认其 2027 级招生名额与方向匹配。

### 9.2 Plan B：出国/出境深造（中外项目的天然优势）

- **时间线**：2025 年下半年考出雅思/托福 → 2026 年 3—8 月准备文书与推荐信 → 2026 年 9—12 月递交申请（2027 年秋季入学）→ 2027 年 1—4 月收 offer。
- **与推免的关系**：**两者前 90% 的努力重合**（GPA、科研、英语、推荐信），可以并行到 2026 年 9 月。推免落定后再决定是否放弃出国；若推免失败，出国申请正当季，不会落空。
- **成本**：需提前与家庭沟通学费与生活费；外方合作院校若有联合培养/学位衔接通道，可作为性价比选项。

### 9.3 Plan C：其他推免通道与考研

- **"特殊学术专长"推免**：教育部相关办法允许对有特殊学术专长或突出创新能力的学生，经三名以上本校教授联名推荐、学校审核公示后，可不受综合排名限制。**如果你在大二—大三做出突出的科研成果（高水平论文、国家级竞赛顶级奖项），这是一条可能的通道**——但门槛很高，且各校执行严格，不要把它当主计划，只当作"科研做得极好"时的意外收获。
- **研究生支教团**：部分高校（含本校体系）设有支教团推免专项，通常要求学生工作/志愿经历突出，推免至本校，支教服务 1—2 年后回校读研。**优点是竞争维度不同（不只看排名）**，缺点是多花 1—2 年。如果你对学生工作和公益有真实热情，这是可选项，需在大二—大三积累相应的志愿时长与任职经历。
- **考研**：若推免未成且不选择出国，2026 年 12 月（大四上）参加全国统考。备考需从大三下开始规划，与夏令营准备冲突，**因此推免主线越稳，考研压力越小**。
- **专项计划**：如符合"退役大学生士兵计划""少数民族高层次骨干人才计划"等条件，另有单独通道，需向学校研招办确认。

### 9.4 是否要转专业/转出中外项目？（仅当资格受限时考虑）

**决策树**：
```
问：中外合作办学专业是否有推免资格？
├─ 有（合并排名或单列名额）
│   └─ 不转专业，按本方案执行；若名额单列，目标=班内前1—2名
└─ 无 / 名额为 0 / 规定不明确
    ├─ 问：中外项目学生能否转入普通专业？（很多学校限制中外项目学生转专业，务必核实）
    │   ├─ 能 → 尽早（大一/大二转专业窗口）申请转入普通班的新能源材料与器件或相关专业
    │   │       代价：可能需补修课程、降级、放弃外方学位；收益：获得完整推免资格
    │   │       决策要点：你的GPA是否达标？补修量是否可承受？家庭是否同意放弃外方学位与已缴学费？
    │   └─ 不能 → 主线切换为出国申请（Plan B），辅线为考研（Plan C）
    │             同时保留科研与竞赛投入（对出国申请同样是核心材料）
    └─ 无论如何：**GPA 和科研都要继续做到最好**，因为三条路都需要它们
```

> 这个决策必须在**大二结束前**做出，越晚成本越高（补修课程、降级、转专业窗口关闭）。

## 十、执行系统：怎么保证计划真的落地

计划写出来只是 10%，执行系统决定剩下 90%。

### 10.1 时间分配基准（大二—大三）

| 项目 | 占比 | 说明 |
|---|---|---|
| 课程学习（含作业、复习） | 55—65% | 主线，任何情况下不挤占 |
| 实验室科研 | 15—25% | 每周固定 8—12 小时，寒暑假可翻倍 |
| 竞赛/项目 | 5—10% | 集中在赛季（3—5 月、9—11 月） |
| 英语 | 5% | 每天 30 分钟，长期不断 |
| 运动与睡眠 | — | 每周 ≥3 次运动，23:30 前睡；这是效率的前提，不是可选项 |

### 10.2 周节奏（可直接抄）

- **周日晚上 30 分钟**：写下周计划（课程/实验/竞赛/英语各列 3 条），排出每天的时间块
- **每天睡前 10 分钟**：勾掉完成项，记录"今天最有效率的 1 小时做了什么"
- **每周五 1 小时**：本周复盘（绩点跟踪表更新、实验记录整理、下周调整）
- **每月底 2 小时**：对照学期目标检查进度；更新材料库与简历
- **每学期末 半天**：学期复盘 + 下学期计划；每学年末做一次"年度复盘"（见下）

### 10.3 看板（一张 A4 纸，每月更新）

| 指标 | 现状 | 目标 | 差距 | 下一步动作 |
|---|---|---|---|---|
| 累计学分绩点 | | ≥3.7/4.0（或对应百分制 87+） | | |
| 专业排名 / 人数 | | 前 15%（名额单列则班内前 2） | | |
| 不及格课程数 | 0 | 0 | | |
| CET-4 / CET-6 | | 通过 / 550+ | | |
| 实验室时长（累计） | | ≥400 小时（到大三下） | | |
| 大创 | | 省级以上立项 | | |
| 竞赛获奖 | | ≥1 项校级以上，力争国家级 | | |
| 论文/专利 | | 有真实数据支撑的成果 | | |
| 志愿服务时长 | | 达到学院要求 | | |
| 体测 | | 达标 | | |
| 夏令营目标清单 | | 20—30 个 | | |

### 10.4 同伴与信息机制

- **找 2—3 个同路人**（最好含 1 个比你高一届、已经拿到资格的学长学姐）：互通信息、互相督促、共享资料。保研是信息战，一个人闷头学很容易错过窗口期。
- **固定信息渠道**（每周至少查一次）：华东地区一所211高校研究生院官网、教务处官网、本科学院官网通知公告、校团委（竞赛通知）、学院教务办公室公告栏、班级/年级通知群、目标院校研究生院官网与公众号。
- **不要依赖**：付费保研群、来路不明的"内部名额"、社交平台上的经验帖（信息滞后且个案性强，可作参考不可作依据）。

### 10.5 心态与风险

- **排名会波动**，一次期末考砸不等于失败，前六学期是长跑；关键是每学期都比上学期更懂"怎么拿分"。
- **科研会失败**，实验重复不出结果是常态，记录清楚"为什么不成功"本身就是能力。
- **不要把保研当唯一目标**：你在这两年里真正获得的（自学能力、科研素养、英语、时间管理、抗压能力），无论最后走推免、出国还是考研，都是你的资产。
- **健康优先**：熬夜刷实验导致安全事故或长期生病，是彻底的负收益。
