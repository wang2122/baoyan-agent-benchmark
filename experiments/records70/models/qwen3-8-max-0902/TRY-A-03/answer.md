## 〇、先说结论：三句话

1. **你不是"四年制2027届"，你是"五年制2028届"。** 你这个专业是华东地区一所211高校与**外方合作院校**合作办学项目，**学制5年**，培养模式是"国内3年 + 第四学年起可赴加2年"（俗称 3+2）。所以你的推免窗口在 **2027年9月**，不是2026年9月——你比同届四年制同学多一年准备时间，这是优势，但也意味着中间横着一个"出国还是保研"的岔路口。

2. **好消息：本校推免办法的"排除名单"里没有中外合作办学。** 排除的只有"专升本、第二学士学位、独立学院学生"。你是国家统招计划录取的，原则上在推免范围内。**坏消息：有没有"名额"和"怎么排名"是另一回事**，这必须去学院教务办问死。

3. **"转专业跑掉"这条路基本是堵死的。** 《华东地区一所211高校本科生转专业实施办法》第八条明确把"中外合作办学类专业学生"列入**不予转专业**情形。所以别把希望寄托在转出去，要把希望寄托在**把本专业 GPA 刷到前面 + 攒够发展素质分**。

## 四、排序规则：500分怎么算，你的发力点在哪

本校2025届各学院细则采用的综合评价公式（**以本科学院当年细则为准，但框架应一致**）：

```
综合评价成绩（满分500分）= 学业成绩（GPA × 100，满分400）
                        + 发展素质成绩（满分100）
```

**发展素质成绩 100 分的五个构成项：**

| 项目 | 分值上限 | 你的可操作度 |
|---|---|---|
| 科研成果（论文、专利等） | **≤ 30 分** | 🎯 高 —— 大二就能启动 |
| 竞赛获奖 | **≤ 30 分** | 🎯 高 —— 大二就能启动 |
| 参军入伍服兵役 / 完成义务兵役 | 20 分 | 低（个人选择） |
| 志愿服务 | ≤ 10 分 | 中 —— 顺手做，别当主攻 |
| 国际组织实习 | ≤ 10 分 | 中 —— 对你这个专业反而有机会 |

**排序规则**：按综合评价成绩从高到低确定推免名单；**同分时 GPA 高者优先**（有的学院 GPA 保留3位小数，有的以教务系统数值保留2位小数）。

### 💡 这里是全文最重要的一段算术

GPA 满分 4.0 → 400 分。**专业第1名和第10名的 GPA 差距，通常只有 0.1–0.2，换算成分数只有 10–20 分。**
而**发展素质里的"科研30 + 竞赛30 = 60分"**，足以把 10 个名次以上的差距抹平甚至反超。

结论：
- **GPA 是入场券**（不达标就出局，且同分时决胜），必须守住；
- **科研 + 竞赛是胜负手**（60分的空间，是排名跃升最快的杠杆），必须尽早攒。
- **两者不可偏废**：只刷 GPA 没有发展素质分 → 卡在名额线外；只做竞赛挂了科 → 直接丧失资格。

### 还有一条"破格"通道：学术特长生

《实施办法》规定：**有特殊学术专长或具有突出培养潜质者**，经**三名以上本校本专业教授联名推荐**，经学院推免生遴选工作小组严格审查、学校推免生遴选工作领导小组复审，**可不受成绩、学分、外语等基本条件的限制**。公示时须同时公示证明材料和教授推荐信。

👉 对你的现实意义：**这条路的本质是"你手里得先有硬成果"**。教授不会为一个没进过实验室的学生联名。所以它不是捷径，而是"科研做得极好"的额外保险。**大二就开始联系导师进课题组，是这条路的唯一入口。**

### 第二阶段：教育部"推免服务系统"（9月下旬–10月中下旬）

系统网址：**中国研究生招生信息网（研招网）`yz.chsi.com.cn/tm`**

2025届（2024年）的实际时间线，可作为2028届（2027年）的推算模板：

| 时间（2024年实况） | 动作 |
|---|---|
| **9月22日** | 系统开通：注册学信网账号 → 登录 → **查询本人推免资格** → 填报个人资料 → 上传照片 → **网上支付报名费** |
| **9月28日 9:00** | **志愿填报功能开通** |
| **9月29日 9:00 起** | 招生单位开始反馈是否同意复试（前一天不给反馈，是留给你从容报考的） |
| **约10月20日** | 志愿填报/确认截止（各校可能更早，有的学院要求9月28日17:00前完成） |

**六步操作流程：**
1. **注册并登录**（学信网账号，可在"学信档案"核对本人的学籍学历信息）；
2. **填报个人资料 + 上传照片**；
3. **网上支付报名费**（务必在9月28日9点前完成，否则可能来不及填志愿）；
4. **填报志愿**：可同时填 **3个平行志愿**（不分主次，专项计划除外）。⚠️ **每个志愿提交后48小时内不允许修改**；48小时后仍未收到复试通知、复试未通过或被拒待录取的，可继续填报其他志愿；48小时内若招生单位明确拒绝，可立即改填；
5. **复试**：招生单位通过系统发复试通知，**你必须在系统内回复"是否同意参加复试"**，否则对方可取消通知。⚠️ **未通过系统确认接受复试通知的，不能被录取**；
6. **确认"待录取"**：⚠️ **待录取通知可以拒绝多个，但只能接受一个**；一旦接受，不能再填报其他志愿或接受其他复试/待录取通知。**未通过系统确认接受"待录取"，录取不生效。**

**三条铁律：**
- 未经教育部"推免服务系统"确认的推免录取结果，**一律无效**；
- 拟录取的推免生**不得再报名参加当年硕士研究生统考**，否则取消推免录取资格；
- 获得推免资格后**不得再申请出国（境）留学、参加就业派遣**，违约责任自负。

## 七、如果保研这条路走不通：四条备选路径

按可行性从高到低排：

1. **🥇 3+2 出国 + 海外/港澳申请制硕士（这个专业的"原生路径"）**
   完成第四、五学年赴外方合作院校学习，拿 **外方合作院校 的 Bachelor Degree + 本校毕业证学位证**，然后用**申请制**（不需要推免资格）申研。
   - 优势：路径天然顺畅、双学位含金量高、可申请北美/英联邦/港新名校；
   - 成本：加方学费按标准另收（**这是要和家长提前算清楚的账**）；
   - 关键：**大三上就要开始准备雅思/托福、GPA、科研经历、推荐信**。这条路的准备工作和你为保研做的准备**有70%重合**（GPA、科研、英语），所以**不用现在就二选一，先把重合的部分做扎实**。

2. **🥈 全国硕士研究生统一招生考试（考研）**
   兜底方案。不需要推免资格，但需要大四/大五全力备考，且**与3+2出国时间冲突**（初试在12月，你人在加拿大）。如果选这条，基本等于放弃出国。

3. **🥉 "学术特长生"破格推免**
   见第四节。**三名以上本校本专业教授联名推荐**，可不受成绩、学分、外语条件限制。前提是你手上已经有拿得出手的成果（论文/专利/顶级竞赛奖）。

4. **本校直博/硕博连读、第二学士学位、就业**
   视情况而定。本科学院有**两个博士点**，本校直博是一个值得了解的方向。

## 八、常见误区（这些坑每年都有人踩）

| ❌ 误区 | ✅ 真相 |
|---|---|
| "中外合作办学不能保研" | **不准确。** 本校办法排除的是专升本/第二学士学位/独立学院，中外合作办学**不在排除名单**；实践中本校中外合作办学项目也有保研名额。但**名额多少、怎么排名，必须问学院**。 |
| "读了中外合作只能出国" | **不准确**，但**对你这个专业，出国确实是更顺畅的路径**。 |
| "我是四年制，2027年毕业" | **错。你是5年制，2028届，推免在2027年9月。** 这个认知错误会让你整整错判一年的节奏。 |
| "转专业出去就行了" | **基本堵死。** 转专业办法第八条明确排除中外合作办学类学生。 |
| "GPA最重要，别的都是加分项" | **半对。** GPA是入场券+同分决胜（400分），但**科研30+竞赛30=60分的发展素质**足以抹平10个名次的GPA差距。 |
| "大三再准备也来得及" | **来不及。** 夏令营在**大四前的暑假**（对你是2027年5–7月）就要打完，而夏令营看的是你**前三年半**的积累。科研成果、竞赛奖项、大创项目、推荐信，全都要提前1–2年布局。 |
| "到时候再交材料" | **申请窗口只有约4天。** 成绩单要教务处盖章、排名证明要盖章、推荐信要教授签字。人在国外时这些几乎办不了。**从大二就开始建档案。** |
| "拿到推免资格就稳了" | **不稳。** 还要在教育部系统里填志愿、确认复试、确认待录取，**任何一步没在系统里点确认，录取都不生效**。且待录取**只能接受一个**。 |
| "保研和出国可以两手抓" | **风险极高。** 获得推免资格后不得再申请出国留学，违约责任自负；且时间线严重冲突。**建议做单选题。** |
