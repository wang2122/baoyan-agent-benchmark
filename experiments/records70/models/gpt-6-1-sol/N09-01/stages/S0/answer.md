你的准备重点应当是：守住排名优势，选出一到两个能讲透的项目，围绕真实能力确定申请方向，再把报名、专业复习和面试安排到同一张计划表里。项目参与深浅不同很正常；申请材料要让老师看清楚你具体解决过什么问题，以及你有哪些值得继续培养的能力。

以下按“2026年申请、2027年入学”理解本轮推免。你没有提供具体年级、项目清单、个人分工和目标院校，所以涉及方向与材料的建议均是可根据实际情况调整的方案，不把示例当成你的既有成果。

**1．先判断自己的优势和需要补足的部分。**

前约2%约为专业前约2%，这是明确的学业优势，值得申请有竞争力的机械、机器人相关团队。但成绩排名不等于已经获得本校推免资格，也不等于目标院校一定接收。先核实排名的统计学期、口径和是否包含加分，取得正式成绩单与排名证明，并核对所在学院本届推荐办法、名额及资格公示。简历据实写“哈尔滨工业大学（威海）—机器人工程”，排名口径与证明一致。

六级500–549可以作为明确的英语成绩展示。以已经公布的上海交通大学2027年校级推免办法为例，其英语条件为CET6≥425或相应托福、雅思成绩，500–549满足这一校级条件；学院仍可能提出其他要求，不能由此推导出所有院校都满足，也不能把达标理解为录取优势已经兑现。[上海交通大学2027年接收推免办法](https://yzb.sjtu.edu.cn/post/3775)

对你来说，接下来更有价值的是把英语转成实际表现：能介绍自己的项目、解释关键技术词汇、阅读并概括相关论文。如果某个目标项目明确要求你尚未达到的语言成绩，再单独安排提升；申请季末段不宜把主要时间押在刷六级分数上。

机械和机器人项目经历能成为第二个支点，但目前还无法仅凭“参加过项目”判断科研能力。整理之后，可能发现你最强的是结构设计、建模分析、实验调试或控制实现中的某一项。申请方向应顺着这项证据展开。

**2．先做项目盘点，再决定哪些经历进入简历。**

给每个项目建立一张内部记录表，先不急着写漂亮的介绍：

| 要记录的内容 | 要回答的问题 |
| --- | --- |
| 背景与目标 | 要解决谁的什么问题？有哪些载荷、尺寸、成本、精度或实时性约束？ |
| 时间与团队 | 何时参与、共几人、指导者是谁？项目目前处于什么阶段？ |
| 个人任务 | 哪个零件、模型、程序、实验或分析由你完成？谁提出方案、谁做最终决策？ |
| 技术过程 | 输入是什么，采取了什么方法，为什么这样选，具体实现了哪些步骤？ |
| 验证结果 | 有哪些仿真、实验或测试？与什么基准比较？结果在什么条件下成立？ |
| 支撑材料 | 图纸版本、代码记录、实验日志、原始数据、报告、视频和获奖证明分别在哪里？ |
| 边界与不足 | 哪些由队友完成？哪些仅复现或按指导执行？还有什么没有验证？ |

团队成果和个人贡献要分开记录。例如“团队完成整机并获奖”可以写，但还需要写出你负责的模块；整机有视觉、规划、控制和机械结构，不代表你都做过。对论文、专利也分别写清作者或发明人顺序、具体贡献和当前状态，投稿、录用、发表以及申请、授权不能混用。

之后按实际参与情况安排展示位置。下面的分类只是整理方法，不是学校的评价标准：

| 实际参与情况 | 材料安排 | 后续准备 |
| --- | --- | --- |
| 能独立说明方案、实现和验证，也能解释关键决策 | 作为主项目，分配最多展示时间 | 补齐证据、失败分析与追问准备 |
| 在指导下完成一个明确模块，理解原理并能复现 | 作为第二项目或辅助经历 | 把自己负责的模块讲完整，争取补一次独立验证 |
| 主要负责装配、采集、测试执行或资料整理 | 有相关价值时简要列出 | 讲清执行质量、发现的问题及协作贡献 |
| 主要旁观，或目前无法说清自己做了什么 | 暂不放进核心项目栏 | 如确有必要再补学；时间紧时优先准备其他经历 |

优先选“与你申请方向相关、个人贡献明确、证据充分、能经得起追问”的项目。获奖级别高但自己只做了少量工作，可以放在荣誉或辅助经历中；一个规模较小但你真正完成了分析与验证的项目，也可以成为主项目。经历不必等长，简历通常突出两个项目即可。

**3．把主项目整理成一条可以检查的技术链。**

每个主项目都准备“目标与约束—个人任务—方法与选择—验证与结果—不足与下一步”这条叙述。重点不是堆软件名称，而是解释你怎样用工具解决问题。

假设你确实做过机械臂末端夹具的设计，这个示例可以这样转换；它不是对你已有经历的描述：

> 项目目标是在指定工件、载荷与安装空间下完成夹持。我负责夹具结构设计和强度校核，控制程序由队友完成。我比较了［实际比较过的方案］，根据［真实约束］确定结构，完成［实际图纸或模型］，随后通过［实际仿真或测试］检查［指标］。当前还没有验证［真实不足］。

如果实际只按老师给定方案画图，就写“根据既定方案完成建模与出图”，再讲你如何处理尺寸链、装配干涉或加工问题。面试前重新学会方案原理能提高理解深度，但不能把后来学会的内容追溯成当时独立提出的方案。新做的验证可以列为后续补充，并标明时间。

不同项目要准备不同的技术追问，按你实际做过的模块选择：

- **机械结构项目：**载荷怎样确定，材料与传动方式为什么这样选，强度、刚度或疲劳哪个限制设计，装配与加工有哪些约束？若使用有限元，边界条件、接触、网格与材料参数怎样设置，计算结果如何校验？软件给出云图不等于验证完成。
- **机器人建模与控制项目：**坐标系怎样定义，运动学或动力学模型有哪些假设，控制器的输入输出是什么，采样、噪声、饱和等因素怎样影响效果？若实际只完成PID调试，就讲清误差定义、调参过程和测试条件，不把它写成提出新算法。
- **实验与系统调试项目：**如何定位故障，怎样区分结构、传感器、执行器和程序的问题，记录了哪些数据，复现条件是什么？能讲清一次故障排查，也能体现分析能力。
- **复现类项目：**原方法是谁提出的，你复现到哪一步，是否得到相近结果，差异可能来自哪些条件，自己修改了什么？未成功复现也可以分析原因，但要准确说明完成程度。

项目结果尽量用真实数据表达，并带上测试条件、单位、基准和重复次数。例如声称“定位误差下降”，需要解释误差如何定义、与哪种方案相比、是否在同一负载和轨迹下测试。若没有数据，就如实写“完成样机搭建”“通过指定功能测试”，并说明验证局限，不能为了量化而编一个百分比。

对每个主项目至少准备六个问题：为什么这样做？有没有替代方案？最难的部分是什么？哪里失败过？结果怎样证明？如果继续做，你会先改哪里？不熟悉的队友模块可以说明接口和系统作用，细节则明确自己的了解范围。

**4．用经历选择方向，再筛学校和导师。**

机器人工程可以连接不同学科。你应先判断自己希望研究什么问题，再确认它在哪个学院、专业和团队招生：

| 个人证据与兴趣 | 可以优先考察的方向 | 需要重点补足的能力 |
| --- | --- | --- |
| 结构、机构、传动、样机、力学分析较扎实 | 机械工程中的机器人机构、机电系统、机械设计等 | 力学、机械原理与设计、建模和实验验证 |
| 建模、传感、闭环调试和控制实现较扎实 | 控制、机器人运动控制、机电控制等 | 线性代数、自动控制、运动学动力学与编程 |
| 确有较深入的视觉、规划或算法代码与实验 | 机器人感知、规划、智能机器人等 | 算法、概率统计、优化及相应计算机基础 |

如果目前证据主要是机械设计和样机调试，可以先以机械、机电或机器人机构为主线，拓展一个邻近方向。想转向感知或算法，需要通过自己完成的实现与实验补证据，不能只凭“机器人”专业名称推断跨到相关计算机方向已经准备充分。

招生专业名也不一定叫“机器人”。例如上海交大2027年机械与动力工程学院接收推免的专业中包含学术型机械工程与专业型机械，机器人相关研究要进一步核对团队方向。[机械与动力工程学院2027年推免综合考核细则](https://me.sjtu.edu.cn/YanJS/mainnotice/7697.html)

硕士、直博的选择要单独考虑。若仍在判断兴趣、项目深度尚待检验，可以优先申请硕士；若已确认长期科研意愿，对方向和团队有充分了解，再认真考虑直博。专业学位和学术学位都应查看具体培养方案、实践安排、毕业要求和后续发展机会，不用学位名称简单判断研究质量，也不为争取某个学校临时承诺并不愿意走的培养路径。

建立一张申请表，以“学院—专业—团队”为单位，而不是只列学校：

| 信息类别 | 需要核实的内容 |
| --- | --- |
| 准入条件 | 本科专业、排名、外语、推荐资格及其他要求 |
| 当年招生 | 学位类型、校区、招生方向、批次是否仍开放 |
| 申请流程 | 院校报名截止时间、材料格式、面试方式、是否另需导师联系 |
| 匹配程度 | 团队近期做什么，你的哪段经历能对应其研究问题 |
| 培养条件 | 指导方式、学生训练、毕业要求、住宿与经费等本人关心的条件 |
| 当前状态 | 已报名、待审核、已考核、候补或拟接收；通知与回复期限 |
| 来源 | 官方链接、发布日期、最后核查时间 |

有充分准备时间时，可先筛出约8—12个申请单元，形成少量冲刺、一批主要目标和至少一两个你愿意接受的备选。这个数量只是管理建议，需根据批次冲突和材料负担调整。哈工大相关学院及熟悉的校内团队可以纳入候选，但要核实当年流程，不能把校内或跨校区申请当成自动兜底。也不能只用学校层次定义“稳妥”：具体团队可能名额很少，备选同样需要正式申请和考核。

导师主页和近期论文适合判断方向；名额、门槛和截止时间以当年研招办、学院通知及正式回复为准。往届经验可以帮助准备，不能替代2026年的通知。看不清是否有余量时，向学院招生办公室确认当前批次，而不是凭群聊判断。

**5．把盘点结果转成一套一致的材料和表达。**

建议准备以下材料，具体以申请单位要求为准：

- **一至两页简历：**教育背景、真实排名与英语成绩、两个重点项目、相关奖项和技能。技能写到能解释实际用途的程度；“熟练掌握”应经得起现场追问。
- **证明材料：**正式成绩单、排名证明、语言成绩、所列奖项与成果证明；资格材料按通知要求提供。所有材料的项目名称、时间、角色、成果状态保持一致。
- **个人陈述：**说明为什么想研究某类问题、已有经历如何支持这一选择、还需要补哪些能力，以及与申请团队的联系，避免泛泛表达对名校或热门方向的向往。
- **面试展示：**先做一份约5分钟的版本，突出背景、一到两个项目和研究兴趣；再按目标单位时长调整。技术细节、原始结果与补充图表放在备用页。
- **项目证据包：**每个主项目一份简短技术说明，附自己负责部分的图、数据或代码索引。涉密和未经许可的团队材料不能直接公开，必要时使用获准的脱敏说明。

你的自我介绍可以从这个骨架改起：

> 我是哈尔滨工业大学（威海）机器人工程专业本科生，专业排名前约2%，六级500–549。本科阶段参与了［真实项目类型］，其中在［主项目］中负责［个人任务］。通过［实际工作］，我对［具体问题］产生了兴趣，希望进一步学习［方向］。目前我比较扎实的基础是［有证据的能力］，需要继续补足的是［真实短板］。

不要同时声称精通机械、控制、视觉和人工智能。清楚的能力边界有助于老师判断适配度。面试遇到未知问题，可以说明已有理解和分析路径，不能用术语掩盖不会。

如果需要联系导师，邮件简洁写明身份、排名、英语、最相关的个人贡献、对其研究的具体兴趣，以及希望了解的招生类型，附简历和必要材料。先阅读团队主页及一两项相关工作再联系，避免把同一封泛泛邮件群发。导师表达欢迎、建议报考或口头认可，仍需进入学院正式考核与录取流程。

**6．后续准备按剩余时间安排，当前申请季先处理不可错过的事项。**

截至2026年10月10日，本轮已在正式推免阶段。研招网公布：2027年推免生从2026年9月18日起注册并查询资格，9月21日起填报志愿，10月18日截止填报志愿，相关复试与待录取确认安排至10月20日。全国系统的截止时间不代表每个学院都招生到最后一天，院校可能更早结束。[研招网推免服务系统说明](https://yz.chsi.com.cn/tm/)

因此，如果你就是本轮申请者，建议按下面的顺序推进：

1. **今天先核实状态。**确认本人推免资格已在系统中可查，梳理是否已有复试、候补、拟接收或待录取通知，记录每个通知的具体回复期限。若资格显示异常，立即向本校负责部门核实。排名再好，也不能绕过资格备案。
2. **接下来一至两天完成最小可用材料。**整理正式证明，定下一个主项目和一个辅助项目，统一简历、个人陈述与展示中的表述，同时完成一轮模拟面试。不要等材料“完美”才提交尚未截止的申请。
3. **同步核查仍开放的正式机会。**优先处理已经报名、候补或已有联系的单位；新增申请只选择官方仍在接收、方向匹配且本人愿意就读的项目。确认是否需要先在院校系统报名，再按要求完成国家系统操作，不能只联系导师或只填一个系统。
4. **按已安排的考核做定向复习。**每天练习主项目追问、相关专业基础和英语表达。此时不宜临时开启一个大项目、追求短期论文或大范围转方向。
5. **慎重处理待录取。**确认培养类型、团队安排及本人接受意愿，按通知时限操作，不把待录取确认当成可随意更换的占位动作。以上海交大本轮规则为例，自主选择并确定拟录取后不得提出放弃。[上海交通大学2027年接收推免办法](https://yzb.sjtu.edu.cn/post/3775)

如果你已经完成正式待录取确认，后续重点转为完成毕业要求、手续和入组前准备。若目前尚未取得推荐资格，要先厘清是备案问题还是没有被推荐，不能把未获资格者当作可以直接进入推免录取的申请人处理。

如果你的实际年级更早，下面这套节奏可用于完整准备周期；本轮已过去的夏令营和预推免节点不应当作现在仍可报名的机会：

| 阶段 | 工作重点 | 可检查的产出 |
| --- | --- | --- |
| 前1—2周 | 项目盘点、资格条件核查、方向初筛 | 项目记录表、主项目选择、申请信息表 |
| 接下来3—6周 | 深挖主项目，补最有价值的验证，复习相关基础 | 技术说明、真实实验或仿真结果、追问答案 |
| 报名前 | 按通知准备简历、证明、陈述和展示，联系相关团队 | 可直接提交的材料与报名回执 |
| 夏季交流或考核阶段 | 按各单位当年安排参加活动，记录问题并修正 | 面试复盘、更新的材料和申请状态 |
| 预推免与正式阶段 | 补充开放机会，核实接收条件，完成系统操作 | 正式通知、确认记录和后续手续清单 |

有四周以上余量时，补项目应选择一个你能独立完成的小闭环。例如在已有结构方案中比较两种设计，并用计算和测试解释差异；在已有控制平台上比较不同参数或方法，记录相同条件下的响应；在复现项目中找到一项明确差异，做对照实验检验原因。产出可以是一页可靠的数据分析，而不是新增一个听起来宏大的项目名称。

仿真要说明模型假设，不能称为实物实验；比较结果时保持条件一致，记录重复测试和误差。若一周内仍无法说清补充工作的可验证目标，就缩小任务或暂缓，把时间用于已有主项目。

专业复习按申请方向集中推进：机械方向优先机械原理与设计、理论力学和材料力学；机器人控制方向优先线性代数、自动控制、运动学动力学及实际用到的编程；感知或规划方向再补相应算法、概率统计与优化。具体考核范围要看目标学院通知，不把这些建议当作所有学校统一考纲。

学期内仍以课程和正式考核为先。在课外准备时间里，可以约一半用于项目与基础复习，三成用于材料和申请信息，两成用于英语与模拟面试；临近截止则提高申请操作的优先级。每周完成一次口头模拟：请老师或同学追问个人贡献、关键参数、结果证据和失败原因，记录答不清的问题，集中补最影响主项目可信度的部分。

你当前最值得建立的申请形象，是“学业基础扎实，在一到两个机械或机器人问题上有明确的个人工作，并能解释其方法、结果和局限”。把这一形象落实到证据和表达里，再用准确的报名与录取安排承接它，才能把排名优势转成更合适的深造机会。
