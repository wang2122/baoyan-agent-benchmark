> 说明：本答卷只做分析、判断与建议，**不做任何评分**。文中引用的学科评估、就业人数等数据均标注了来源性质与口径，请在正式决策前按第七节的清单自行复核。

## 一、先厘清三个前提，否则"利弊"无法判断

你的问题里有三个变量没给定，它们会直接改变结论。我先把它们摆出来，然后**分情形给结论**（第四、五节）。

### 前提1：家在哪里？这决定"离家近"指向哪个省网

"离家近"在电网就业语境下有两层含义，必须分开看：

- **地理距离**：读研城市到家的通勤便利度（回家频次、生活成本）。
- **就业属地**：你最终想进哪个省的电网公司。这一层比地理距离重要得多，因为**电网招聘高度属地化**——各省电网对本省/本地高校有明显的生源倾斜与校友网络优势，跨省求职时"本地王牌"的效力会明显衰减。

你没说家在哪。你本科在南京读书，最常见的情况是家在江苏或周边（安徽、浙江、上海），但也不排除家在山东（这能解释你为什么把山东大学列入）或京津冀（对应华北电力）。第四、五节按四种情形分别给排序。

> 如果你能补一句"家在哪个省/市"，结论可以直接收敛到一条最优路径。

### 前提2：时间节点

文中数据的时间基准是：南信大2026届（2022级）推免指标与公示已出，东南大学电气工程学院"2027年接收推荐免试研究生考核入选名单"已于2026年8月公示。也就是说，**刚过去的一轮是"2026年9月推免、2027年入学"**。

你说"本校推免资格尚未确认"，据此我按**你参加的是下一个完整推免周期**（即次年7–9月夏令营/预推免 + 9月正式推免）来排时间表。如果你的实际节点不同，请把第六节的时间轴整体平移，其余判断不变。

### 前提3：你的目标函数是"进电网"，不是"做学术"

这一点极其重要，它几乎推翻了你对"论文还没录用"的焦虑：

- 电网招聘看的是：**硕士学历 + 学校在电力系统的行业认可度 + 目标省网的属地匹配 + 笔试面试表现**。
- 论文、专利在国网统考和提前批中**基本不构成门槛**，只在少数省电科院/经研院/直属科研单位的岗位上有加分。
- 因此：**不要为了等一篇论文录用而牺牲推免时机或推高目标院校**。论文达到毕业要求即可。

## 二、你的个人条件盘点：硬实力够，短板在"出身"和"成果形式"

### 优势（真实且稀缺）

| 项目 | 状态 | 在推免中的分量 |
|---|---|---|
| 专业排名前约2% | 已确定 | **最高权重**。推免筛选第一关就是排名，前2%在几乎所有院校的初筛里都是"安全区" |
| CET-6 550–599 | 已确定 | 已经很高，**不必再刷**。各校推免的英语门槛普遍在425–500区间，你远超 |
| CET-4 600–649 | 已确定 | 锦上添花 |
| 竞赛经历 | 有 | 中等权重，见下文 |
| 本校"双一流"身份 | 已确定 | 南信大是"双一流"建设高校，在部分院校初筛中好于普通双非 |

### 关于本校推免资格：大概率稳，但必须确认四件事

南信大近年推免规模在快速扩大：2026届（2022级）推免指标822人（含研究生支教团10人、补偿计划7人），按7256名本科生计，**整体保研率约11.19%–11.34%**（不同来源对最终获得资格人数统计为804–812人，口径略有差异）。你在**前2%**，从概率上说大幅优于11%的平均线。

但要确认以下四点，任何一点出问题都可能翻车：

1. **排名口径**：是"专业排名"还是"学院排名"？推免名额通常按专业/学院分配，如果电气专业所在学院名额偏紧，前2%也可能擦边——去学院教务办问清楚"电气工程及其自动化专业近三年分到的推免名额数"和"你们这届的加权成绩计算细则"。
2. **加分政策**：竞赛、专利、论文、志愿服务在校内推免细则里的加分区间，以及加分是否有上限、是否只认"国家级/省部级"、是否只认"前三作者"。这直接决定你该不该再冲一个竞赛。
3. **一票否决项**：有无挂科（补考/重修记录）、处分、体测不达标、必修课不及格等。
4. **综合测评 vs 加权成绩**：南信大推免表同时列"综合测评排名"和"必修课加权平均分"，搞清楚最终排名用的是哪一个，两个口径下你的名次可能不同。

**Plan B 必须同时准备**：推免是"别人给你名额"，你控制不了全部变量。若资格落空，考研是唯一退路。四校中，河海大学、华北电力大学的考研性价比相对高，东南大学电气考研难度最大。建议在9月前按"推免为主、考研英语与专业课不松手"双轨推进。

### 短板（以及如何补救）

- **本科院校在电力系统的行业认可度一般**。南信大的招牌是大气科学，电气专业在国网系统内不属于"电力部属院校"，也不属于传统电气强校。这一点**只有在你硕士学校是985/211或电力部属院校时才能被完全覆盖**——好在你列的四所全部满足，这是你选校清单里最正确的一个决定。
- **论文尚未录用**。这是四所学校里冲刺985时最大的相对劣势（东南、山大的竞争对手里，有录用论文的人不少）。补救方式：面试时用"在投/在审 + 我能把工作讲清楚"来体现科研训练，而不是硬凑成果。
- **专利在审**。如实写"已受理/进入实审"，附受理通知书。**千万不要写成"已授权"**——推免材料造假一旦被查出，资格直接取消。

## 三、决定"能不能进电网、能不能离家近"的三条主线

在逐校分析前，先把评价框架定下来。你后面看到的所有"利弊"都归结到这三条。

### 主线1：学校在电力系统的行业认可度（决定"能不能进、进哪一档"）

电网招聘对院校有明确的圈层认知：

- **学科评估等级**：是各省电力公司筛选简历时最常引用的硬指标。
- **"电气二龙四虎"与传统电力口院校**：清华、西交、华科、浙大（四虎），华北电力、武汉大学（二龙的一种说法）等在国网内部有长期口碑。
- **985/211 标签**：在国网**提前批**（校园招聘，9–11月，主要面向985、211及原电力部属院校的硕士研究生，部分岗位可免统考直接录用）中，**学历优先级大致是：985硕士 ＞ 211/电力部属硕士 ＞ 优质本科**。提前批几乎不下探到普通双非院校。

> 关键结论：**你必须读一个985/211或电力部属院校的电气硕士**。这不仅是"更好"，而是"有没有资格参加提前批"的分界线。你的四所候选全部合格，这一步你已经走对了。

### 主线2：属地匹配（决定"能不能离家近"）

各省电网的生源结构高度本地化，数据说话：

- **国网江苏电力2025年第一批录用1159人，生源高校约90所**。录用人数排名第1的是南京工程学院（250人，占总人数约22%），第2是东南大学（约102–110人），第3是河海大学，其后为西安交通大学、中国矿业大学、南京师范大学（均超50人）。
- **国网山东电力2025年第一批录用1283人，生源高校163所**，录用人数较多的高校为：山东大学、山东科技大学、山东理工大学、华北电力大学，其中**山东大学居首**。

这组对比非常直白：**在江苏，"东南 + 河海"是仅次于南工程的本地主力；在山东，"山大"是绝对第一**。跨过去，效力就打折扣。

### 主线3：学历层次与岗位层次（决定"进市局还是县局"）

- 省会城市、经济发达地市的**市局基本只招硕士**；电科院、经研院等科研单位部分岗位要求博士。
- 硕士学校层次还会影响**分配去向**：同为硕士，院校电气实力不同，去向差异明显（有的省985硕士主要进市局，其他院校硕士主要进县局）。
- 国网招聘官方公告通常**不设户籍硬性限制**，但部分热门地区/岗位存在本地生源优先，实际录取中本地考生可能占优。

所以"离家近"要实现，路径是：**硕士学历 + 目标省网认可的院校 + 尽量走提前批**。

### 附：国网招聘时间轴（供你倒推读研期间的动作）

以2026届（即上一届）为例，节奏如下，各届基本稳定：

- **国调网调提前批**：10月中旬发布（2026届为2025年10月18日）
- **第一批**：10–11月发布公告并网申，12月初笔试（2026届为2025年12月7日，上午电工类本科场、下午电工类研究生场），笔试后约1周面试
- **第二批**：次年3月
- **第三批**：次年5月
- 唯一报名渠道：国家电网招聘平台（zhaopin.sgcc.com.cn），需上传学信网学籍验证报告，提交后信息不可修改

## 四、四校逐一分析：利与弊

### 4.1 东南大学（南京·江宁九龙湖校区）

**定位**：985 / 双一流A类；电气工程第五轮学科评估**A-**（网传版本，第四轮为B+，校方称该学科"取得历史性突破"）。

**利**

1. **离家近（若家在江苏/南京）**：研究生主要在九龙湖校区（南京江宁），是本科学校所在地，回家、实习、跑宣讲会成本最低。
2. **江苏电网的本地王牌**：2025年国网江苏电力第一批录用中，**东南大学位列第2（约102–110人）**，仅次于南京工程学院；有统计称东南大学2025年全国电网系统录取约198人、其中江苏电网约102人，硕士就业率与就业质量均处高位。
3. **学科与平台强**：拥有江苏省智能电网技术与装备重点实验室、伺服控制技术教育部工程研究中心、国家级工程实践教育中心、东南大学智能电网研究中心及一批校企联合研究中心。A- 学科在跨省求职时（浙江、安徽、上海、山东电网）都比B/B+ 更好使。
4. **985标签在提前批最吃香**：国网提前批的院校圈层里985硕士优先级最高，若你想进省会/苏南发达地市市局，985是最稳的敲门砖。
5. **方向契合电网需求**：新型电力系统、碳中和、智能电网方向热度高，与国网江苏、南瑞等单位的合作紧密，实习与项目机会多。

**弊**

1. **推免难度四校最高**。985 + A- + 南京区位，是电气保研的热门去向，竞争激烈。你的"双非本科 + 无论文录用"在这个池子里是相对劣势，需要靠：排名（你有）+ 六级（你有）+ 提前联系导师 + 预推免面试表现来补。东南大学电气近年有暑期考核/预推免环节（如2027年接收推免考核入选名单于2026年8月初公示），这是你必须抓住的窗口。
2. **校内培养压力大**。A- 学科的课题组毕业要求、科研节奏普遍偏高。如果你的目标是"拿硕士学历进电网"，这里的性价比不如华电/河海——你可能要付出更多科研精力去换一个你用不上的科研训练。
3. **若家不在江苏，优势大幅缩水**。南京区位和江苏电网的本地网络是它最大的两张牌，家在山东/京津冀的话这两张牌基本作废，只剩"985 + A-"两个通用标签。
4. 同一省份内部，江苏电网的竞争强度（南工程每年输送数百人）也意味着**即使东大毕业，进苏南热门市局仍需提前批 + 好的笔试面试表现**，不是躺进。

### 4.2 山东大学（济南·千佛山/兴隆山校区）

**定位**：985 / 双一流；电气工程第五轮学科评估**B+**（网传版本，从第四轮B升入B+）；电气工程一级学科博士点 + 博士后流动站；下设电力系统及其自动化（**国家重点培育学科**）、电机与电器（山东省重点学科）、电力电子与电力传动、高电压与绝缘技术、电工理论与新技术五个二级学科。

**利**

1. **山东电网的"地头蛇"，没有之一**。国网山东电力2025年第一批录用1283人、生源校163所，**山东大学居录用人数首位**（有统计称2025届国网山东公司录用山大硕士生182人，该数字来自媒体统计、口径需自行核实）。如果你的目标是山东电网，山大是最短路径。
2. **985标签**在国网提前批同样处于最高优先级档，进济南市局/青岛市局等热门单位时是硬通货。
3. **学科方向偏"电力系统"这条主干**：电力系统及其自动化是国家重点培育学科，与电网业务对口度极高；若你想走继电保护、调度自动化、电网规划这类方向，山大的师资和项目积累扎实。
4. **同为985但电气竞争强度通常低于东南**：A- vs B+ 的学科差距，会带来推免申请池的竞争差异。作为双非前2%的申请者，山大的实际录取概率可能高于东南大学（这是相对判断，务必向在读学长核实当年情况）。
5. 若家在山东、苏北、河南、河北南部，济南的地理距离是合适的。

**弊**

1. **若家在江苏/南京，"离家近"不成立**。南京—济南高铁约2.5–3小时，不算近；更关键的是，**山东电网与江苏电网分属不同省公司，山大在江苏电网的校友密度和认可度，远不如东南大学和河海大学**。你读完山大再回江苏电网求职，等于放弃了本地化优势，只剩985通用标签——这恰恰是四校里"绕远路"最明显的一种。
2. **电气学科层次弱于东南（A-）和华电（A）**。B+ 在985里属中上，但在电力系统的行业声量上，与"电气二龙四虎"和华电有可见差距。跨出山东省后，这个差距会被放大。
3. **强势方向相对集中**（电力系统、电机与电器）。若你对电力电子、新能源并网、储能等方向更感兴趣，需要具体核对该方向的导师与课题组实力，不能只看学院牌子。
4. 若家不在山东又不打算留山东，**山大在你清单里的定位会比较尴尬**——它既不"离家近"，也不是全国通吃型。

### 4.3 华北电力大学（北京校部·昌平 / 保定校区）

**定位**：211 / 双一流；电气工程学科在**教育部第四轮与第五轮学科评估中均位列A档**（校方院系官网明确表述），持续入选国家"双一流"建设学科；电力系统及其自动化为国家级重点学科。电力系统内称"电老虎"/"电力黄埔"。

**利**

1. **电气行业认可度最高的非985院校，且是全国通吃型**。校友网络覆盖全国各省市电力公司，从北京供电公司到浙江电网、从河北电网到广东电网都有密集分布。这一点是它区别于其他三校的核心价值——**不管你最后想去哪个省的电网，华电学历都被认**。
2. **国网就业体量最大**。据媒体引述的官方统计，华电2025届毕业生被国家电网录用1629人、南方电网录用270人；保定校区2025届电气研究生中，有统计称343人进入国家电网系统（占统计样本414人的82.9%，另一份统计为307人/74%，口径不一）。整体看，电气研究生进国网系统的比例大致在**七到八成**量级。2025届全校毕业生10747人（本科5948、硕士4570、博士229），硕博落实率超98%。
3. **推免/考研对双非相对更友好**。华电电气招生规模大，非985身份使得申请池中"清一色985"的程度低于东南。以你前2% + 六级550+的条件，录取概率在这四所里属于较高的一档（仅次于河海）。
4. **提前批身份合格**：211 + 原电力部属院校，在国网提前批的院校门槛内（多省提前批明确"原985、211及原电力部属院校硕士研究生"）。有大量电力系统中层校友，提前批面试的"隐性加分"明显。
5. **两校区毕业证完全一致**。北京校部与保定校区分别录取、不能互认，但毕业证书在外观、印章、编号上无任何差异，就业认可度等同。这意味着你可以用相对低的门槛（保定）拿到同样的行业招牌——**这是华电相对其他三校的一个隐藏优势**。

**弊**

1. **地域是它最大的短板（对你而言）**。北京校部在昌平，保定校区在河北，距南京都远（南京—北京高铁约4小时，到保定更久）。如果你的家在江苏，华电是四校里"离家近"最差的一所，读研期间也较难参与江苏电网的宣讲、实习与提前批面试。
2. **211非985的档位问题**。在国网提前批的院校优先级中，211/电力部属硕士排在985硕士之后。竞争者挤省会城市最热门市局、省公司本部、电科院时，华电硕士可能被985硕士压一头——虽然华电的学科评估（A）高于东南（A-）和山大（B+），但**部分省公司的人力筛选是先看"985"标签再看学科**，这种错位客观存在。
3. **内部竞争激烈**。电气招生规模大，意味着同校同专业竞争者多，导师资源、项目资源、实习推荐都需要主动争取，"躺赢"心态在这里会吃亏。
4. 学科优势集中在传统电力系统方向，若你对交叉方向（水电、新能源并网、水利电力）有兴趣，选择面相对窄。

### 4.4 河海大学（南京·江宁校区为主；另有常州校区）

**定位**：211 / 双一流（以水利工程A+闻名）；电气与动力工程学院于2023年11月学科调整后成立，前身可追溯至1958年设立的水力动力装置专业；电气工程**一级学科博士点**（2003年获电力系统及其自动化二级博士点，2010年获一级学科博士授予权）、博士后流动站；电气工程学科第五轮评估为 **B**（网传版本，媒体报道称"等级提升为B"），入选江苏高校优势学科四期建设工程、"十四五"江苏省重点学科A类。

**利**

1. **离家最近（若家在江苏/南京）**。主校区在南京江宁，与你的本科学校同城。这是"离家近"这个诉求上性价比最高的一所——**距离近 + 上岸概率高 + 江苏电网认可**三者同时成立。
2. **江苏电网的第三大生源校**。2025年国网江苏电力第一批录用中，河海大学录用人数超50人，位列第3（前两名为南京工程学院、东南大学）。作为一所非985的211，能压过西安交大、中国矿业大学排到第3，充分说明江苏电网对它的本地认可度。
3. **上岸难度四校最低**。电气学科B、学校牌子（在电力行业）弱于华电，推免竞争相对缓和。作为同城"双一流"高校的学生，南信大生源对河海并不陌生。在你的清单里，它是**最可靠的保底选项**——既能确保有学上，又不会掉出"211 + 一级学科博士点"这个电网就业的安全线。
4. **方向契合江苏电网的现实需求**。河海电气在新能源、电力系统、水电与动力工程上有交叉优势，与江苏电网"新能源消纳 + 特高压 + 配电网升级"的业务方向对得上。
5. 拥有完整的本硕博培养体系（电气一级学科博士点 + 博士后流动站），若读研后改变主意想深造或进电科院，路径没有被堵死。

**弊**

1. **电气学科层次四校最低（B）**。这是硬伤。B 意味着在**跨出江苏省之后**，行业认可度会明显衰减：去山东、京津冀、华南求职时，河海电气的牌子远不如华电，也不如东南和山大的985标签。
2. **学校整体品牌在电力系统的通用性有限**。河海的全国声誉建立在水利上，电气是"校内强势但行业内属区域型"。若你未来想转行、考公、或去电网系统外的单位（设计院、发电集团总部、外企），985标签的优势会更明显。
3. **若家不在江苏，优势大幅缩水**。河海的价值几乎全部绑定在"南京 + 江苏电网"上。家在山东/京津冀的话，它的排名应该落到四校最后。
4. 校友网络集中在华东与水利系统，覆盖面不如华电的全国性网络。想靠校友资源跨省调动/发展，后劲不足。

### 5.2 分情形排序

**情形A：家在江苏（含南京、苏南、苏中），目标是江苏电网**

1. **东南大学** — 985 + A- + 南京 + 江苏电网第2生源校，四项全中，是你的理论最优解。
2. **河海大学** — 南京 + 江苏电网第3生源校 + 上岸概率最高，是最佳保底，且"离家近"这个诉求上和东南几乎一样好。
3. **华北电力大学** — 全国通吃，回江苏也能被认，但读研四年（三年）不在江苏，本地资源与提前批地理便利性都弱，且非985。
4. **山东大学** — 除非家在苏北紧邻山东，否则地域和"回江苏"两端都不占优，在你清单里定位最尴尬。

> **推荐组合**：东南大学（冲刺）+ 华北电力大学（主申）+ 河海大学（保底），三所全部投，梯度清晰。

**情形B：家在山东，目标是山东电网**

1. **山东大学** — 国网山东第1生源校，最短路径，几乎不用犹豫。
2. **华北电力大学** — 全国通吃，在山东电网也是重要生源校，可作为冲刺985失败后的主申。
3. **东南大学** — 985标签在山东电网有效，但离山东远、本地校友网络弱于山大与华电。
4. **河海大学** — 出江苏认可度衰减明显，最弱选项。

> **推荐组合**：山东大学（主申）+ 华北电力大学（并申）+ 河海大学（保底）。

**情形C：家在京津冀**

1. **华北电力大学** — 无争议第一。地域近 + 行业认可度最高 + 本地校友网络最密。
2. **东南大学** — 985 + A-，跨省通用性强，进冀北/北京电网的985档位有优势。
3. **山东大学** — 985，山东到京津冀距离尚可，但电气声量弱于东南。
4. **河海大学** — 华东区域型院校，跨到华北效力衰减。

**情形D：家在江苏以外，或"去哪个省还不确定"**

1. **华北电力大学** — 全国通吃是唯一能对抗"目标省份不确定"的特性。
2. **东南大学** — 985 + A- 的通用性最好，任何省电网都认。
3. **山东大学** — 985标签通用，但电气学科相对弱。
4. **河海大学** — 通用性最弱。

### 5.3 一句话结论

- **先定省份，再定学校**。电网招聘的属地性远强于学校名气，"离家近"的正确解法是"选目标省网最认的那所"，而不是"选名气最大的那所"。
- **四校的抽象排序**：学科与行业认可度 华电 ≈ 东南 > 山大 > 河海；985标签与提前批档位 东南 = 山大 > 华电 = 河海；江苏属地 东南 > 河海 >> 山大 ≈ 华电；山东属地 山大 > 华电 >> 东南 > 河海；上岸难度 东南 > 山大 ≈ 华电 > 河海。

## 六、执行清单

### 6.1 推免时间轴（按"距离正式推免还有约一个完整周期"排布）

| 时间 | 动作 |
|---|---|
| 现在 | ①向学院教务确认推免名额与排名口径（见第二节4点）；②列出四校电气学院导师名单，标记"与电网/电力企业有横向合作"的课题组；③整理材料：成绩单、排名证明、四六级、竞赛证书、论文在投证明、专利受理通知书 |
| 当年12月–次年3月 | 稳住排名（这是你的核心资产，任何一门课的绩点都别掉）；推动论文进入外审/录用流程；发邮件联系导师（附个人陈述 + 简历 + 成果清单） |
| 次年3–5月 | 盯四校研招网/学院官网的夏令营与推免通知；准备专业课（电力系统分析、继电保护、电机学、电力电子、高电压技术） |
| 次年6–8月 | 参加夏令营/暑期考核。**东南大学电气近年有暑期推免考核环节（如2027年接收推免考核入选名单于8月初公示），这个窗口必须抓住** |
| 次年8–9月 | 预推免（部分学校无夏令营，只有预推免）；同步准备考研专业课以防资格落空 |
| 次年9月 | 本校推免资格公示 → 国家推免服务系统填报（通常9月下旬开放） |
| 次年10月 | 确定去向，转入"读研期间如何进电网"的准备 |

### 6.2 材料准备要点

- **论文未录用**：在材料里写"已在投/在审"，附投稿证明或审稿状态截图。面试时能讲清"问题是什么、我做了什么、结论是什么"即可，这比一篇挂名论文更有说服力。**绝不虚构"已录用"**。
- **专利在审**：附受理通知书/实审通知书，明确标注状态。
- **竞赛**：挑与电气/数理/工程强相关的放前面（全国大学生电工数学建模竞赛、电子设计竞赛、数学建模、智能车、节能减排、挑战杯/互联网+等），并注明你的个人角色与具体贡献，团队奖项要能说清"我负责哪一块"。
- **个人陈述**：明确写"职业规划是进入电力系统（国家电网/南方电网），希望做与电网运行、新型电力系统相关的工程与研究"。电网导向的导师普遍喜欢目标清晰、能干活、以就业为导向的学生——**这比假装想做学术更容易拿到offer**。
- **六级不用再刷**：550–599 已远超各校门槛。

### 6.3 面试高频问题准备

1. 为什么选我们学校 / 这个方向？
2. 挑一个你最熟的竞赛或论文项目，讲清楚技术路线和你的贡献。
3. 专业课基础：电力系统分析（潮流、短路、稳定）、继电保护、电机学、电力电子技术、高电压技术的基本概念。
4. 职业规划：为什么想进电网、想去哪个省、能接受去市局还是县局。
5. 如果问"论文为什么还没录用"，如实说明审稿周期，强调工作已完成、正在走流程。

### 6.4 选导师与选学硕/专硕

- **导师**：优先选与电力企业有横向合作、有稳定毕业生去向、毕业要求可控的课题组。**直接问在读学长"上一届师兄师姐去了哪些单位"——这个信息比学院牌子可靠得多**。
- **学硕 vs 专硕**：国网招聘对专硕、学硕基本一视同仁（同属"电工类"）。但部分省电科院、经研院、直属科研单位可能偏好学硕/博士。**建议以"能上岸"为第一原则**，同时打听该课题组的毕业要求与近三年真实去向再定。若你明确想进省电科院/经研院，学硕更稳；若目标是市局/县局，专硕完全够用，且招生名额通常更多。

### 6.5 读研期间为进电网要做的三件事

1. **研二暑期前锁定目标省网的提前批信息**（提前批9–11月集中进行，由各省电力公司自主组织宣讲和面试，部分岗位可免统考直接录用）。
2. **笔试准备**：国网统考电工类考电路、电力系统分析、继电保护、高电压、电机学等，研究生场次在12月初。提前批没拿到满意offer，统考就是主战场。
3. **实习**：争取去目标省网的电科院、经研院、调度中心或南瑞等关联企业实习，既有简历加分，也提前建立属地连接。

## 七、风险提示与信息核实清单

1. **学科评估第五轮结果教育部未正式公布**。本答卷中南信大、东南（A-）、山大（B+）、华电（A）、河海（B）的等级均引自网传整理版本与院校/院系的自述（如华电电力工程系官网明确"第四轮与第五轮均位列A档"、河海相关招生信息称"第五轮为B"）。请以此作为参考排序，不要作为硬性依据。
2. **就业数据口径不统一**。例如华电2025届国网录用人数，有"1629人"与"超过3000人"两种说法；东南大学在江苏电网2025年第一批录用人数有"102人"与"110人"两种统计；山大国网山东录用硕士生人数的媒体统计数字也需核实。**请以国网招聘平台与各省电力公司官方公示名单为准**。
3. **各省电网提前批的院校名单与免笔试政策每年都在变**。你入学当年的政策与你读研毕业那年的政策可能不同，不要基于今年的规则做四年后的规划。
4. **推免资格未确认是最大的不确定性**。所有择校分析都建立在"你能拿到推免名额"这个前提上。请优先把第二节的四个确认项做完。
5. **"离家近"的优先级需要你自己拍板**。如果它是硬约束（比如家中有需要照顾的人），那么"目标省网属地匹配"应当压倒"学校名气"，此时东南/河海（江苏）或山大（山东）的价值远高于华电；如果它是软偏好，"全国通吃 + 行业认可度最高"的华北电力反而更抗风险。
6. **南方电网的情形不同**。如果你的家在广东、广西、云南、贵州、海南，进的是南方电网而非国家电网，上述省网排序需要重做（南网的院校偏好与国网不同，华南本地院校权重更高）。

## 八、给你的最终建议（分三步）

**第一步**：确认本校推免资格的四件事（名额、口径、加分、一票否决项）。这是所有分析的前提，做不完后面都悬。

**第二步**：明确"家在哪里 / 想进哪个省网"。这一步的答案直接决定排序：
- 江苏 → 冲东南，主申华电，保底河海；
- 山东 → 主申山大，并申华电，保底河海；
- 京津冀 → 华电优先；
- 未定 / 家不在上述 → 华电（全国通吃）优先，东南次之。

**第三步**：按第六节时间轴推进，**四校全部投递，形成"冲刺—主申—保底"梯度**，不要押注单一学校。同时用一句话回答面试官："我要进电网，所以我要一个电力系统认的硕士学历和一个能让我到达目标省网的平台。"——你的排名、六级和竞赛足够支撑这句话，论文未录用不会成为障碍。
