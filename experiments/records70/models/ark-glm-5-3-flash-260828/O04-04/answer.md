# 定位与主线

先给结论：你的起点（985平台 + 大一上92分 + 竞赛入门奖）足以把保研当成默认目标。真正决定上限的只有三件事：**专业排名、一段真实的GNN科研、英语硬指标**。清华要分层看：本部电子系/计算机/交叉信息院是小概率事件，深研院（深圳国际研究生院）是“努力到位后有现实路径”的目标。策略上按“排名前3% + 一篇拿得出手的成果 + 三档院校组合”执行。

保研规则的底线认知：
- 综合排名以学业成绩为主（通常85%上下），竞赛/科研只是附加分且有上限。**排名比分数重要**——92分只是起点，先去问教务要专业排名。
- 红线：不挂科、四六级达标、无违纪。挂科一票否决。
- 外保核心材料 = 前五~六学期成绩单+排名证明、六级成绩、科研经历、竞赛、2–3封推荐信（科研导师的最有分量）。

# GNN科研的12个月路径

产物优先于过程，每一步都要留下能写进简历的东西：

1. **1–2个月**：Python/NumPy → PyTorch；PyG官方教程跑通GCN在Cora上的节点分类。产物：可运行的repo。
2. **2–4个月**：精读 DeepWalk → GCN → GraphSAGE → GAT → GIN 五篇基石 + 1篇综述（或Hamilton《Graph Representation Learning》前几章），每篇写复现笔记。产物：笔记+消融实验。
3. **3–6个月**：进组或大创立项（今年窗口已过就大二再报，先用“科研训练/进组打杂”顶上），从导师给的子问题切入：跑baseline、清洗数据、做消融。大二被拒很正常，多问几个组，用“能落地的小事”建立信任。
4. **6–12个月**：独立负责一个小问题。产物优先级：投稿（workshop / EI / CCF-C）＞ 开源repo+技术报告 ＞ 大创结题优秀。
5. **差异化定位**：利用通信背景做“图+通信”交叉——GNN用于无线资源分配、链路预测、网络拓扑优化、图信号处理、语义通信。这是面试时回答“通信工程为什么做GNN”的完整故事，也是你区别于纯CS学生的卖点。

# 竞赛与英语取舍

- **值得继续**：数学建模国赛（认可度最高、能讲科研故事）、大数赛冲国奖（数学功底信号）。美赛从S升级到H/M一次即可，之后止损。
- **边际收益低**：蓝桥杯、各类商业赛、过多参赛。竞赛附加分通常只有1~3分量级，**永远不要让它挤占排名和科研时间**。
- **英语**：四级若去年12月没拿理想分，2024年6月必须拿下且冲550；六级500+是很多顶尖院系筛材料的隐形门槛，冲550。有余力大三考雅思/托福（深研院部分项目全英文，也给留学留后路），属可选项。

# 关于“冲清华”

- **本部电子系/计算机/交叉信息院**：名额少、门槛=专业前列+硬科研（论文或顶级竞赛）。把它当主线努力方向，不当唯一目标。
- **深研院**（数据科学与信息技术、电子信息等）：路径相对清晰，看重排名+科研潜力+面试。你若保持专业前3% + 一段扎实GNN科研 + 六级500+，是有竞争力的画像。
- **同档备选**：上交电院、浙大信息学部、中科大，及哈工大/东南/北邮的AI+通信交叉团队。保底是本校（名称已概括）（通信/计算机/AI学院，本校政策通常友好）。

# 一句话定位

排名前约1% + 一作论文 + 国家级大创 + 六级500–549，这已经是清北本部夏令营“值得投”的画像。现在的瓶颈不再是资格，而是三件事：**材料与套磁的时间窗口（现在就是）、考核硬实力（机试/笔试/论文深挖）、以及投递组合的运气管理**。

# 之前规划中仍然适用的部分

- **排名守护**：前六学期成绩在预推免时仍计入，前约1%要守住到最后一学期，不挂科一票否决的规则不变。
- **GNN主线和“图+通信”差异化叙事**：现在升级为面试主故事——通信背景+GNN+一作，正好讲“AI for网络/网络for AI”的双向故事，对电子系、信息科学类院系是明显加分。
- **三档组合投递**：结构不变（冲刺–同档–保底），只是整体档位上移；夏令营本质有抽签成分，清北画像也要投8–12个项目。
- **推荐信和面试英语的提前量**：不变，但现在必须实际执行。
- 每学期末“排名、英语、科研产出”三项体检的习惯，保留。

# 需要调整的部分

- **竞赛：从选择性投入改为全面止损**。美赛、国赛不再花时间；唯一例外是把国家级大创做好结题（争取优秀，写进材料）。
- **六级：停止刷分**。500–549已过清北绝大多数院系的显性线，再刷到550的边际收益极低；把时间转投面试英语——2–3分钟英文自介、5分钟英文讲论文、英文问答，这才是真正被考察的环节。
- **目标结构更新**：原规划“清华本部是彩票、深研院可达”调整为“本部主攻（清华电子系/计算机系+北大信科/电子/计算机/智能学院）、深研院降为备选、本校（名称已概括）保底”。另外，同档的上交、浙大、中科大顶尖组仍然要投。
- **新增一个关键决策：直博还是学硕**。清北热门组给外校生的名额里，直博通常远多于学硕；如果读博意愿≥50%，走直博+提前套磁，入营和录取概率显著提升，代价是面试科研深挖更狠。这个要在4月前想清楚。
- **新增动作：校外套磁**。3–4月给目标组导师发邮件（自我介绍3–5句+CV+论文+为什么选这个组），直博尤其要套。
- **时间表前移**：原规划“大三下3–5月备材料”，现在3月就必须启动，因为清华、北大各院系的通知往年4月中到5月陆续发布，材料4月要能随时打包。

# 考核准备按院系类型分两条线

- **清华电子系、北大信科/电子类**：考数学（线代/概率/随机过程）+通信/信号基础+ML基础+英语面试，基本无机试。你的匹配度最高，作为主投。
- **清华计算机系、北大计算机类**：多一环机试（算法题）。若决定投，3–6月每周固定刷题，目标LeetCode 200题量级+往年机试题；不投就把这三个月全部给论文和数学。
- **论文深挖是所有营的必考题**：动机、与SOTA的对比、每个实验为什么这么设计、局限、如果重做会怎么做，都要能脱稿讲；论文级别无论高低，被问穿才是致命的。
- 若第一篇偏应用或期刊层级一般，用“对第一篇的深度掌握+第二产出”来补强，而不是回避。
