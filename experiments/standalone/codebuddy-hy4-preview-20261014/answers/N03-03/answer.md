> **目标类型**：推荐免试攻读硕士 / 直博

## 〇、使用说明与信息边界（请先读这一段）

1. **文中所列的学院名称、招生专业、项目归属，以各校研究生院与学院官网当年发布的《接收推荐免试研究生章程 / 工作细则》为准。** 近年高校院系调整非常频繁（例如上海交通大学 2024 年 12 月整合自动化系与感知科学与工程学院成立「自动化与感知学院」，复旦大学新设「智能机器人与先进制造创新学院」），去年的招生单位名称今年可能已经变了。
2. **学科等级不作为申报依据。** 全国第四轮学科评估（2017 年公布）结果可查，第五轮评估结果教育部未向社会正式公布，网络流传版本不可信。下文凡涉及"顶尖 / 第一梯队"的表述，均指学界与业界的公开共识，请勿当作官方排名使用。
3. **"2026 年推免季"的口径**：按主流理解即"2026 年内启动、2027 年秋季入学"的这一轮。为避免年份歧义，第五部分的时间轴采用**相对时间轴**（"入学前一年的 10 月 → 入学当年 9 月"），无论你处在哪个轮次都可以直接套用。
4. 下文每个组合都标注了**推荐申报的学位类型**（学硕 / 专硕 / 直博）、**对口研究方向**、**为什么适合你**、**门槛与风险**、**信息核实入口**。

## 一、先校准：你的画像与竞争力定位

### 1.1 硬指标拆解

| 维度 | 你的情况 | 在推免竞争中的真实含义 |
|---|---|---|
| 本科院校 | 上海大学（211 / 双一流） | 出身不是短板但也不是加分项。清北复交的"硬卡学校"岗位会有隐形门槛，但**前 2% + 有论文**足以让你进入绝大多数 985 的面试环节并被认真评估 |
| 专业排名 | 前约 2% | **最核心的一张牌。** 几乎所有 985 的推免细则都写"专业排名前 10%/15%/20%"，前 2% 意味着你在"排名"这一项基本不会被筛掉，可以放心把精力放在科研叙事和套磁上 |
| 英语 | 六级 650–699 | **第二张牌，而且是稀缺的。** 650+ 可以直接满足几乎所有项目的免修/英语门槛；对国际化联合培养项目（浙大国际校区、东南-蒙纳士、上交溥渊、清华深研院）是实打实的加分项，也是导师判断"能否读英文文献、能否写英文论文"的直接证据 |
| 科研 | 机器视觉方向 EI 会议论文一篇 | **差异化优势。** 在电气 / 控制类申请者中，"有正式发表的论文"仍是少数。但要注意：EI 会议含金量跨度极大，面试时会被深挖，见 5.2 与 5.4 |
| 工程 | 控制方向大创 | 提供"完整工程闭环"的证据：建模 → 控制算法 → 实现 → 验证。这是导师最看重的"能不能干活"的信号 |
| 专业 | 电气工程及其自动化 | **被很多人低估的一项。** 电气 + 视觉 = 电力设备智能巡检、能源系统视觉感知，这是当下非常热、且科班 CS 学生做不了的方向 |

**结论**：你的画像属于"**211 头部 + 有科研产出 + 英语超强 + 电气/控制/视觉三栖**"。这种画像的特点是——**上限取决于你敢不敢冲、套磁到不到位，下限非常稳**。所以下面 15 个组合按"冲刺 3 / 主攻 6 / 特色 4 / 稳妥 2"分层，而不是清一色地保守或清一色地冒险。

### 1.2 三条可选的申请叙事（这一步比选学校更重要）

你的背景可以讲出三个完全不同的故事，对应三类学院。**不要三条同时讲，会显得没有主线。**

| 叙事 | 讲法 | 适配学院 | 建议权重 |
|---|---|---|---|
| **A. 控制 + 视觉（推荐主打）** | "我做控制，也做视觉，我想让机器人真正'看得见、抓得准'" | 自动化 / 控制 / 机器人学院 | **主攻（约 60% 志愿）** |
| **B. 电气 + AI（差异化奇兵）** | "我的本科是电气，我的研究是视觉，我要做的是电力系统的智能感知与巡检" | 电气工程 / 能源类学院 | 辅助（约 25% 志愿） |
| **C. 纯 AI / 视觉** | "我发过视觉论文，我想继续做视觉" | 人工智能 / 计算机学院 | 谨慎（约 15% 志愿） |

**为什么建议主打 A、用 B 做奇兵、慎用 C？**

- 走 **C**，你要和 CS 科班、有顶级会议论文的学生正面竞争，你的电气背景优势完全归零，论文又只是 EI 会议，胜率最低。
- 走 **A**，你同时具备"控制工程经验（大创）+ 视觉算法能力（论文）"，这恰好是机器人视觉感知、视觉伺服、具身智能这两个方向最缺的复合型人才画像，而纯 CS 学生缺控制，纯自动化学生缺视觉。
- 走 **B**，你的电气本科背景从"劣势"变成"壁垒"——电力巡检这个赛道，CS 学生进不来，电气学生不会算法，你正好站在交叉点上。这个叙事在面试里极容易出彩，建议你**专门为它准备一份个人陈述**。

> **一句话定位**：你是"会用视觉做控制的电气人"，不是"想转 CS 的电气人"。前者让人眼前一亮，后者让人觉得可惜。

**专业 / 项目**：电子信息（**智能制造**方向 / 人工智能方向）硕士；或 电气工程（能源互联网方向）

**对口方向**：工业视觉检测与缺陷识别、智能传感与机器视觉、机器人感知与控制、能源互联网视觉感知

**为什么适合你**：
- 清华深研院相比清华本部，对 211 优质生源的大门开得更宽，且电子信息是大类招生，下设人工智能、智能制造、海洋技术与工程、互联网+创新设计、数据科学等多个方向，**"智能制造"方向几乎是为你的"视觉 + 控制"组合量身定制的**。
- 深研院与产业端（鹏城实验室、华为、腾讯及深圳智能制造产业链）结合紧密，你做过大创，属于"能落地"的类型，比纯刷分型选手更受这里欢迎。

- 备选路径：若报电气工程方向，可以把你的背景包装成"**输变电设备无人机巡检图像智能识别 / 能源系统视觉感知**"，这是清华电气在深研院的重点布局之一，且全国做这个方向的团队不多。

**信息核实**：清华大学深圳国际研究生院官网（sigs.tsinghua.edu.cn）→ 招生 → 推免招生；清华研究生招生综合信息平台（yzbm.tsinghua.edu.cn）。

## 五、申请执行方案

### 5.1 相对时间轴（入学前一年记为 T-1，入学当年记为 T）

| 时间 | 关键动作 |
|---|---|
| **T-1 年 10–12 月** | ①确认上海大学推免遴选细则（成绩占比 / 加分规则 / 英语要求）并开始对照自查；②确定主线叙事（建议 A 主打、B 辅助）；③补齐科研短板（见 5.2）；④关注保研类信息渠道与目标院校官网 |
| **T-1 年 1–2 月** | 确定 15–20 所目标院校与 30 位左右候选导师；开始读导师近三年论文，做"导师档案表"（方向 / 近年代表作 / 经费与项目 / 毕业去向 / 在招名额） |
| **T 年 3–4 月** | 准备材料：成绩单、排名证明、六级成绩单、论文首页与检索证明、大创结题证明、获奖证书、推荐信；撰写三版个人陈述（A / B / C 叙事各一版） |
| **T 年 4–6 月** | **夏令营 / 优才营报名高峰**（各校 4–6 月陆续发布通知）。夏令营是冲击名校的主战场，能去就去 |
| **T 年 5–6 月** | **第一波套磁**。邮件附一页纸简历 + 论文摘要 + 个人陈述（见 5.3） |
| **T 年 7–8 月** | 参加夏令营 / 暑期学校，争取"优秀营员"；同步准备专业课与论文复述 |
| **T 年 8–9 月** | **预推免（预报名）**。这是很多人的"第二次机会"，也是上交、浙大、复旦等项目的重要通道；各校预报名系统通常在 8 月底至 9 月中开放 |
| **T 年 9 月** | 全国推免服务系统正式报名（通常在 9 月下旬开通）；填报志愿、接收复试通知与待录取通知。**注意：待录取通知往往要求在数小时内确认，务必提前和家人、导师沟通好决策规则** |
| **T 年 10 月** | 系统关闭前后的补录与捡漏；确认录取后联系导师、提前进组 |

### 5.2 材料清单与"讲法"

**核心材料**
- 本科成绩单 + 专业排名证明（教务处盖章，务必提前问清楚办理周期）
- 六级成绩单（650–699 这一项要**单独强调**，写在简历显眼位置）
- EI 会议论文：首页、检索证明（或录用通知 + DOI）
- 大创结题材料、演示视频 / 样机照片 / 代码仓库
- 获奖证书、奖学金证明
- 2–3 封推荐信（建议：大创指导老师 + 论文指导老师 + 一位核心专业课老师）

**关于你的 EI 会议论文，必须做三件事：**
1. **准备一页纸的"论文说明"**：问题定义 → 现有方法的不足 → 你的方法 → 实验设置（数据集、指标、baseline）→ 结果 → **你个人承担的工作**（这一点最重要）。
2. **诚实界定贡献**。EI 会议在部分老师心中有"水会"的预设。与其辩解，不如直接讲清楚你做了什么、做到了什么程度、下一步打算怎么改进。**诚实比包装更能赢得控制/机器人方向的导师好感。**
3. **增强可信度的三种方式**（任选其一即可显著提升）：把扩展版投往 SCI 期刊或更好的会议；把代码开源并附 GitHub 链接；把方法做成可交互的 demo（检测/分割/识别的可视化结果）。

**关于大创，要讲"闭环"而不是"参与"**：我做了什么系统 → 控制对象是什么 → 控制律/算法怎么设计 → 如何验证 → 遇到了什么问题 → 怎么解决的。导师想听的是工程判断力。

### 5.3 联系导师邮件的要点

- **标题**：`推免自荐-上海大学-电气工程及其自动化-专业排名2%-XXX`
- 正文控制在 300 字以内，四段：①一句话自我介绍（学校、专业、排名、英语）；②一句话讲你的研究经历（视觉论文 + 控制大创），并说明与导师哪个具体方向相关；③一句话说明你读过他的哪篇工作、有什么具体的想法或问题（**这一步决定回复率**）；④附件 + 礼貌请求。
- **附件**：一页纸简历 + 论文首页/PDF + 个人陈述（合并为一个 PDF，文件名带姓名）。
- **节奏**：同一学院一次只联系一位老师；一周无回复再联系下一位；**不要群发**。
- **对冲刺层（清华深研院、自动化所）尤其重要**——这两个地方不套磁等于没申请。

### 5.4 面试高频追问与准备清单

**必被追问（关于论文）**
- 你的方法的**创新点**到底是什么？和 baseline 相比提升了多少？
- 你的实验有没有做**消融实验**？数据集规模与划分方式？
- 这篇论文里**你具体做了哪一部分**？（会被反复追问，务必准备一致的、具体的答案）
- 这个方法有什么**局限**？如果继续做，你下一步做什么？

**必被追问（关于大创 / 控制）**
- 系统的**被控对象与数学模型**；为什么选这个控制策略；稳定性/收敛性如何论证；参数如何整定。
- 传感器选型、实时性、工程上的取舍。

**电气专业基础**（报电气学院时重点复习）
- 电路、电力系统分析、电机学、电力电子技术、自动控制原理。

**英语环节**
- 六级 650+ 意味着老师对你的英语期待会更高。准备一段 1–2 分钟的英文自我介绍 + 一段英文的研究经历介绍（含专业术语）。
- 高频英文问题：介绍你的论文 / 为什么选择我们学校 / 你未来的研究计划。

**动机类**
- 为什么从电气转到控制 / 视觉？（**不要说"电气不好就业"或"想转 CS"**，要说"我在做大创时发现，让系统真正自主运行的关键在感知与控制，所以我把研究重心放了过来，而电气背景让我更理解物理系统本身"）
- 为什么选我们学校 / 这个方向？（**必须说出具体的导师名字和具体的方向**，泛泛而谈是最低分的回答）

### 5.5 学硕 / 专硕 / 直博 / 工程硕博专项，怎么选

| 类型 | 适合谁 | 你的情况建议 |
|---|---|---|
| **学硕** | 想读博、想走学术/研究院路线 | 冲刺层与主攻层的首选申报类型；名额少、竞争激烈 |
| **专硕（电子信息等）** | 以就业为目标、想尽快进入产业 | **你的主力申报类型**。招生规模大、对工程经历友好、上海/深圳/苏州等产业城市优势明显 |
| **直博** | 明确想做研究、能承受 5 年周期 | **你值得认真考虑**。你有论文、有排名、英语强，直博在名校的成功率往往高于学硕，且奖学金与导师资源更好。但要想清楚：直博一旦退出代价很大 |
| **工程硕博专项** | 想去头部企业研究院、想拿企业资源 | **强烈建议关注**。清华、上交等校的工程硕博士培养改革专项近年名额持续增长，是"信息差红利"最大的一块 |

**给你的建议**：冲刺层报学硕/直博（反正机会成本不高），主攻层学硕与专硕并行，特色层与稳妥层主报专硕 + 争取直博或硕博连读名额。

### 5.6 志愿填报与"保底"操作

1. **保底必须真的保到底**：确认拿到本校（或华理）的**明确接收意向**（最好有导师的口头或书面确认），再在冲刺层放手一搏。
2. **推免系统只有 3 个平行志愿**（以当年规则为准），必须"冲 1 稳 1 保 1"，不要三个都冲。
3. **待录取通知有时限**（常见为数小时内确认）。提前和家人、导师约定决策规则：例如"收到 X 校待录取即确认；否则等待 Y 校"。**当场犹豫是最常见的翻车点。**
4. **夏令营优秀营员 / 预推免预接收 ≠ 最终录取**，仍需在系统里完成报名与确认。每年都有人因为忘记在系统里填报而与 offer 失之交臂。
5. **不要放弃捡漏**：系统开放后期经常有名额释放（有人放弃、有人改志愿），保持手机畅通、信息渠道活跃。

## 六、风险提示与信息核实清单

1. **招生专业、名额、代码、考核方式每年都会变**，且近年院系调整频繁。所有报名动作必须以目标院校**研究生院与学院官网当年发布的正式通知**为准，不要用去年的专业目录套今年。
2. **新建学院/新设项目要格外留意归属关系**。例如复旦大学智能机器人与先进制造创新学院由多个研究院与系整合而成，其下属单位的研究生招生统一依托该创新学院进行；上海交通大学自动化与感知学院由原自动化系与感知科学与工程学院合并组建。类似调整可能在你报名前再次发生。
3. **学科评估等级请自行核对**。第四轮学科评估（2017 年公布）结果可在教育部学位与研究生教育发展中心公开渠道查询；第五轮评估结果教育部未正式公布，网传版本仅供参考，不应作为决策依据。
4. **EI 会议论文的认定规则各校不同**。部分高校对推免加分、复试评分中的论文认定有明确的期刊/会议目录要求，需提前向学院教务或研招办确认你的论文是否被认可、能加多少分。
5. **推免资格是前提**。上海大学前约 2% 的排名意味着资格基本稳，但仍须严格对照本校当年的遴选办法，确认成绩口径、加分上限、英语与违纪/挂科等硬性条件，避免出现"外校 offer 拿到了、本校资格没有"的最坏情况。
6. **对导师的核实不可省略**。通过学院官网师资页、近三年论文、课题组毕业生去向三个渠道交叉验证；特别留意导师是否即将退休、是否仍在招生、课题组实际出口方向。
7. **城市与产业资源要纳入决策**。你的方向（视觉 + 控制 + 机器人）在上海、深圳、苏州、杭州的产业生态明显更好，这对实习、就业与项目来源都有直接影响。

## 七、如果只记住三句话

1. **你的主线叙事是"控制 + 视觉"，不是"从电气转行"。** 让机器人"看得见、抓得准"是你最自然、最有说服力的故事。
2. **"电气 + AI"是你独有的差异化武器。** 电力设备智能巡检这个方向，CS 学生进不来，电气学生不会算法，而你正好站在交叉点上——专门为它准备一份个人陈述和一份志愿。
3. **冲刺层靠套磁，主攻层靠夏令营，稳妥层靠早谈条件。** 前 2% + 六级 650+ + 有一作论文，这三项决定了你的下限非常高；真正决定上限的，是你有没有提前半年认真读导师的论文、发出去那几封有内容的邮件。
