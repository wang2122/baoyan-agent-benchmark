# 保研 Benchmark公开题库

本项目是屿智同行的保研 Agent 评测项目。

题面已脱敏；导出清单记录数据版本与内容哈希。

本数据集包含70题、83个作答阶段：57道单阶段题、13道两阶段题，两阶段合为一道题评分。部分任务共享背景信息。完整题面、评分条件和参考项目见[题目与评分](questions-and-scoring.md)。

[当前索引](selection.json) · [完整评分通则](scoring.md)

`tasks.jsonl`保存题面及阶段，`rubrics.jsonl`保存公开可下载的评分条件。评测时不得将评分标准或参考项目提供给被测Agent。

每题100分，完整择校题采用项目匹配70分、推荐质量30分。待核项保留待核。本数据包不含答卷、成绩或执行记录。数据许可为CC BY 4.0。
